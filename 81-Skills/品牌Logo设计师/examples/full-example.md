# 完整示例：Momcozy 子品牌「Momcozy Bloom」Logo 设计

> 与 `SKILL.md` 的「认知空白占位」方法配套的落地样例，演示一次完整输出长什么样。执行时替换品牌名 / 品类 / 风格偏好即可。

---

## 竞品视觉审计

| 品牌 | 视觉联想 | 是否已拥挤 |
|------|---------|-----------|
| Elvie | 极简科技、冷静高级 | 已拥挤（极简科技被反复使用） |
| Medela | 医疗信任、专业理性 | 已拥挤（医疗蓝绿被用滥） |
| Willow | 柔和现代、生活方式化 | 部分拥挤（柔和现代常见） |

**认知空白判断**：极简科技、医疗理性、柔和现代都已被占据；「温暖但智能」「母性关怀但不低幼」仍空着。

---

## 方案 1：温暖智能

- **认知目标**：用户第一反应是「这是一个真正理解妈妈生活、又很聪明的品牌」。
- **图形逻辑**：一个柔和的圆角母性轮廓，内嵌一条克制的微光弧线（智能的暗示），不堆砌科技元素。
- **字标关系**：圆角小写无衬线 wordmark，与图形同曲率，保持亲和。
- **记忆度判断**：独立符号 = 母性轮廓 + 微光弧，缩小到头像仍可辨；非行业默认极简。
- **为什么适合 Momcozy**：抢占「温暖 + 智能」空白，区别于 Elvie 的冷科技与 Medela 的硬医疗。

## 方案 2：柔和专业

- **认知目标**：「可信赖但不冰冷的专业品牌」。
- **图形逻辑**：双圆相切构成负空间的母婴符号，线条粗细一致、结构理性。
- **字标关系**：几何无衬线，字距略松，传达专业与呼吸感。
- **记忆度判断**：负空间符号可独立识别，适合五金压印与吊牌。
- **为什么适合 Momcozy**：在 Medela 的医疗信任之外，用柔和削弱冰冷感。

## 方案 3：女性自我掌控感

- **认知目标**：「现代、温暖、好记，且强调妈妈自己的掌控感」。
- **图形逻辑**：一个上扬弧 + 闭合圆的组合，暗喻「托举与自主」，避免低幼。
- **字标关系**：大写首字母 + 小写，略带衬线的高对比字标。
- **记忆度判断**：上扬弧是独特记忆点，缩小不糊；延展性强，可生成单色刺绣版。
- **为什么适合 Momcozy**：锚定「母性关怀但不低幼」，支撑高端线延展。

---

## 输出要点回顾

- 三套方案是三种**认知策略**，不是三种配色。
- 每套都回答了「认知目标 / 图形逻辑 / 字标关系 / 记忆度 / 为什么适合」。
- 所有图形描述均强调「不可独立识别 / 缩小可辨 / 非行业默认」，呼应 `SKILL.md` 的记忆度三问。
