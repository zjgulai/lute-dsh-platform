## 一、「三大购物时刻」框架与子场景（母婴向）

### 1. Calendar · 时间驱动（可预测峰值）

**特征：** 节日/季节固定；流量与广告竞价有规律；需 **提前 2–3 个月** 完成选品、打样、头程与页面。

| 主场景 | 子场景示例 | 典型购买意图 | Momcozy 关联举例 |
|--------|------------|--------------|------------------|
| 母亲节 | 送妈妈、送自己、婆媳/配偶代买 | 送礼、情绪价值、自用犒赏 | 哺乳舒适礼盒、产后放松小物、与「妈妈身份认同」相关的组合 |
| 情人节/伴侣节 | 孕产期关怀、准爸爸送礼 | 送礼、情感表达 | 准爸妈双人关怀套装、夜间喂养支持类组合 |
| 圣诞节/年末 | 礼品清单、家庭聚会、新生儿见面礼 | 送礼、家居氛围 | 礼品包装 bundle、节日配色配件 |
| 返校季（部分市场） | 背奶上班、泵奶收纳 | 自用、效率整理 | 便携储奶、背奶包配件、清洁收纳 |
| 黑五/网一/Prime Day | 囤货、大件决策窗口 | 自用、性价比 | 吸奶器主机、高客单 bundle |

**排期提示：** 欧洲与美国母亲节日期不同；圣诞与 Q4 需单独做 **库存与现金流** 沙盘。

---

### 2. Life · 事件驱动（高情绪、强礼品）

**特征：** 由人生节点触发；客单与转化率常高于平日；内容营销适合 **故事化、礼盒化**。

| 主场景 | 子场景示例 | 典型购买意图 | Momcozy 关联举例 |
|--------|------------|--------------|------------------|
| 新生儿到来 | 产前准备、产后第一周 | 自用、家庭采购 | 吸奶器与配件、哺乳文胸、夜间哺乳便利品 |
| Baby shower | 宾客凑礼、主办人统一主题 | 送礼、社交礼仪 | 中性色礼盒、可刻字/可写贺卡组合 |
| 满月 / 百天 | 亲友送礼、纪念仪式 | 送礼、纪念 | 里程碑卡、成长记录 + 实用小物 |
| 周岁 | 派对、相册、成长礼物 | 送礼、纪念 | 与「告别婴儿期」叙事相关的套装 |
| 二胎/多胎 | 效率、公平、大宝情绪 | 自用、家庭平衡 | 双人份配件、收纳与动线优化 |

---

### 3. Everyday · 日常驱动（全年基本盘）

**特征：** 需求波动小于大促，但考验 **评论、复购、SKU 宽度与广告效率**。

| 主场景 | 子场景示例 | 典型购买意图 | Momcozy 关联举例 |
|--------|------------|--------------|------------------|
| 哺乳日常 | 居家/职场泵奶、漏奶、RT 不适 | 自用 | 乳垫、羊脂膏替代护理、法兰/阀膜配件 |
| 外出带娃 | 通勤、旅行、公共场所哺乳 | 自用、便携 | 便携消毒、小型温奶、收纳包 |
| 辅食期 | 引入固体食物、清洁 | 自用 | 与「离乳过渡期」相邻的周边（注意品类边界） |
| 睡眠训练 | 规律作息、夜奶减少 | 自用 | 夜间静音泵奶、低打扰照明/收纳（谨慎宣称疗效） |
| 背奶/职场妈妈 | 单位泵奶、储奶动线 | 自用、效率 | 冰包、瓶标、分装配件 |

## 二、产品策略模板与差异化抓手

以下模板可与 SKILL 第三步「三套策略」一一对应；每套策略建议 **显式写出采用的 1–2 个抓手**。

### 模板 A：场景礼盒（Bundle / Gifting）

- **适用：** Life + Calendar 叠加。  
- **核心：** 降低选品成本、提高客单、统一视觉与贺卡叙事。  
- **差异化：** 主题命名清晰、内件可替换层级（入门/进阶）、包装开箱体验。

### 模板 B：配件生态（Accessory Ecosystem）

- **适用：** Everyday + 已存在爆款主品（如穿戴式吸奶器）。  
- **核心：** 互补购买、低试错单价、长尾词。  
- **差异化：** 兼容说明透明、材质与清洗指引、套装比单买更省。

### 模板 C：细分人群（Niche Cohort）

- **适用：** 双胞胎、剖腹产恢复期、大胸围等。  
- **核心：** 搜索词更精准、广告可收窄。  
- **差异化：** 尺码/用法说明极致具体、社群语言一致。

### 模板 D：材质/功能微创新（Upgrade）

- **适用：** 成熟类目中的体验痛点（噪音、重量、过敏）。  
- **核心：** 评论区痛点 → 产品规格单点突破。  
- **差异化：** 可量化指标（克重、dB、认证）、对比图诚实。

### 模板 E：内容平台趋势嫁接（Trend Bridge）

- **适用：** TikTok/Reels 上可视性强的用法演示。  
- **核心：** 趋势词 + 母婴安全与合规表述并重。  
- **差异化：** 同一产品多场景短视频脚本、KOL 可复述的一句话卖点。

### 模板 F：DTC 独占款（Shopify-first）

- **适用：** 亚马逊做认知、独立站做组合与订阅。  
- **核心：** 订阅补货、会员礼、联名限量。  
- **差异化：** 故事页、邮件流与亚马逊详情差异化但承诺一致。

**组合建议：** 「场景礼盒 + 配件生态」「细分人群 + 材质升级」等；避免三套策略仅换文案不换人群/渠道。

## 三、产品验证清单模板（复制即用）

在 SKILL 第五步展开时，可按下列勾选并补数据。

### 1. 需求

- [ ] 主词在目标站点 **搜索量/类目体量** 是否有区间判断？  
- [ ] Google Trends / 平台站内趋势 **是否同向**？  
- [ ] 是否存在 **强季节**？峰值是否与备货周期匹配？

### 2. 竞争

- [ ] 前 **10** 条结果中：品牌 vs 白牌比例？  
- [ ] 头部 **价格带、评分、评论数** 区间？  
- [ ] 差评 **Top 主题**（尺寸、兼容、噪音、售后）？  
- [ ] 是否有 **专利/外观** 或平台限售风险（粗筛）？

### 3. 利润（粗算即可，注明假设）

- [ ] 采购/生产成本区间  
- [ ] 头程 + 仓储 + 平台佣金 + 支付费  
- [ ] 广告占比假设（新品期 / 稳态期）  
- [ ] **目标毛利** 是否高于团队底线？

### 4. 趋势持续性

- [ ] 热点持续 **周/月** 还是可跨季？  
- [ ] 是否依赖 **单一网红/单一事件**？  
- [ ] 有无 **互补 SKU** 承接流量（避免单点崩盘）？

### 5. 渠道与履约

- [ ] Amazon：尺寸/重量段、FBA 可行性、是否需分类审核？  
- [ ] Shopify：履约时效、退换政策、包装是否适合送礼场景？

**结论栏（一句话）：**  pursue（推进） / pilot（小批量试销） / park（暂缓） —— 写明 **首要风险** 与 **下一步唯一动作**。

## 四、季节性规划表（时间轴模板）

按 **目标市场** 复制多份（美国 / 德国 / 英国等节日不同）。

| 阶段 | 距大促/节日 | 动作 | 负责人/备注 |
|------|-------------|------|-------------|
| T-90 ~ T-60 | 选品定案 | 完成三大时刻对齐、趋势表、三套策略初筛 | 需数据截图或来源标注 |
| T-60 ~ T-45 | 样品与包装 | 礼盒结构、合规文案、主图风格 | DTC 可与亚马逊区分叙事 |
| T-45 ~ T-30 | 页面与广告 | 关键词投放、A+ / 着陆页、达人脚本 | 礼品意图关键词单独一组 |
| T-30 ~ T-14 | 库存与促销 | FBA 入库、Coupon/Prime 专享、邮件序列 | 关注 IPI 与周转 |
| T-14 ~ T-7 | 冲刺 | 高转化词加价、库存预警、客服话术 | 礼品迟到风险话术准备 |
| T-0 ~ T+7 | 复盘 | 广告 ACOS、断货天数、退货原因 | 输出下一季 Calendar 调整项 |

**Life/Everyday：** 可将上表中的「节日」替换为 **固定上新节奏**（如每月 1 次主题礼盒），保留 **验证清单** 与 **库存纪律** 两栏不变。
