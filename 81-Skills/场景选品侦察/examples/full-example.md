# 场景选品侦察 — 完整示例

> 本示例演示从「哺乳期重返工作」身份迁移节点出发的完整五步输出，供格式参考。

## 1. 身份迁移节点

```
当前阶段：哺乳期（居家/逐步返岗）
下一个阶段：重返办公室的哺乳期职场妈妈
这个迁移为什么重要：妈妈的掌控感被工作节奏打碎，通勤、隐私、时间碎片、装备便携成为全新摩擦，这些摩擦在「在家带娃」阶段根本不会出现。
```

## 2. 反直觉场景

```
场景名称：通勤途中的泵奶窗口（地铁/公交/开车）
具体摩擦：返工后一天两次的泵奶时间被挤压进通勤和会议间隙，妈妈在移动中既要隐蔽又要定时排空，害怕漏奶、堵奶和涨奶。
购买动机：不是「要一个吸奶器」，而是「要一个能让我在通勤路上不被打断地完成这件事、还不被同事注意的装备」。
```

## 3. 三个场景机会

```
机会 1：通勤便携泵奶收纳+保温套装（泵奶器+储奶袋+冰盒一体化通勤包）
适合渠道：DTC 为主（痛点教育需要内容）
与 Momcozy 的协同：直接复用现有可穿戴泵奶器，做成「返岗通勤套餐」bundle，交叉销售极强。

机会 2：可穿戴泵奶器的「静音办公模式」配件/遮罩配件
适合渠道：Amazon（搜索型购买：「quiet wearable pump cover」）
与 Momcozy 的协同：现有产品线延伸，供应链复用度高。

机会 3：职场妈妈泵奶时间管理+提醒应用（软硬件联动）
适合渠道：DTC 内容生态（作为内容钩子，不单独卖）
与 Momcozy 的协同：社群洞察里有大量「忘记泵奶/堵奶」的求助，可作为内容引流而非独立 SKU。
```

## 4. 品牌能力矩阵（五维速评）

| 维度 | 机会1 | 机会2 | 机会3 |
|------|------|------|------|
| 用户交叉销售潜力 | 强 | 强 | 中 |
| 供应链复用能力 | 中（需新增包材） | 强 | 弱 |
| Amazon 承接能力 | 中 | 强 | 弱 |
| DTC 内容承接能力 | 强 | 中 | 强 |
| 社群洞察支撑度 | 强 | 中 | 强 |

## 5. 主推方向

```
推荐方向：通勤便携泵奶收纳套装（机会1），绑定「返岗第一周」叙事。
推荐理由：它是身份迁移的物理锚点，能自然带动现有可穿戴泵奶器复购，且「返岗」是强烈的情绪与刚需时刻。
适合 Amazon 还是 DTC：先 DTC 讲「返岗第一周生存包」故事 + 邮件序列，跑通后在 Amazon 上架标准 SKU。
第一验证动作：在现有社群发起「返工第一天最慌的3件事」问卷，验证通勤泵奶是否高频词（需真实数据，勿编造）。
```
