# 价格分析方法论

本文件说明「电商价格监控」的定价分析方法，供需要深入判断时查阅。

## 跨平台聚合

对同一产品的多个平台价格做聚合，输出最低价、最高价、均价、中位数与价差（`price_spread = max - min`）。

- 非法价格（≤ 0 或非数值）直接跳过，不参与聚合。
- 平台数 < 2 时价差置空（无可比对象）。

## 趋势判定（双指标）

用「线性回归斜率 + 波动率」两个指标判断趋势方向，而非只比较首尾价格：

- 斜率 > +2%（相对均价）→ `up`；< -2% → `down`；否则 `stable`
- 波动率（标准差 / 均值）> 0.15 → `volatile`（波动优先于方向）

## 告警规则（电商定价特有）

| 类型 | 触发条件 | 严重度 |
|------|---------|--------|
| MAP 违规 | 售价 < 最低广告价（MAP） | 低于 10% 为 medium，>10% 为 high |
| 竞品降价 | 现价相对参考价跌幅 ≥ 阈值（默认 10%） | ≥20% 为 high，否则 medium |
| 促销识别 | 折扣 ≥ 阈值（默认 15%） | low |

## 使用建议

- 输入价格 JSON 需包含每个产品的平台价格，可附带 `price_history` 做趋势。
- MAP 价格文件可选；缺省时跳过 MAP 违规检测，不报错。
