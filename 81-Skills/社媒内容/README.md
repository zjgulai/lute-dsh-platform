# mkt-social-content

社交媒体内容批量生成 Skill

## 功能

- Instagram 内容生成
- Facebook 内容生成
- LinkedIn 专业内容
- Twitter/X 短内容
- TikTok 脚本

## 使用场景

- 品牌社媒矩阵运营
- 多平台内容分发
- 内容日历规划
- 短视频内容生产

## 触发方式

当用户提及以下关键词时触发：
- "社媒内容"
- "Instagram 帖子"
- "TikTok 脚本"
- "内容日历"
- "社媒运营"

## 输入要求

- 品牌调性与视觉指南
- 产品卖点与故事
- 目标受众画像
- 平台选择

## 输出交付物

- 平台适配内容
- 内容日历模板
- 短视频脚本
- Hashtag 策略
