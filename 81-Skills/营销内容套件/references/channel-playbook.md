# 渠道打法手册（Channel Playbook）

按渠道拆分同一卖点的差异化写法，避免各平台内容雷同。生成营销内容时优先参考本手册。

## 广告（Facebook / Instagram Ads / Google）

- 结构：一句话钩子 → 核心卖点 → 行动号召（CTA）
- 字数：标题 ≤ 40 字符，正文 90-125 字符
- 钩子类型：痛点（「跑一半没电？」）、利益（「12 小时续航」）、好奇（「户外人都在用」）
- 每版出 2-3 个变体做 A/B 测试
- 禁忌：标题堆砌多个卖点、无 CTA、照搬社媒口语

## 社媒（Instagram / TikTok / 小红书）

- 结构：视觉描述 + 短文案 + Hashtags
- 语气：平台原生气（小红书种草口吻、TikTok 快节奏、Instagram 视觉导向）
- Hashtags：品牌词 1 + 品类词 2 + 场景词 2
- 禁忌：广告腔、长段落、无视觉描述

## 邮件（Email 序列）

- 序列：欢迎信 → 产品故事 → 限时优惠 → 用户证言
- 每封：一个主题、一个 CTA、可扫读（短段落 + 要点）
- 主题行：≤ 50 字符，制造打开理由
- 禁忌：一封塞多个目标、无退订/合规声明

## 落地页（Landing Page）

- 结构：主标题（唯一卖点）→ 副标题 → 三点支撑 → CTA → 信任元素
- 单一转化目标，避免多 CTA 分散
- 禁忌：卖点堆砌、缺 CTA、正文过长

## 视频脚本（Video Script）

- 前 3 秒钩子 + 卖点演示 + 结尾 CTA
- 15 秒短脚本：一个卖点一个脚本
- 禁忌：把广告文案直接当旁白念
