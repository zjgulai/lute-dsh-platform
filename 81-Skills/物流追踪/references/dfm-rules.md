# 多承运商单号格式识别规则 (DFM Rules)

> 用于当用户只给单号没给承运商时，推断承运商的具体规则。

## 单号格式 → 承运商推断表

| 单号特征 | 承运商 | 置信度 | 说明 |
|----------|--------|--------|------|
| `1Z` + 16位（18位总长） | UPS | 高 | UPS 标准 tracking number |
| 10位纯数字 | DHL | 中 | DHL Express 常见格式 |
| `SF` 开头 + 12位数字 | 顺丰 | 高 | 顺丰国际件 |
| `YT` 开头 | 圆通 | 高 | 圆通运单 |
| 12位纯数字（如976...） | 中国邮政/EMS | 中 | 需进一步确认 |
| `LN` 开头 + `CN` 结尾 | 中国邮政国际挂号 | 高 | 国际小包，末端由目的国邮政派送 |
| `CJ`/`YT` 国际件 | 递四方/云途 | 中 | 跨境路线 |

## 推断规则

1. **先声明推断依据**：当用户只给单号没给承运商时，先说「根据单号格式，这可能是 X 的运单」，再请求确认。
2. **置信度低时追问**：无法高置信度推断时，追问承运商，不猜测。
3. **中英混写单号**：支持 `tracking number`、`shipment`、`delivery status` 等说法，不影响识别。

## 疑点与边界

- `LN...CN` 单号是邮政挂号小包，出关后轨迹更新慢，需提示用户追踪信息可能延迟。
- 单号可能含字母大小写，统一转大写处理。
