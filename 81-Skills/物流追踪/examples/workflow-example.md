# 物流追踪工作流示例

## 场景：客服查询客户包裹状态

### 用户输入
```
客户问：我的包裹到哪了？单号 SF9876543210，昨天发的顺丰。
```

### 工作流
1. 识别：单号 SF9876543210，承运商顺丰（SF 开头格式高置信）
2. 追踪：解析单号格式 → 确认为顺丰国际件
3. 输出：状态/轨迹/ETA/异常预警

### 输出示例
```
## 物流追踪

### 信息
- 承运商: 顺丰
- 单号: SF9876543210
- 发货: 深圳（昨日）

### 状态
- 当前: 运输中
- 位置: 广东省内转运中心
- 预计到达: 明日

### 轨迹
- 已揽收 - 深圳
- 运输中 - 转运中心

### 无异常
```

## 场景：批量监控在途补货

### 用户输入
```
帮我监控今天在途的5个运单，看看哪几个快到了，哪几个有延误。
单号: SF1001, SF1002, YTO3001, 1Z999AA10123456784, LN123456789CN
```

### 工作流
1. 逐单解析单号格式
2. 按承运商分组
3. 汇总：即将到达/正常在途/延误风险

### 输出要点
- 优先标出「即将到达」（可安排接收）
- 标出「延误风险」并给出建议
- 逐单列出状态和ETA
