# CRO Playbook — LIFT 模型、样本量与失败案例

本文件在用户需要做 A/B 测试设计、统计判断或方法论落地时查阅（渐进式披露第三层）。

## 1. LIFT 模型落地顺序

LIFT（LIFT = Value Proposition / Relevance / Clarity / Urgency / Anxiety / Distraction）是着陆页优化六大杠杆。落地时按杠杆排序，避免只调低杠杆元素：

| 优先级 | 杠杆 | 核心问题 | 常见动作 |
|---|---|---|---|
| P0 | Value Proposition | 用户 5 秒内能否理解「为什么选你」 | 主标题改为具体价值主张 |
| P0 | Clarity | 信息和下一步行动是否清晰 | CTA 文案具体化（"免费试用14天" vs "提交"） |
| P1 | Relevance | 页面与流量来源意图是否匹配 | 广告词与落地页首屏一致 |
| P1 | Anxiety | 用户有何顾虑未消除 | 添加社会证明、退款保证、隐私说明 |
| P2 | Urgency | 是否有合理紧迫感 | 真实限时优惠（禁用虚假倒计时） |
| P2 | Distraction | 有无干扰元素 | 移除与主 CTA 无关的弹窗/链接 |

## 2. A/B 测试统计判断

- **显著性门槛**：95% 置信区间（p < 0.05），建议每变体 ≥ 100 次转化、测试周期 ≥ 2 周（覆盖周内波动）。
- **最小可检测效应（MDE）**：测试前按基线转化率 p0 与预期提升估算样本量：

  ```
  n ≈ 16 * p0 * (1 - p0) / (MDE/2)^2   （每变体，95% 置信、80% 功效的近似）
  ```

  例：基线转化率 3%（p0=0.03），想检测到 20% 相对提升（MDE=0.006），每变体约需
  n ≈ 16 * 0.03 * 0.97 / (0.003)^2 ≈ 51700 次访问——样本不足的「涨了 5%」结论不可信。

- **测试停止规则**：达到预注册样本量才读结果；禁止「边看边停」的窥视式决策（peeking）。

## 3. 常见失败案例（踩雷点）

1. **CTA 改色测试**：90% 的按钮颜色/圆角微调无显著差异——先验证价值主张与信任元素，再动文案颜色。
2. **多变量同时改**：一次改 5 处导致无法归因——每轮只测一个变量。
3. **样本不足提前下结论**：流量小（日访问 < 1000）却一周就「改版」，实为噪声。
4. **以牺牲体验换转化**：欺骗性倒计时、隐藏退订、强制注册墙短期提升、长期流失与投诉。
5. **忽略移动端**：桌面端数据好但移动端（占 60%+ 流量）转化差，优化方向跑偏。
