# 完整示例：SaaS 注册页转化率优化（诊断 → 假设 → 实验 → 结果解读）

本示例演示一个完整 CRO 循环，供写优化建议/报告时参考。

## 场景

某 SaaS 产品注册页：访问 → 注册转化率 3.2%，行业基准 6%。用户主要从 Google 搜索「团队协作工具」进入。

## 第一步：诊断（LIFT）

- **Value Proposition**：首屏主标题「新一代协作工具」太泛，5 秒内无法理解差异。
- **Clarity**：CTA 是「提交」，未说明注册后能得到什么。
- **Anxiety**：无客户 logo、无隐私说明，新用户不敢填邮箱。
- **Relevance**：广告词是「免费团队项目管理」，落地页首屏却在讲「全平台协作」，不一致。

## 第二步：假设（可测试）

- H1：把主标题改为「5 人以下团队免费的项目管理工具」→ 注册转化率提升 15%。
- H2：CTA 从「提交」改为「免费开始，无需信用卡」→ 注册转化率提升 8%。
- H3：首屏加入 3 个客户 logo + 「已服务 20000+ 团队」→ 注册转化率提升 5%。

## 第三步：实验设计（样本量）

基线 3.2%，预期 H1 相对提升 15%（MDE=0.0048），每变体约需
n ≈ 16 × 0.032 × 0.968 / (0.0024)^2 ≈ 86000 次访问；按日访问 6000，需约 2 周。

## 第四步：结果解读

- 变体 A（原版）转化率 3.1%，变体 B（H1 改标题）转化率 4.0%：p=0.02，达显著，相对提升 29%，超预期。
- 结论：采用变体 B，并进入下一轮测试（H2 CTA 文案）。
