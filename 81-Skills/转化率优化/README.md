# mkt-cro-optimization

转化率优化（CRO）Skill

## 功能

- 着陆页优化
- 转化漏斗分析
- A/B 测试方案
- 用户行为优化建议

## 使用场景

- 着陆页转化率提升
- 结账流程优化
- 用户流失分析
- CRO 实验规划

## 触发方式

当用户提及以下关键词时触发：
- "CRO 优化"
- "转化率提升"
- "着陆页优化"
- "转化漏斗"
- "A/B 测试"

## 输入要求

- 当前转化数据
- 页面/流程截图
- 用户行为数据
- 竞品参考

## 输出交付物

- 着陆页优化建议
- 转化漏斗分析报告
- A/B 测试方案
- 优化优先级清单
