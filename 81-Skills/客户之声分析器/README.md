# cbec-customer-voice-analyzer

整合多平台用户反馈（Amazon评论、Reddit、TikTok、YouTube、Facebook等），生成可执行的改品、文案和竞品策略洞察。当用户提及"VoC"、"客户之声"、"评论分析"、"用户痛点"、"竞品反馈"、"改品方向"或需要跨平台用户声音分析时使用。 触发词：VoC、客户之声、评论分析、用户痛点、竞品反馈、改品方向。 

## 快速开始

查看 [SKILL.md](./SKILL.md) 获取完整使用指南。
