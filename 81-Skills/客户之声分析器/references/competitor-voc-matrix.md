## 「遗憾空间」判定法

**重点不是「谁更好」，而是找到：**

1. **行业共痛点**：所有竞品都被抱怨，但没人真正解决的问题。判定：≥3 个品牌在该主题上均有负面反馈，且强度 ≥ 中等。
2. **Momcozy 独有优势**：只有 Momcozy 被表扬，竞品未被提及或负面。判定：正面反馈集中且无竞品正面提及。
3. **Momcozy 暂时缺位**：竞品被表扬但 Momcozy 未被提及。判定：竞品在该主题有 ≥2 条正面反馈，Momcozy 0 条。
4. **可追平窗口**：竞品有负面但 Momcozy 暂无负面，且 Momcozy 有技术或配件方案可快速改进。判定：竞品负面 ≥2 条，Momcozy 负面 0 条，且有可执行改品路径。
