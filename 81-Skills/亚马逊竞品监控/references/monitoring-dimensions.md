# 竞品监控维度参考

竞品监控报告的各维度指标与判定口径。分析竞品数据时按本表口径执行，避免口径不一致。

## 1. 价格

| 指标 | 口径 | 判定 |
|------|------|------|
| 当前售价 | 竞品 ASIN 前台挂牌价（非划线价） | — |
| 价格变动 | 当前价 vs 上次快照价 | 涨跌 ≥5% 记为显著变化 |
| 最低价 / Buy Box 价 | 购物车实际成交价 | 低于挂牌价说明有隐藏 Coupon/Deal |
| 降价动机归因 | 清库存 / 抢 Buy Box / 新品铺量 | 决定是否跟进 |

## 2. 评价

| 指标 | 口径 | 判定 |
|------|------|------|
| 评价总数 | Review 数 | 短期激增（如 +55/周）常与促销或刷单相关 |
| 星级 | 均值（保留 1 位小数） | 结合评价增量判断口碑真实走向 |
| 差评关键词 | 近期 1-2 星高频词 | 识别对方质量/服务波动 |

## 3. 排名

| 指标 | 口径 | 判定 |
|------|------|------|
| BSR（大类/小类） | 竞品 Best Sellers Rank | 波动大说明销量或流量剧烈变化 |
| 关键词排名 | 核心词自然位 | 结合广告投放判断是否加投 |

## 4. 促销

| 指标 | 口径 | 判定 |
|------|------|------|
| Deal 类型 | Lightning Deal / Coupon / 秒杀 / 会员折扣 | 标注折扣力度与起止时间 |
| 折扣力度 | 现价 / 原价 | 记录对销量的可能影响 |

## 5. Buy Box

| 指标 | 口径 | 判定 |
|------|------|------|
| Buy Box 归属方 | 购物车卖家 | 谁主导购物车 |
| 购物车份额 | 我方 vs 竞品 | 份额下滑需标注原因（价格 / 时效 / 库存） |
| 隐性维度 | 配送时效、FBA 库存、账户绩效 | 购物车争夺不仅看价格 |

## 判定提醒

- 竞品降价不孤立判断：先归因（清库存 / 抢 Buy Box / 新品铺量）再决定跟进。
- 应对建议必须把「库存水位」纳入：盲目跟价却未补货，易断货丢排名。
