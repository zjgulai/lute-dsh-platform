# 完整示例：亚马逊竞品监控报告

## 输入

用户提供两个快照的竞品数据（JSON）：

```json
{
  "asin": "B08N5WRWNW",
  "current": {"price": 24.99, "reviews": 1289, "rating": 4.2, "bsr": 1820, "buy_box_owner": "我方"},
  "previous": {"price": 29.99, "reviews": 1234, "rating": 4.3, "bsr": 2110, "buy_box_owner": "竞品A"},
  "promotions": [{"type": "Lightning Deal", "discount": "16%", "active": true}]
}
```

## 分析过程

1. 价格：$29.99 → $24.99，降幅 16%，超过 5% 阈值，记为显著降价。
2. 评价：1,234 → 1,289（+55），增速快，结合星级 4.3 → 4.2 判断，疑似促销带量或轻微口碑下滑。
3. 排名：BSR 2110 → 1820，排名上升，说明销量/流量走强。
4. Buy Box：购物车由「竞品A」转回「我方」，我方配送时效或价格更优。
5. 促销：竞品已启动 Lightning Deal，折扣 16%。

## 输出报告

```
## 竞品监控报告

### ASIN: B08N5WRWNW
- 价格: $29.99 → $24.99 (降价16%)
- 评价: 1,234 → 1,289 (+55)
- 星级: 4.3 → 4.2
- 排名: BSR 2110 → 1820（上升）
- Buy Box: 竞品A → 我方
- 动作: 竞品已启动 Lightning Deal

### 建议
1. 评估是否跟进降价（竞品为清库存/抢购物车，非新品铺量）
2. 检查我方库存水位，避免跟价后断货丢排名
3. 结合配送时效与 FBA 库存，维持 Buy Box 优势
4. 继续观察竞品 Deal 结束后的价格回弹与评价走向
```

## 边界处理

- 若只给了「价格」一个维度：只出价格变动报告，其余维度标注「数据缺失」。
- 若竞品 ASIN 缺失：不臆造，先追问 ASIN 列表。
