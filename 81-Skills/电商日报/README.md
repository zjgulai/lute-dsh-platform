# ecom-daily-report

电商日报/周报自动生成工具，输入1-7天订单CSV，输出日常经营报告。

## 快速开始

```bash
# 生成日报
使用 ecom-daily-report: 生成昨日经营日报

# 生成周报
使用 ecom-daily-report: 生成本周周报

# 异常监控
使用 ecom-daily-report: 检查销售异常
```

## 功能特性

- **日报生成**: 当日销售额、订单量、客单价、环比对比
- **周报汇总**: 周度核心指标、趋势分析、目标进度
- **异常预警**: 销售额/订单量/客单价异常波动检测

## 输入要求

- 1-7天订单CSV文件
- 标准字段：订单号、日期、金额、SKU、数量

## 输出内容

- 日报/周报文本报告
- 关键指标摘要
- 异常预警提示
- 环比数据对比

## 依赖

- 父技能: ecom-main-hub
- 相关技能: ecom-csv-processor, ecom-monthly-review
