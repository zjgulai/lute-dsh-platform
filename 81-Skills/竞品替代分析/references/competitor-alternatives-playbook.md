# 竞品替代分析与差异化定位实战手册

本文件是 `竞品替代分析` 技能的渐进式披露第二/三层，仅在需要落地竞品对比矩阵、替代方案矩阵、差异化定位声明与竞争话术时读取。

## 1. 竞品对比矩阵模板

| 维度 | 我们 | 竞品A | 竞品B | 竞品C |
|------|------|-------|-------|-------|
| 目标客群 | | | | |
| 定价（含档位） | | | | |
| 核心功能 1 | | | | |
| 核心功能 2 | | | | |
| 差异化能力 | | | | |
| 主要短板 | | | | |
| 迁移成本 | | | | |
| 适用场景 | | | | |

填写规则：
- 每格必须基于事实或明确标注"（假设，待核实）"。
- 差异化能力列是后续定位声明的输入，至少提炼 1 条"竞品做不到、我们能做且用户在乎"的能力。

## 2. 替代方案矩阵模板

| 场景 | 竞品X 的问题 | 我们的替代价值 | 迁移路径 | 迁移成本 |
|------|-------------|--------------|---------|---------|
| | | | | |

用于"从竞品A迁移到我们"的说服场景。迁移路径要写具体步骤（数据导出→导入→对账→并行运行→切换），迁移成本要量化（人力/时间/资金）。

## 3. 差异化定位声明公式

```
对于[目标用户]来说，[产品名]是[品类]中唯一能[独特价值]的解决方案，
不同于[竞品]，我们[关键差异]。
```

反共识锚点（用于找出"只有我们这么想"的定位）：
- 竞品都在强调的（功能堆砌/低价/大而全）→ 反着走。
- 用户真正痛苦但无人解决的 → 作为 UVP。
- 一句话说不清的价值 → 不是定位，返回重构。

## 4. 竞争话术库

### 销售异议处理（"你们和竞品B比怎么样"）
1. 先确认客户在比什么维度（价格/功能/服务/集成）。
2. 只在对方真实在意的维度上比较，不全面贬低竞品。
3. 用"我们的差异化 + 一个客户案例"替代功能罗列。

### 竞品提及应对
- 客户说"竞品B 只要半价"→ 转向总拥有成本（TCO）+ 迁移成本 + 长期收益。
- 客户说"竞品B 功能更多"→ 转向"你实际用到的功能" + 简洁性价值。

### 正面比较话术（禁忌）
- 禁止造谣竞品、禁止泄露竞品内部数据。
- 比较必须可被公开资料佐证，标注信息来源与日期。

### 迁移说服策略
1. 量化现状的隐性成本（竞品订阅 + 维护 + 低效）。
2. 展示替代后的收益（时间/成本/能力）。
3. 提供分阶段迁移降低风险。
4. 给出明确下一步（试用/数据导入/对账）。

## 5. 输出契约

每次交付至少包含：
1. 竞品对比矩阵（或替代方案矩阵）。
2. 一句差异化定位声明。
3. 一套可直接使用的竞争话术（3-5 条）。
4. 结论 + 下一步建议。

信息不足时按 SKILL.md「错误处理」返回追问，禁止硬编数据。
