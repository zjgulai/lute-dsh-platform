# 竞品替代分析

竞品替代方案与差异化定位 Skill（英文 slug：mkt-competitor-alternatives）

## 功能

- 竞品分析
- 替代方案矩阵
- 差异化定位策略
- 竞争话术生成

## 使用场景

- 竞品对标分析
- 差异化定位声明
- 销售话术准备
- Alternative-to 页面创建

## 触发方式

当用户提及以下关键词时触发：
- "竞品分析"
- "竞品替代"
- "差异化定位"
- "竞争对比"
- "alternative-to"

## 输入要求

- 主要竞品列表
- 自身产品特点
- 目标市场定位
- 竞品优劣势

## 输出交付物

- 竞品分析矩阵
- 差异化定位声明
- 竞争话术脚本
- Alternative-to 页面文案

## 资源文件

- `references/competitor-alternatives-playbook.md`：对比矩阵/替代矩阵/定位声明/话术模板（正文点名，按需读取）。
- `examples/full-example.md`：端到端完整示例（正文点名，按需读取）。
- `scripts/run.py`：自包含脚手架 CLI（`python run.py --product ... --competitors ...`），不依赖 skills._shared。
