# 端到端示例：从竞品分析到竞争话术

## 场景

我们「明镜项目协作 SaaS」（面向 10-100 人团队）对标两家竞品：
- 竞品A「TeamPro」：功能全、价格高（$49/用户/月）、面向 100+ 人企业。
- 竞品B「LightTask」：便宜（$9/用户/月）、功能少、面向个人/小团队。

## 输入

- 自身产品：明镜，$19/用户/月，核心功能=项目看板 + 目标对齐（OKR）+ 自动化报表。
- 目标客户：10-100 人成长型团队，需要"轻量但能对齐目标"的协作工具。
- 竞品优劣势：TeamPro 功能全但复杂贵；LightTask 便宜但缺目标对齐与报表。

## 产出

### 1. 竞品对比矩阵

| 维度 | 明镜 | TeamPro | LightTask |
|------|------|---------|-----------|
| 目标客群 | 10-100人成长型团队 | 100+人企业 | 个人/小团队 |
| 定价 | $19/用户/月 | $49/用户/月 | $9/用户/月 |
| 项目看板 | ✓ | ✓ | ✓ |
| 目标对齐（OKR） | ✓ | ✓ | ✗ |
| 自动化报表 | ✓ | ✗ | ✗ |
| 学习成本 | 低 | 高 | 低 |
| 迁移成本 | 低 | 中 | 低 |

### 2. 差异化定位声明

对于 10-100 人的成长型团队来说，明镜是项目协作工具中唯一能"同时把目标对齐（OKR）和自动化报表做进一套看板"的解决方案，不同于 TeamPro 的昂贵复杂、LightTask 的缺失目标管理，我们用 $19/用户/月 提供企业级目标对齐能力。

### 3. 竞争话术（3 条）

- 客户说"TeamPro 功能更多"→ "TeamPro 确实全，但成长型团队常用的 80% 功能里，我们覆盖了核心部分，并把目标对齐和报表做到开箱即用，学习成本低一半；您实际用到哪些功能我可以逐条对齐。"
- 客户说"LightTask 只要 $9"→ "LightTask 便宜，但它没有目标对齐和报表，团队一扩张就得换工具、重新迁移。我们把迁移工具做成内置，一次导入即可，总成本反而更低。"
- 客户说"你们和 TeamPro 比怎么样"→ "我们更聚焦成长型团队：不堆功能，把 OKR 对齐和自动化报表做进看板，价格是 TeamPro 的 38%。"

### 4. 结论与下一步

- 结论：差异化锚点=「轻量 + 目标对齐 + 自动化报表」，主攻 TeamPro 的"贵而复杂"与 LightTask 的"缺目标管理"缝隙。
