# 趋势阶段分析 · 参考手册

与 `SKILL.md` 配套使用：信号表、工具目录、报告结构与研究例行。语境默认含 **母婴跨境（如 Momcozy）**、**Amazon 美欧 + Shopify DTC**、竞品参照 **Elvie / Willow / Medela / Haakaa / KeaBabies**。

---

## 一、广告平台研究方法

### 1.1 TikTok Creative Center

| 动作 | 做法 |
|------|------|
| 定关键词 | 用英文/当地语产品词、场景词（如 hands free、pump、mom），避免只搜品牌词 |
| 看创意池 | 相关视频量、是否反复出现同一产品形态 |
| 看时间 | 高播放素材首次出现时间与仍在投放的「老素材」比例 |
| 看表达 | 卖点是否从「新奇」变成「比价、平替、避雷」 |

### 1.2 Facebook Ad Library

| 动作 | 做法 |
|------|------|
| 筛地区/语言 | 与目标市场一致（如 US、UK） |
| 搜关键词 | 产品词 + 类目词；必要时搜竞品品牌名观察「跟投」密度 |
| 存档 | 截图或导出时在笔记中记录**查询日期**与**关键词** |

### 1.3 广告信号汇总表

| 信号 | TikTok 侧重 | Meta 侧重 | 早期增长 | 峰值动能 | 饱和期 |
|------|-------------|-----------|----------|----------|--------|
| 在投广告量 | 创意中心相关量、爆款重复度 | 库内结果条数、同图多账户 | 相对少、增速快 | 多且仍更新 | 极多、模板化 |
| 广告主数 | 难以精确则用「品牌/店铺多样性」估 | 明确可看多 Page | 分散度中等 | 头部+腰部分散 | 大量小卖家同质化 |
| 创意多样性 | 场景、叙事差异大 | 素材类型、文案角度多 | 高 | 高→开始重复 | 低（同一痛点反复） |
| 素材寿命 | 新爆款更迭快 | 同一广告长跑天数多 | 新素材占比高 | 长跑证明 ROI | 长跑多+新素材难突围 |
| 落地页 | Shopify 店、亚马逊链接混杂 | 同上 | 粗糙与专业并存 | 品牌化页面增多 | 价格战落地页、夸张宣称增多 |

> 阈值勿机械套用：母婴类目合规严，广告量可能低于普货但仍已饱和；需结合 **电商与 Trends**。

## 二、电商平台研究信号表

### 2.1 Amazon（美/欧站点）

| 信号 | 数据来源/看法 | 早期增长 | 峰值动能 | 饱和期 |
|------|----------------|----------|----------|--------|
| 销售速度 | BSR、New Releases、大类排名变动 | 子类排名快速上升 | 头部稳定、中腰部仍轮动 | 头部固化、新品难进前页 |
| 竞品数量 | 搜索结果前 2–3 页有效 listing 数、同质化主图 | 有限 | 明显增多 | 高度同质、价格战 |
| 评论速度 | Keepa/手动跟踪评论数区间变化 | 加速 | 仍快但向头部集中 | 增速放缓或刷评嫌疑增多 |
| 价格压缩 | 主力价格带宽度、Coupon 密度 | 带宽、折扣适中 | 带收窄、促销频繁 | 低价锚点固化 |
| 品牌集中度 | 前 10 是否被少数品牌占据 | 分散 | 开始集中 | 极高 |

### 2.2 AliExpress（及同类批发端）

| 信号 | 看法 |
|------|------|
| 同款链接数与销量 | 激增常意味白牌供给涌入，靠近饱和 |
| MOQ 与发货地 | 极低 MOQ + 多仓发 → 进入门槛低 |
| 图片/文案同质化 | 与 Amazon 主图趋同 → 饱和信号增强 |

## 四、产品研究报告模板结构

建议输出为一份 Markdown 或文档，按序包含以下章节（标题可微调，逻辑勿缺）：

1. **摘要** — 阶段判断（早期 / 峰值 / 饱和）+ 结论档位（Go / Cautious / No-Go）+ 一句理由。  
2. **范围与假设** — 产品定义、市场、渠道、日期；未提供信息时的假设。  
3. **产品类型判定** — 趋势爆品 vs 长青畅销及对本品的含义。  
4. **证据表** — 列：**数据来源 | 观测事实 | 对阶段的含义**（至少两行来自不同大类：广告/电商/Trends/内容）。  
5. **Google Trends** — 12 月 + 5 年图的文字描述；区域；相关查询上升/下降解读。  
6. **竞争格局** — Amazon 与 DTC 侧头部与差异化空间；可点名竞品（如 Elvie、Willow、Medela 等）**仅作参照，避免不实销量宣称**。  
7. **盈利门槛** — 毛利率、广告占比假设与敏感性；未达标时的降级结论。  
8. **Shopify DTC 窗口** — 若适用：定位、素材测试计划、合规与信任背书清单、风险（退货、认证）。  
9. **下一步** — 7–14 天内可执行的验证动作（最小实验）。

## 五、日 / 周 / 月研究例行（最佳实践）

### 每日（约 15–30 分钟）

| 动作 | 目的 |
|------|------|
| 固定关键词刷 Meta Ad Library + 保存新增样本 | 捕捉投放潮与素材同质化 |
| 看核心 ASIN 的 BSR/价格是否异常跳动 | 察觉活动与价格战 |
| 记录当日结论一句 | 形成时间序列 |

### 每周（约 1–2 小时）

| 动作 | 目的 |
|------|------|
| TikTok Creative Center 与 YouTube 新评测扫一轮 | 内容侧是否转入「横评/避雷」 |
| Google Trends 对比上周同关键词 | 趋势拐点早期发现 |
| 更新「证据表」：新增/反转信号标红 | 支持阶段迁移判断 |

### 每月（约 2–4 小时）

| 动作 | 目的 |
|------|------|
| 复盘 5 年 Trends + 季节性 | 规划大促与备货节奏 |
| 抽查供应链端（AliExpress/1688）同款密度与报价 | 饱和与价格底认知 |
| 输出月度一页纸：阶段是否变更、结论档位是否需调整 | 对齐选品与投放会议 |

## 六、常见误判提醒（母婴跨境）

- **只看品牌词 Trends**：易把「品类饱和」误判为「仍增长」；需区分通用词、长尾词与品牌词。  
- **只看广告量**：合规限制会导致广告偏低；须结合 Amazon 自然位与评论现实。  
- **忽略退货与售后成本**：即使阶段「Go」，毛利率门槛仍可能不达标。  
- **忽略区域**：欧盟需单独看语言词、认证与竞品池，勿用美国数据直接外推。
