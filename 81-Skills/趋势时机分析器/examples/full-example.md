# 趋势时机分析器 · 端到端使用示例

本示例演示一次完整的趋势时机判断，展示从信号输入到结论输出的全流程。语境：Momcozy 母婴跨境，Amazon 美欧 + Shopify DTC，竞品参照 Elvie / Willow / Medela。

---

## 输入（用户提供）

> 我们 DTC 站上可穿戴吸奶器的页面访问量最近涨了 40%，但转化率没跟上；同时 Google Trends 显示这个品类搜索也在涨。帮我判断现在该追还是该等。

同时用户提供的私有信号：
- 客服里「静音泵」「医院级吸力」问题增多
- 社群出现「夜里泵奶不吵醒宝宝」的讨论

## 输出（趋势时机分析器生成）

### 1. 分析对象

```text
品类：可穿戴吸奶器（wearable breast pump）
子趋势组合：可穿戴 + 静音夜间使用；可穿戴 + 医院级吸力平价化
市场：北美（美国为主）
渠道：Amazon + Shopify DTC
```

### 2. 信号拆解

```text
公开趋势：
- Google Trends 搜索量仍在涨但增速放缓
- Amazon listing 数量持续增加、高度同质化
- TikTok 热度仍在，但内容开始转向「比价/避雷」

私有先行指标：
- DTC 页面访问涨 40%，转化未跟上（需求在涨、承接待优化）
- 客服「静音」「医院级吸力」问题增多（付费意愿前兆）
- 社群「夜吸不吵醒宝宝」讨论自发起势

竞品动作信号：
- Elvie/Willow 招 PM、加大 Meta 广告，集中讲 hospital-grade suction
- Medela 提交静音泵专利、JD 提 wearable + quiet operation
```

### 3. 阶段判断

| 层级 | 判断 | 说明 |
|------|------|------|
| 品类层 | 增长尾段/平台期 | 大盘仍在涨但红利递减，头部格局固化 |
| 子趋势层 | 静音夜间：早期窗口 | 需求自发起势，供给端尚未把「静音」当主心智 |
| Amazon 层 | 红海但可差异化 | 搜索充分教育，需静音场景切入 |
| DTC 层 | 适合先行验证 | 可更早拿到场景付费意愿信号 |

### 4. 时机建议

```text
结论：结构性跟进，静音夜间子趋势立即试探
为什么现在是/不是窗口：大盘不是「闭眼进」的黄金窗口，但静音夜间属于需求领先供给的早期窗口，竞品尚未占位
更适合从哪个渠道试：DTC 先行验证「静音夜吸」场景付费意愿，验证后回灌 Amazon 做差异化承接
下一步最小验证动作：拉近 30 天 DTC 站内搜索词+客服高频词，确认「静音/夜间」词持续上涨后，投一小批静音场景定向内容/广告测 CTR 与转化
```

---

## 关键判断要点回顾

1. **私有信号优先于公开信号**：DTC 访问、客服问答、社群讨论比 Google Trends 更早
2. **大品类 vs 子趋势拆解**：真正的时机在「可穿戴 + 静音夜间」这个子组合，而非「可穿戴吸奶器」大品类
3. **竞品动作是领先指标**：招聘、专利、广告话术转向比搜索量更早
