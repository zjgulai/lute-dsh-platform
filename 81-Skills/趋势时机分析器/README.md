# cbec-trend-timing-analyzer

判断品类或子趋势应该立即进入、延后观察还是避免跟进，结合公开趋势与 Momcozy 私有先行指标。当用户提及"趋势阶段"、"入场时机"、"生命周期"、"什么时候进入"、"趋势分析"或需要时机判断决策时使用。 触发词：趋势阶段、入场时机、生命周期、什么时候进入、趋势分析。
