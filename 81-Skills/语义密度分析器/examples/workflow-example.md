# 完整工作流示例

从输入到输出的端到端演示：评估一段技术文档的知识密度。

## 输入

用户提供 5 个文本块（节选自技术文档）：

```json
{
  "chunks": [
    {"id": "chunk_1", "content": "分布式一致性是分布式系统的核心问题。为了保证数据一致性，系统需要在多个副本之间协调状态。", "language": "zh"},
    {"id": "chunk_2", "content": "Paxos 算法通过两阶段提交（Prepare/Promise 与 Accept/Accepted）来达成多数派一致。关键公式：quorum = floor(N/2) + 1。", "language": "zh"},
    {"id": "chunk_3", "content": "Raft 将一致性拆解为三个子问题：领导者选举、日志复制、安全性。相比 Paxos 更易理解。", "language": "zh"},
    {"id": "chunk_4", "content": "总之，在实际工程中要根据网络分区概率选择合适的共识算法。", "language": "zh"},
    {"id": "chunk_5", "content": "这段话是填充性的过渡说明，没有实质信息。", "language": "zh"}
  ],
  "config": {"language": "zh", "calibrate": true, "visualize": true}
}
```

## 阶段 1：NLP 特征提取

| 文本块 | 逻辑密度 | 实体密度 | 结构密度 |
|--------|---------|---------|---------|
| chunk_1 | 0.42 | 0.35 | 0.00 |
| chunk_2 | 0.55 | 0.72 | 0.30 |
| chunk_3 | 0.50 | 0.48 | 0.30 |
| chunk_4 | 0.60 | 0.28 | 0.00 |
| chunk_5 | 0.20 | 0.15 | 0.00 |

## 阶段 2-3：基础评分 + LLM 校准

分层采样（样本数不足 15，取全部 5 个）→ LLM 评分 → 线性回归。

校准后权重：w_logic=0.32, w_entity=0.41, w_struct=0.27, r²=0.86。

## 阶段 4：最终评分

| 文本块 | 综合密度 | 判定 |
|--------|---------|------|
| chunk_2 | 0.68 | 🔴 高密度（核心知识+公式）|
| chunk_3 | 0.52 | 🟡 中密度（解释说明）|
| chunk_1 | 0.35 | 🟢 低密度（背景信息）|
| chunk_4 | 0.33 | 🟢 低密度（过渡总结）|
| chunk_5 | 0.12 | ⚪ 填充文本 |

## 输出

- **最高密度块**：chunk_2（含 quorum = floor(N/2)+1 公式，优先提取为 SKU）
- **热力图**：文档走向分布显示中段知识密度最高
- **建议**：chunk_2/chunk_3 纳入 RAG 索引，chunk_5 可裁剪
