# 密度评估判定规则（DFM Rules）

本文件定义语义密度分析器的触发判定规则，用于路由竞争场景的边界判断。

## 触发规则（应触发语义密度分析器）

主意图为**评估文本的知识密度**时触发：

- 用户要求评估文档/段落的「知识密度」「语义密度」「信息密度」
- 用户要求生成知识热力图、密度评分、密度排名
- 用户提到 RAG 内容筛选中需要识别「高价值内容区域」
- 用户需要优化知识提取策略（密度高的区域多提取）
- 用户要求长文档关键内容定位

## 不触发规则（路由到相邻技能）

| 用户真实意图 | 路由到 | 判定关键词 |
|------------|--------|-----------|
| SKU 标签分组 | 语义分桶器 | 分桶、分组、Union-Find、标签重叠 |
| 文档按语义边界分块 | 语义文档分块器 | 分块、章节拆分、保持段落完整 |
| 知识单元相似度/重复检测 | 知识相似度分析器 | Anchor/Logic/Outcome、重复、冲突 |
| 锚点精确分割 | 锚点文本分割器 | 锚点、模糊匹配、OCR 容错 |
| SEO 关键词密度 | SEO内容优化 | 关键词密度、Title/Meta、内链 |
| 书籍深度阅读萃取 | 知识萃取专家 | 读书、萃取、思维模型、精华 |
| 评论情感分析 | VOC情感分析器 | 情感、评论、痛点、VOC |

## 核心区分原则

「密度」是模糊词，需要区分：

1. **知识密度（本 Skill）**：逻辑/实体/结构三维度，评估信息含量
2. **关键词密度（SEO）**：词频统计，评估 SEO 排名
3. **SKU 密集度（分桶器）**：标签重叠，用于分组

主意图判定优先于关键词匹配。句子中出现「密度」但真实意图是分组/分块/相似度时，路由到对应相邻技能。

## 边界情况处理

- 文档 < 1000 tokens：不触发，直接阅读即可
- 空文本/纯代码：不触发，追问是否需要其他帮助
- 未指定语言：触发后追问确认 zh/en
- 样本数 < 10：触发后提示跳过 LLM 校准
- 多 Skill 冲突（先分块再密度）：追问明确先后顺序，由主导技能接入
