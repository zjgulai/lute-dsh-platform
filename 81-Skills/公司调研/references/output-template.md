# Output Template

## 1. Executive Summary

不超过 200 字，回答：

- 它是谁。
- 当前处于什么状态。
- 为什么现在值得关注。

## 2. Results

字段格式：

```text
field | value | source | tier | quote | confidence
```

必选字段组：

- 基础信息：公司名、官网、成立时间、总部、员工规模。
- 业务与产品：主营业务、核心产品、客户、定价、商业模式。
- 财务与融资：融资历程、最新估值、营收或增长线索。
- 团队与治理：创始人、高管、股东、董事会。
- 竞争与市场：主要竞品、差异化、市场规模、市场阶段。
- 风险与负面：诉讼、监管、处罚、召回、合规、负面舆情。
- 近期动态：近 12 月重大事件、产品发布、合作、组织变化。

## 3. Analysis

按深度选择框架：

- L2：SWOT。
- L3：SWOT + Five Forces + BMC 中至少 2 个。
- L4：SWOT + Five Forces + BMC + PEST + value chain 中至少 4 个。

每个框架必须附关键发现。

## 4. Insights

每条洞察使用：

```text
事实：
推理：
结论：
影响：
```

## 5. Sources

```text
[1] URL - T1/T2/T3/T4 - 用于哪些字段
```

## 6. Notes

- 数据冲突与仲裁。
- 信息缺口。
- 反向观点。
- 需要二次核实事项。
- 未采用来源及原因。
