# 供应链主控 - 季度供应链规划示例

## 场景：Q4 季度供应链规划

### 背景
- 公司：跨境电商母婴品牌 Momcozy
- 季度：2026 Q4（10-12月）
- 关键节点：双十一(11.11)、黑五(11.28)、圣诞(12.25)

### 协调器整合方案

**一、库存维度**
- 双十一备货：按去年同期 1.3x 倍数，备货 500万
- 黑五备货：美国仓备货 200万，欧洲仓 100万
- 圣诞补货：12月中旬前完成最后一轮补货
- 安全库存：日常 30天，大促前 45天

**二、供应商维度**
- 主力供应商产能利用率：Q4 预计 85%
- 需新增 1-2 家备选供应商应对峰值
- 供应商合同续签：Q3 完成 3家主力供应商续约
- 1688 新供应商开发：9月完成准入评估

**三、物流维度**
- 海运优先：10月中旬前完成大促备货到仓
- 空运应急：预留 10% 预算应对突发补货
- 多仓分布：美国仓 60%，欧洲仓 25%，日本仓 15%
- 承运商选择：DHL(时效优先) + 海运(成本优先) 双线并行

**四、风险评估**
- 库存风险：暖冬可能导致保暖品类滞销 → 设置 15% 弹性库存
- 供应商风险：限电/疫情可能导致产能波动 → 提前锁定产能
- 物流风险：旺季运费上涨 20-30% → 提前订舱锁定价格
- 汇率风险：人民币升值影响利润 → 供应商结算币种协商

**五、关键里程碑**
| 时间 | 里程碑 | 负责角色 |
|------|--------|---------|
| 9月15日 | 完成Q4需求预测 | 库存预测专家 |
| 9月30日 | 完成供应商产能确认 | 供应商评估专家 |
| 10月15日 | 大促备货到仓 | 物流路线专家 |
| 11月1日 | 双十一启动 | 全角色协同 |
| 11月20日 | 黑五备货到仓 | 物流路线专家 |
| 12月15日 | 圣诞最后一轮补货 | 库存预测专家 |
