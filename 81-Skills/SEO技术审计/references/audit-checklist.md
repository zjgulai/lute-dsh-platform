# 技术SEO审计检查清单

按电商/品牌站优先级的完整审计检查清单。审计时按 P0 → P1 → P2 顺序逐项检查，输出问题优先级清单。

## P0（会直接掉流量，立即处理）

- [ ] **noindex 误留**：改版/迁移后是否残留 `noindex` 标签或 `X-Robots-Tag: noindex`
- [ ] **robots.txt 误封**：是否误封了核心目录/关键页面（`Disallow: /` 等）
- [ ] **301 链断裂**：旧 URL 重定向目标是否 404 / 是否重定向到不相关页面
- [ ] **canonical 自指错位**：canonical 是否指向错误 URL / 是否与页面 URL 冲突
- [ ] **关键页面 404**：核心落地页/类目页是否返回 404
- [ ] **重复内容**：参数 URL、`www`/非 `www`、HTTP/HTTPS 是否产生重复页面

## P1（影响体验与排名，本周处理）

- [ ] **Core Web Vitals 超标**：LCP > 2.5s、CLS > 0.1、INP > 200ms
- [ ] **首屏资源过大**：Hero 图片 > 300KB、未做懒加载
- [ ] **阻塞渲染资源**：未使用的 JS/CSS 阻塞首屏
- [ ] **sitemap 不完整**：sitemap 遗漏新页面 / 含 404 页面
- [ ] **孤立页面**：有页面无内部链接指向
- [ ] **移动适配**：视口缺失、触控目标 < 48px、字体过小

## P2（长期健康，本月处理）

- [ ] **URL 层级过深**：平均 > 3 层
- [ ] **面包屑缺失**：类目页/详情页无面包屑导航
- [ ] **缓存策略缺失**：未启用浏览器缓存
- [ ] **第三方脚本阻塞**：GTM 等第三方脚本未异步加载
- [ ] **爬虫预算浪费**：低价值 URL 消耗抓取配额

## 审计引擎选择

| 引擎 | 何时用 | 降级 |
|------|--------|------|
| lighthouse | 需要完整本地性能审计 | 未安装 → pagespeed |
| pagespeed_insights | 无本地环境、需远程分数 | 无 Key → custom_crawler |
| custom_crawler | 基础结构/索引检查，始终可用 | 兜底 |
