# 行为转化表模板

阶段三输出的标准化模板，可直接复制使用。

---

## 模板结构

### 原理 [N]: [原理名称]

| 维度 | 内容 |
|------|------|
| **一句话本质** | [用通俗语言描述核心机制] |
| **心理机制** | [为什么这条原理在人性/认知层面成立] |
| **每日最小行动** | [≤5分钟，具体可操作，格式："当X时，做Y"] |
| **每周深化行动** | [15-30分钟，用于巩固和扩展] |
| **典型错误避免** | [不这样做会犯什么错] |
| **触发条件** | [if-then 公式，与现有习惯捆绑] |
| **复盘问题** | [每日/每周自问的一个低负担问题] |
| **效果指标** | [如何判断是否有效的具体信号] |

---

## 示例

### 原理 1: 损失厌恶利用

| 维度 | 内容 |
|------|------|
| **一句话本质** | 人对损失的痛苦感是获得快感的2倍，利用此驱动行为改变 |
| **心理机制** | 进化塑造的防御性认知偏误，对威胁的敏感度高于机会 |
| **每日最小行动** | 当犹豫是否开始任务时，写下"不做会损失什么"而非"做了会获得什么" |
| **每周深化行动** | 回顾本周3次启动困难时刻，分析损失描述是否有效降低阻力 |
| **典型错误避免** | 避免空洞的"你会后悔"，必须具体描述损失的时间/机会/信用 |
| **触发条件** | 当感到拖延冲动时（if），立即写下3条具体损失（then） |
| **复盘问题** | 今天我用损失视角启动的任务，阻力是否比往常小？ |
| **效果指标** | 任务启动时间缩短、启动前的焦虑感降低 |

## 批量模板（多原理版本）

如需一次呈现多条原理的行为转化，使用以下紧凑格式：

```
┌─────────────────────────────────────────────────────────┐
│ 原理: [名称1]                                             │
├─────────────────────────────────────────────────────────┤
│ 最小行动: [内容]                                          │
│ 触发条件: [if-then]                                       │
│ 复盘问题: [问题]                                          │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 原理: [名称2]                                             │
├─────────────────────────────────────────────────────────┤
│ 最小行动: [内容]                                          │
│ 触发条件: [if-then]                                       │
│ 复盘问题: [问题]                                          │
└─────────────────────────────────────────────────────────┘
```

---

## 使用提示

1. **最小行动必须具体**: "每天读书"不合格，"每天早上刷牙后读2页"合格
2. **触发条件必须明确**: 使用 if-then 格式，绑定已有习惯
3. **复盘问题必须低负担**: 能用是/否或1-5分回答
4. **效果指标必须可观察**: 主观感受（"更自信了"）不如具体行为（"主动发言次数增加"）
