# com-knowledge-extractor

深度书籍分析与知识萃取 Skill，用于把书籍、长文或读书笔记转化为可判断、可迁移、可执行的知识系统。

## 一句话说明

先判断内容是否成立，再萃取思维模型，最后转成最小行动和复盘机制。

## 何时触发

- "深度阅读一本书"
- "萃取书中知识"
- "整理读书笔记"
- "分析这本书的核心论点"
- "把书里的内容用起来"
- "建立思维模型"

## 快速用法

```text
使用 com-knowledge-extractor:
书名: [书名]
材料: [章节/笔记/摘录]
目标: [判断价值 / 萃取模型 / 转成行动]
```

## 输出结构

- 结构真相还原：核心命题、论点链条、证据地图和局限
- 思维模型迁移：可复用模型、适用场景、机会点和误用陷阱
- 行为转化设计：第一性原理、最小行动、触发条件和复盘机制

## 使用边界

- 适用于深度阅读、知识内化、读书分享和个人模型库建设
- 不适用于快速摘要、娱乐性书评或只需要提取金句的场景
- 如果输入材料太短，先补充章节、笔记或关键摘录，再启动完整三阶段流程
