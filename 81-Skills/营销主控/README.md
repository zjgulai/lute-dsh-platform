# mkt-main-hub

营销技能包主协调器

## 功能

整合广告创意、付费优化、社媒内容、邮件营销、增长策略等营销技能

## 子 Skills

| Skill | 功能 | 触发场景 |
|-------|------|---------|
| mkt-ad-creative | 广告创意生成 | 需要广告文案、创意概念 |
| mkt-paid-ads | 付费广告优化 | 需要预算分配、出价策略 |
| mkt-social-content | 社媒内容生成 | 需要社媒帖子、内容日历 |
| mkt-email-sequence | 邮件营销序列 | 需要欢迎/弃购/复购邮件 |
| mkt-cold-email | 冷邮件外联 | 需要 B2B 外联、销售开发 |
| mkt-launch-strategy | 产品发布策略 | 需要 GTM 方案、增长实验 |
| mkt-copywriting | 文案写作 | 需要销售文案、品牌故事 |
| mkt-competitor-alternatives | 竞品替代方案 | 需要竞品分析、差异化定位 |
| mkt-cro-optimization | CRO 优化 | 需要转化率提升、着陆页优化 |

## 使用场景

- 营销活动整体规划
- 多技能协调调用
- 营销工作流编排

## 触发方式

当用户提及以下关键词时触发：
- "营销技能包"
- "营销自动化"
- "全渠道营销"
- "营销工作流"

## 输入要求

- 营销目标
- 产品信息
- 目标受众画像
- 预算与时间框架

## 输出交付物

- 营销策略方案
- 子 Skill 调用建议
- 工作流编排指南
