# 完整编排示例 / Full Orchestration Examples

本文件是「营销主控」的渐进式披露第三层：仅在需要参考完整编排样例时读取。

## 示例 1：跨境电商全渠道上市

**目标**：新品同时在 Amazon 与独立站上线

**技能链路**：
1. 竞品替代分析 → 竞争定位
2. 上市策略 → 整体 GTM
3. 广告创意 → Facebook/Google 广告
4. 邮件序列 → 预热邮件序列
5. 社媒内容 → Instagram/TikTok 内容
6. CRO优化 → 独立站转化优化

**协调器输出**：给出链路顺序、每步交付物、跨技能依赖（如广告创意依赖竞品定位的差异化卖点）。

## 示例 2：B2B SaaS 冷启动

**目标**：拿下首批企业客户

**技能链路**：
1. 竞品替代分析 → 差异化定位
2. 营销文案 → 网站文案
3. 冷邮件 → 外联邮件序列
4. CRO优化 → 着陆页优化
5. 上市策略 → 增长实验设计

## 示例 3：电商大促

**目标**：黑五 / 双十一营销活动

**技能链路**：
1. 上市策略 → 大促策略
2. 广告创意 → 促销广告创意
3. 邮件序列 → 促销邮件序列
4. 社媒内容 → 社媒倒计时内容
5. 付费广告 → 付费广告优化
