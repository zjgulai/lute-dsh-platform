## 路由判定规则

1. 单一技能需求 → 直接路由对应子技能，不经过本协调器。
2. 多技能协调（≥2 个技能，且需要编排顺序/分工）→ 本技能。
3. 需求不明确（不知道用哪个营销技能）→ 本技能先路由。
4. 缺产品/目标/渠道/预算 → 先追问，再编排。

## 工作流编排模板

### 全渠道新品上市
竞品替代分析 → 上市策略 → 营销文案 → 广告创意 → 邮件序列 → 社媒内容 → CRO优化

### B2B SaaS 冷启动
竞品替代分析 → 营销文案 → 冷邮件 → CRO优化 → 上市策略

### 电商大促
上市策略 → 广告创意 → 邮件序列 → 社媒内容 → 付费广告
