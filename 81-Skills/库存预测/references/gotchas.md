# 库存预测已知陷阱 / Gotchas

## 常见预测陷阱

1. **过度依赖均值**：用均值预测时忽略需求波动，导致安全库存不足。解决方案：使用标准差量化波动，结合Z-score计算安全库存。

2. **忽略牛鞭效应**：供应链上游的需求波动会被放大。解决方案：与上游共享真实销售数据，减少信息不对称。

3. **促销影响低估**：大促期间销量可能达到日常的3-10倍，简单线性外推严重不足。解决方案：使用历史大促数据做倍数法预测。

4. **新品无历史数据**：新上架SKU无法做统计预测。解决方案：基于相似品参考、竞品对标、预售数据做初步估计。

5. **季节性误判**：未考虑季节性因素导致备货过多或不足。解决方案：使用同比/环比分析识别季节性模式。

6. **补货周期变异**：供应商实际交货时间不稳定。解决方案：使用补货周期的标准差而非固定值，增加缓冲。

## 异常处理

- 预测量为负值 → 检查数据是否存在异常值或趋势反转
- 安全库存为0 → 检查服务水平参数是否过小（<50%）
- EOQ为0 → 检查订货成本或持有成本参数是否合理
