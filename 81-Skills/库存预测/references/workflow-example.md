# 库存预测工作流示例 / Workflow Example

## 场景1：日常补货建议

**用户输入**：
```
我这里有最近30天的销售数据，每天大概卖400-500件，当前库存还剩850件，供应商补货要7天，帮我算一下需要补多少货，什么时候下单合适？
```

**Skill 处理流程**：
1. 解析用户需求：日常补货建议
2. 提取关键参数：日均销量400-500、当前库存850、补货周期7天
3. 计算ROP（再订货点）：(400+500)/2 × 7 + 安全库存 = 约3,500件
4. 当前库存850 < ROP 3,500 → 需要补货
5. 建议补货量 = ROP × 2 - 当前库存 ≈ 6,150件
6. 输出补货建议报告

## 场景2：大促备货规划

**用户输入**：
```
618快到了，我们去年618卖了3万件，今年预计增长30%，帮我做一份备货规划
```

**Skill 处理流程**：
1. 识别场景：618大促备货
2. 基准预测：30,000 × 1.3 = 39,000件
3. 促销倍数：618通常是日均销量的3-5倍
4. 分阶段备货：5/15(30%) → 5/25(50%) → 6/5(20%)
5. 输出分SKU备货建议 + 分阶段到货计划

## 场景3：缺材料 - 追问

**用户输入**：
```
帮我预测一下下个月的库存需求
```

**Skill 处理流程**：
1. 识别需求：库存预测
2. 检测到缺少关键数据
3. 追问：请提供历史销售数据（至少30天）、当前库存水平、补货周期
4. 不编造预测结果
