## 安全库存计算示例

```
安全库存 = Z(服务水平) × 需求标准差 × √(补货周期)

示例：
- 服务水平 95%，Z = 1.645
- 日均需求标准差 σ = 50件
- 补货周期 = 7天
- 安全库存 = 1.645 × 50 × √7 ≈ 218件
```
