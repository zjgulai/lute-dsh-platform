# 竞品SEO分析框架与评分细则

本文件是 SEO竞品分析 的渐进式披露第三层：做关键词差距 / 外链评分 / 页面对比时读取。

## 1. 关键词差距分析框架

**输入**：自身关键词集 + 竞品关键词集（每条至少含 keyword，可选 volume/position/url）。

**步骤**：
1. 规范化：关键词统一小写 + 去空格，构建集合。
2. 三分类：
   - `missing`：竞品有排名、自身未覆盖（机会词）
   - `shared`：双方都有排名（争夺词）
   - `unique`：仅自身有排名（守成词）
3. 重叠度 = shared / (自身 ∪ 竞品) × 100%。
4. 机会排序：按竞品 volume 降序，volume 越高越优先。

**机会关键词分层**（输出到报告）：

| 层 | 判据 | 动作节奏 |
|---|---|---|
| 立即做 | volume > 100 且竞品排名 #1-5 | 本月建专题页/优化现有页 |
| 短期 | volume 50-100 且竞品排名 #6-20 | 3 个月内做内容 |
| 长期 | 长尾低难度 | 6 个月内排进内容矩阵 |

## 2. 外链机会复合评分

**公式**：`composite = DR×0.4 + 相关度×100×0.4 + dofollow(100|0)×0.2`

- DR（Domain Rating 0-100）：缺省 30。
- 相关度（0-1）：缺省 0.5；行业媒体/垂直博客 > 0.7，泛目录站 < 0.3。
- dofollow：dofollow=1 记 100，nofollow=0。

**价值分层**：
- high：composite ≥ 70
- medium：40 ≤ composite < 70
- low：< 40

**失败案例**：只追求数量、复制竞品的低相关目录站外链（DR 低 + 相关度低），会稀释站点权重，甚至触发人工审查。优先拿 2-3 个 high 级（行业媒体/榜单页）胜过 50 个 low 级。

## 3. 页面级特征对比

对比维度与判据：

| 维度 | 提取方法 | 落后判据 |
|---|---|---|
| 字数 | body 文本分词数 | 低于竞品平均 200+ 词 |
| 图片数 | `<img>` 计数 | 明显少于竞品 |
| 结构化数据 | JSON-LD / microdata | 自身无、竞品有 |
| Meta 描述 | `<meta name=description>` | 自身缺失、竞品有 |
| 内链数 | `<a href>` 指向自身域名 | 明显少于竞品 |
| FAQ | FAQPage schema | 自身无、竞品有 |

## 4. 反共识与私有权重

- 反共识：不必追平竞品的全部内容量；先打透一个高频场景词（如 "earbuds for running"）建立局部权威，再横向铺开，比平均用力更高效。
- 私有权重：优先利用自家可获得的独有数据（如真实用户评价、售后问题库）生成竞品没有的内容，而非复制竞品已有的列表型内容。
