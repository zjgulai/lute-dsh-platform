# SEO Competitor Analyzer - 竞品SEO分析工具

提供竞品页面抓取、SEO策略对比、关键词差距分析、反向链接洞察等竞争情报。

## 快速开始

### 基本用法

```
# 单竞品深度分析
提供目标URL + 竞品URL → 输出详细对比报告

# 多竞品概览
提供目标URL + 竞品列表 → 输出竞争格局分析

# 关键词差距分析
提供关键词列表 + 竞品 → 输出机会关键词

# 外链机会挖掘
提供竞品域名 → 输出外链建设清单
```

## 核心功能

- **竞品页面分析**: 页面结构、内容深度、关键词策略、用户体验对比
- **关键词差距分析**: 竞品排名关键词、重叠度分析、长尾关键词机会
- **反向链接洞察**: 外链来源分析、质量评估、可复制的链接机会
- **内容策略分析**: 竞品内容类型、发布频率、内容空白识别

## 输入输出

**输入**:
- 目标网站URL
- 竞品网站URL列表
- 目标关键词列表
- 分析维度要求

**输出**:
- 竞品对比报告
- 关键词差距分析
- 内容策略建议
- 外链机会清单

## 注意事项

1. 遵守robots.txt，避免过度抓取
2. 竞品数据可能存在滞后，建议交叉验证
3. 竞品也在优化，需定期更新分析
4. 不要盲目复制，找到自身差异化优势
