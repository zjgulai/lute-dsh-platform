# 情报简报输出模板

本文件定义 `cbec-intelligence-radar` 生成的结构化简报标准格式。

## 简报类型

### 类型 A: 日报（Daily Brief）

**适用场景**: 每日跨境电商 Claude Skills 动态速览
**时间范围**: 最近 24-48 小时
**核心板块**: 7 大板块（完整版）

### 类型 B: 周报（Weekly Roundup）

**适用场景**: 周度趋势汇总与深度洞察
**时间范围**: 最近 7 天
**核心板块**: 7 大板块 + 趋势分析 + 下周预判

### 类型 C: 专题报告（Topic Focus）

**适用场景**: 针对特定 Skill、仓库或事件的深度追踪
**时间范围**: 根据专题需求自定
**核心板块**: 灵活调整，聚焦主题

## 输出规范

### 文件命名

```
跨境电商_Claude_Skills_战略摘要_YYYYMMDD.md    # 日报
跨境电商_Claude_Skills_周报_YYYYMMDD.md        # 周报
跨境电商_Claude_Skills_专题_{主题}_YYYYMMDD.md  # 专题
```

### 落盘位置

```
core_skills_library/
├── 跨境电商_Claude_Skills_战略摘要_20260509.md
├── 跨境电商_Claude_Skills_战略摘要_20260512.md
├── ...
```

### 元信息要求

每份简报必须包含：
- 日期
- 简报类型
- 数据来源列表
- 检索关键词存档（供人工复核）
- 局限性说明（如中文社区覆盖不足等）
