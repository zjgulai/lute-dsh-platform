# "今日最热"Skill 判定标准

本文件定义如何从当日情报中筛选 Top 3 "最热 Skills"。

## 判定维度

综合以下 5 个维度，按优先级排序：

### D1: 版本更新与发布（权重最高）

**判定标准**：
- 今日或最近 3 天内发布新版本（vX.Y.Z）
- 发布重大功能更新（非 bugfix）
- 仓库 README 近期更新且内容显著变化

**分值**: +5

---

### D2: GitHub Star 增速异常（高权重）

**判定标准**：
- 今日新增 Stars > 平均日增的 2 倍
- 绝对增长 > 100 Stars / 日（中型仓库）
- 绝对增长 > 500 Stars / 日（大型仓库）
- 被 ProductHunt / HackerNews 等流量入口曝光

**分值**: +4

---

### D3: 社区讨论热度（中权重）

**判定标准**：
- Reddit / 知乎 / 知无不言 等平台出现 3+ 条相关讨论
- 有用户主动分享实战案例
- 被行业媒体（亿邦动力 / 36kr 等）报道

**分值**: +3

---

### D4: 实战案例曝光（中权重）

**判定标准**：
- 有具体的"使用岗位 + 解决问题 + 效率提升数据"的案例
- 案例来源可信（LinkedIn 实名 / 知名博客 / GitHub Issue）
- 效率提升数据可量化（非"大幅提升"等模糊表述）

**分值**: +3

---

### D5: 平台榜单上榜（中权重）

**判定标准**：
- ProductHunt "Product of the Day" 或更高
- SkillsMP 分类排行榜前列
- OpenClaw Registry 推荐位

**分值**: +3

---

## 评分规则

1. **累加得分**: 一个 Skill 可同时命中多个维度，得分累加
2. **岗位覆盖加分**: 若 Skill 覆盖 2+ 岗位方向，额外 +1
3. **中文适配加分**: 若 Skill 有中文支持或由中国开发者主导，额外 +1（针对中文用户场景）
4. **Top 3 选取**: 按总得分排序，取前 3 名
5. **同分处理**: 按 D1 → D2 → D3 → D4 → D5 的优先级依次比较

## 排除项

以下情况**不纳入**"今日最热"：
- 仅有仓库存在，但近 7 天无任何更新或讨论
- Star 数高但增速平缓（老仓库的自然增长）
- 非 Claude Skills 相关的通用电商工具
- 信息不足（仅有仓库名，无功能描述或来源）

## 人工判断保留

本标准提供客观评分框架，但"为什么今天热"的解释需要人工判断：
- 版本更新的具体内容是否值得关注
- 社区讨论是正面反馈还是争议
- 实战案例的可信度评估

最终 Top 3 的选择由执行者基于评分 + 人工判断共同决定。
