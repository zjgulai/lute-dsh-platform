# 市场可行性审计

判断新品方向是否值得 Momcozy 进入，在风险、利润、品类生命周期和品牌能力匹配之间做严格裁决。当用户提及"可行性分析"、"Go/No-Go"、"风险筛查"、"市场可行性"、"产品评估"或需要进入前裁决判断时使用。

触发词：可行性分析、Go/No-Go、风险筛查、市场可行性、产品评估、市场可行性审计。

## 快速开始

查看 [SKILL.md](./SKILL.md) 获取完整使用指南。

## 适用场景

- Momcozy 跨境电商业务
- Amazon / Shopify DTC 运营
- 母婴品类产品开发与新方向进入前裁决

## 何时不用

- 完整市场调研报告
- Listing 撰写、广告投放、产品概念设计
- 选品方向探索 / 市场机会扫描 / 趋势判断（用 市场洞察选品）
- 竞品情报 / 竞品分析（用 竞品情报）
- 评论痛点与情感分析（用 客户之声分析器）
- Sorftime 类目调研（用 亚马逊Sorftime调研）
- 实时价格监控（用 电商价格监控）
