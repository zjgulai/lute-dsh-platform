# 市场可行性审计 · 参考手册

简明、可操作的速查：Helium 10、母婴类目策略、平台费用、阈值与可选脚本。

---

## 1. Helium 10（亚马逊调研）用法摘要

| 模块 | 用途 | 操作建议 |
|------|------|----------|
| **Black Box** | 按条件筛品 | 设置价位、评论上限、营收区间，先宽后窄；导出后再人工剔除高风险类目。 |
| **X-Ray** | 搜索结果/Listing 页透视 | 看预估销量、卖家数、均价；与「主词」同一站点、同一时间窗口对比。 |
| **Cerebro** | 反查 ASIN 流量词 | 选 1–2 个腰部竞品 ASIN，抓主词与长尾，核对 **月搜索量** 是否支撑 ≥5000 主词策略。 |
| **Magnet** | 拓词 | 以种子词扩展；关注词与产品的相关性，避免泛词高估需求。 |

**注意**：各工具显示为估算值，应用时统一 **站点（US/EU）** 与 **日期**，并在报告中写明「数据来自 Helium 10，估算口径」。

## 2. 母婴类目策略速览（推荐 vs 规避）

**语境**：Momcozy；跨境 Amazon US/EU + Shopify；竞品参照 Elvie、Willow、Medela、Haakaa、KeaBabies。

| 类型 | 方向 | 说明 |
|------|------|------|
| 相对适合 | 纺织类配件、收纳、非带电护理辅助、明确差异化的哺喂周边 | 合规相对可拆解；注意仍可能涉及 CPSIA/小零件。 |
| 谨慎 | 入口类、长期皮肤接触、婴儿睡眠安全相关、测温/暖奶等小型电器 | CPSIA、食品接触、电子认证（如 FCC）与责任险成本。 |
| 倾向规避（首品） | 强品牌垄断的电动核心品类（吸奶器主机等若无颠覆性创新）、医用宣称、强监管医疗器械 | 与 Medela/Elvie/Willow 等正面硬碰需极大预算与合规储备。 |

欧盟销售需额外考虑 **CE、REACH、GPSR** 等，本表不替代法务/检测机构意见。

## 3. 平台费用速查表（估算级，以官方/后台为准）

| 平台 | 常见费用项 | 经验区间 / 备注 |
|------|------------|-----------------|
| **Amazon FBA** | Referral | 多数类目约 **8%–15%**，母婴/部分类目以**后台费率表**为准。 |
| **Amazon FBA** | FBA 配送 + 仓储 | 依 **尺寸分段、重量、旺季** 变化；大件/超重显著拉高。 |
| **Shopify** | 订阅 | Basic / Shopify / Advanced 月费各档不同。 |
| **Shopify** | 支付 | 常见 **约 2.9% + $0.30/笔**（境内卡；跨境/Amex 可能更高）。 |
| **TikTok Shop** | 佣金 + 活动/物流 | 因站点与类目政策调整频繁，**以卖家中心公示为准**；可做渠道补充，勿与亚马逊费用混算。 |

盈利审计时建议：**亚马逊路径 = referral + FBA（+ 可选广告占比单独一行）**；**DTC = 支付费 + 包装履约 + 获客**。

## 4. 关键阈值总表（与本技能 SKILL.md 一致）

| 维度 | 阈值 | 备注 |
|------|------|------|
| 主关键词月搜索量 | **≥ 5,000** | 工具估算，注明站点。 |
| 腰部卖家月销 | **约 100–300** | 理解为「可达成区间」，非精确值。 |
| 售价 | **≥ $20** | 过低难覆盖费用与售后。 |
| 竞品主 ASIN 评论数 | **< 500**（争空间） | 若类目普遍超高，标竞争饱和。 |
| 目标毛利率 | **≥ 25%**，理想 **30%–40%** | 粗略，含主要变动成本。 |
| 单品利润 | **≥ $5/件** | 与广告、退货率联动评估。 |

## 5. 产品条件检查脚本使用说明（可选）

若技能目录下存在 `scripts/product_criteria_checker.py`（可与本技能同路径部署），可用于**快速对照**部分门槛（**不能替代**合规与亚马逊费用细账）。

**调用方式**

```bash
python3 scripts/product_criteria_checker.py your_product.json
```

**JSON 示例**（字段与脚本一致）

```json
{
  "monthly_sales": 200,
  "price": 29.99,
  "competition_level": "medium",
  "category": "Baby",
  "is_electronic": true,
  "is_bulky": false,
  "is_fragile": false,
  "has_major_brand": true
}
```

**说明**

- `competition_level`：`low` / `medium` / `high`。  
- 脚本对 **电子、大件、易碎、大品牌主导** 会降分；**通过/不通过**为启发式，**最终以 SKILL 中风险筛查与合规为准**。  
- 若仓库中另有历史版本脚本，以**随本技能打包的版本**的 `Usage` 提示为准。
