# GTM 战略规划方法论（Playbook）

本文件是 GTM战略规划 技能的渐进式披露第三层，供制定市场进入 / 渠道 / 定价 / 时间表 / KPI 时按需读取。

## 1. 市场进入策略框架

进入一个新市场时，依次评估并明确：

1. **进入模式**：跨境直营（电商平台首发）/ 本地代理分销 / DTC 独立站 / 合资或收购。低风险先用跨境电商试水，验证后再本地化。
2. **首发阵地**：优先选流量大、信任背书强的渠道作为「首发根据地」，再向周边扩散。
3. **本地化清单**：语言、审美包装、客服与售后、退货政策、合规认证（如欧盟 CE、日本 PSE）。
4. **差异化定位**：一句话说清「进入后凭什么赢」，聚焦一个核心卖点而非面面俱到。

## 2. 渠道策略

- 线上主阵地：平台旗舰店（天猫/京东/亚马逊）负责成交与信任；社媒（抖音/小红书/TikTok）负责种草引流。
- 线下补充：连锁门店、体验点作为信任背书，不追求广铺。
- 私域：公众号 + 企业微信/社群沉淀复购。
- 渠道配比建议：广告 50–60%、KOL/达人 20–30%、内容 10–20%（按品类微调）。

## 3. 定价策略

- 对标中高端竞品定价，留 15–20% 首销折扣空间。
- 跨境定价需计入关税、物流、合规、本地运营成本，通常略高于国内价。
- 定价锚点三问：竞品价格带？目标用户支付意愿？毛利能否覆盖获客成本？

## 4. 上市时间表（倒排）

| 节点 | 关键动作 |
|------|---------|
| M-4 | Listing/详情页准备、合规认证启动 |
| M-3 | 定价与渠道谈判、种子用户/KOL 沟通 |
| M-2 | 营销内容制作（文案/视频/物料） |
| M-1 | KOL 合作启动、预售/种草预热 |
| M0 | 正式上市、首批投放 |
| M+1 | 广告全面投放、数据复盘与优化 |

## 5. 预算分配

- 广告投放 50–60%
- KOL/达人 20–30%
- 内容制作 10–20%
- 预留 5–10% 测试预算，用于渠道 A/B 验证。

## 6. KPI 体系

- 首月/首季销售额
- 广告效率：ACoS / ROAS
- 转化与信任：转化率、评价数、评分
- 复购与增长：复购率、新客占比、渠道贡献度
- 上市健康度：达标时间点、渠道 ROI 对比

## 7. 风险与合规

- 合规：目标市场认证、标签、广告法（避免绝对化用语）。
- 风险：库存、物流时效、本地竞品反应；预留应对预案。
- 策略随市场反馈迭代：M+1 起以数据驱动调整渠道预算分配。
