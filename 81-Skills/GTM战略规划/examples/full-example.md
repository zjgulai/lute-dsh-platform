# 完整 GTM 战略方案示例

以下是一次新品进入海外市场的完整 GTM 战略文档模板（可复用结构）。

## 输入
```
产品: 便携式蓝牙音箱（核心卖点：IPX7 防水 + 24h 续航）
目标市场: 美国
预算: $50,000
竞品: JBL Clip、Sony SRS-XB 系列
ICP: 18-35 岁户外/运动爱好者
```

## 输出：GTM 战略计划

### 一、市场进入策略
- 进入模式：跨境电商直营，Amazon 首发 + 自有 DTC 独立站承接复购。
- 首发阵地：Amazon 美国站（流量 + 信任背书），DTC 独立站做品牌承接。
- 差异化定位：「同价位防水续航最强的户外音箱」，聚焦 IPX7 防水这一核心卖点。
- 本地化：英文 Listing、美式审美包装、本地客服时区、FBA 物流。

### 二、渠道策略
- 线上主阵地：Amazon 美国站（成交）+ TikTok/YouTube 户外达人种草。
- 社媒：TikTok 短视频演示防水场景、Instagram 户外场景图。
- 私域：独立站邮件列表沉淀复购。
- 线下（中期）：REI、Best Buy 等户外/数码连锁，验证线上后切入。

### 三、定价策略
- 主力 SKU 定价 $49.99（对标 JBL Clip 中端带，留 15% 首销折扣空间）。
- 计入关税、物流、FBA 费用、合规成本后毛利目标 ≥ 45%。

### 四、上市时间表
- M-4：Listing 准备、FCC/加州 Prop 65 合规确认。
- M-3：定价定档、渠道入库、达人沟通。
- M-2：营销内容制作（视频/图文/邮件）。
- M-1：TikTok/YouTube 达人合作启动、预售种草。
- M0：正式上市、首批 PPC 投放。
- M+1：广告全面投放、ACoS 与转化复盘。

### 五、预算分配（$50,000）
- 广告投放（PPC + 社媒）：60% ≈ $30,000
- KOL/达人：25% ≈ $12,500
- 内容制作：15% ≈ $7,500

### 六、KPI
- 首月销售：1,000 件
- ACoS：< 30%
- ROAS：≥ 3.3
- 评价数：首月 50+
- 独立站复购率：≥ 15%

### 七、风险与合规
- 合规：FCC 认证、Prop 65 标签、广告法合规（避免绝对化用语）。
- 风险：库存断货预案、竞品 JBL/Sony 降价应对、物流时效。
- 迭代：M+1 起按渠道 ROI 重新分配预算，砍掉低效渠道。
