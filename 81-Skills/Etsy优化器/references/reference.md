## 一、eRank 指标解读指南

**搜索量（Search Volume）**  
Etsy 上该词或近似词的月度搜索需求估计。偏高通常意味着流量池大，但也常伴随更激烈竞争。需与竞争度联读。

**竞争度（Competition）**  
使用该关键词或强相关表达的 Listing 数量量级。竞争越高，同款词下突围越依赖主图、价格、评价与历史转化。

**CTR（点击率，若工具展示）**  
展示到点击的比例信号。若某词「展示高、CTR 低」，优先怀疑主图、标题前 40 字符吸引力、价格与评分，而非盲目加词。

**比值与组合分析（搜索量 / 竞争）**  
相对值越高，通常表示单位竞争下的需求更「划算」，适合作为 **低竞争果实** 的筛选线索之一。注意：极低搜索量即使比值好看，也可能样本噪声大，需结合订单目标判断是否值得占用车位。

**实操建议**  
同一产品做三张迷你表：低竞争果实、高竞争果实、长尾；每行至少包含：关键词、搜索量、竞争、比值、备注（是否适合当前店铺阶段）。

## 二、Etsy 搜索算法要点（精确 vs 广泛 · Quality Score）

**精确匹配 vs 广泛匹配**  
标题与标签中的 **完整短语** 与买家查询越一致，越容易获得较强相关性信号。词序被打散或拆到多个短标签，可能削弱「短语级」匹配效果。广泛层面仍会考虑类目、属性与同义词，但 **不应依赖** 广泛匹配替代核心短语的完整呈现。

**Quality Score 相关因素（运营可影响部分）**  
包括但不限于：点击率、转化率、收藏与加购、客户体验、履约与评价、Listing 与搜索意图的一致性。新链接需要 **60–90 天** 量级积累，频繁改标题标签会拉长学习期。

**对优化的含义**  
先保证 **主意图词** 在标题前部与标签前段稳定出现，再通过图片与描述提升 CTR 与转化，比反复改词更符合算法学习规律。

## 三、母婴手工/定制品类关键词策略案例

**案例 A：个性化婴儿毯（personalized baby blanket）**  
- Superstar：`personalized baby blanket`  
- 低挂果实：`custom baby blanket`、`baby name blanket`、`embroidered baby blanket`  
- 长尾：`baby shower gift blanket`、`newborn keepsake blanket`、`nursery blanket personalized`  
策略：标题前部锁定「个性化 + 婴儿毯」短语；标签补充「礼物、洗礼、新手父母」等购买动机词。

**案例 B：定制婴儿姓名牌（custom baby name sign）**  
- Superstar：`baby name sign`  
- 低挂果实：`custom nursery sign`、`wooden name sign baby`、`personalized nursery decor`  
- 长尾：`baby shower decor sign`、`boho nursery name sign`、`hospital door sign baby`  
策略：材质（木质/亚克力）与风格（boho、minimal）放长尾与后段标签，避免标题超载。

**案例 C：手工婴儿里程碑卡（handmade baby milestone cards）**  
- Superstar：`baby milestone cards`  
- 低挂果实：`monthly milestone cards`、`baby photo cards handmade`、`new baby milestone gift`  
- 长尾：`pregnancy announcement companion`（若产品线相关）、`baby journal cards`、`neutral baby milestone`  
策略：「月份记录」「拍照道具」「礼物」拆成不同长尾，覆盖不同搜索意图。

复制下方模板，按 Listing 填写；`[ ]` 为勾选项。

```
【Listing 基本信息】
- 店铺/品牌：[ ]
- Listing 链接或 SKU：[ ]
- 类目：[ ]
- 上架日期：[ ]  是否已满 90 天：[ ]

【关键词研究（eRank）】
[ ] 已记录核心宽泛词：[ ]
[ ] 已导出/整理三类词表：低竞争果实 / 高竞争果实 / 长尾
[ ] 关键词清单：Superstar 1–2：[ ]  低挂 3–5：[ ]  长尾 5–8：[ ]

【标题（约 140 字符）】
[ ] Superstar 完整短语出现在前部
[ ] 低挂果实 2 个左右以短语形式呈现
[ ] 含一段长尾或用途/礼物收尾
[ ] 分隔符清晰，无违规词与误导表述

【13 标签】
[ ] 13 个全部使用
[ ] 第 1–5（至 7）与标题核心一致或重复
[ ] 第 6–13 补充标题未覆盖的长尾与场合
[ ] 未拆碎重要短语

【图片与描述（全阶段可做）】
[ ] 主图：主体清晰、风格与类目一致
[ ] 附图：尺寸、定制流程、细节、场景、对比
[ ] 描述：首段回答「是什么、为谁、为何买」，含自然关键词

【冷启动与迭代】
[ ] 若未满 90 天：承诺不频繁改标题标签，优先图与描述
[ ] 若已满 90 天：本次只改一项（标题或标签），改因与日期：[ ]
[ ] 下次复盘日期：[ ]

【合规与真实】
[ ] 材质、工艺、产地、定制周期与政策描述真实
[ ] 无侵权品牌词与平台禁售表述
```
