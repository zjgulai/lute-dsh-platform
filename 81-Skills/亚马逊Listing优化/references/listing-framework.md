# Amazon Listing 优化框架（A9 关键词布局 + 规范清单）

## 1. 标题规范

- 长度：≤ 200 字符（含空格），移动端首屏约 80 字符最关键。
- 首字母大写（专有名词与品牌除外），不使用全大写。
- 禁用促销词：`Best Seller`、`#1`、`100% Guarantee`、`Free Shipping` 等。
- 结构建议：`品牌 + 品类 + 核心属性词 + 核心卖点 + 适用场景`。
- 前 80 字符放「核心词 + 核心卖点」，品牌词可后置（除非品牌是购买决策主因）。

## 2. 五点描述（Bullet Points）规范

- 每点突出一个核心价值（利益点），不写成规格表。
- 首字母大写开头，每点以「核心卖点词 + 具体量化 + 场景」展开。
- 每点埋一个长尾词，保持可读性，不堆砌。
- 五点的顺序 = 买家决策权重顺序（最强卖点放第 1 点）。

## 3. 后端搜索词（Backend Keywords）规范

- 上限 250 字节，空格分隔，不加逗号、不加品牌词、不重复标题已埋的词。
- 覆盖：同义词、拼写变体、长尾场景词、品类别名。
- 不堆砌、不重复单复数变形（Amazon 会自动匹配）。

## 4. A9 关键词布局

| 位置 | 权重 | 埋词策略 |
|---|---|---|
| 标题 | 最高 | 核心词 + 核心卖点，前 80 字符 |
| 五点 | 中 | 每点一个长尾词，利益点驱动 |
| 描述/A+ | 中 | 自然融入场景词与长尾词 |
| 后端搜索词 | 低但重要 | 同义词、变体、未在标题五点的词 |

## 5. 常见禁用/降权词（写标题与五点时应避免）

- 促销类：Best、Cheapest、Free、Guarantee（绝对化）、#1、Top
- 主观夸大：Amazing、Incredible、World's Best
- 与产品无关的引流词（误导性埋词会被 A9 降权）

## 6. 移动端 80 字符检查

移动端只显示标题前约 80 字符。确保核心词 + 核心卖点在 80 字符内可读，避免把品牌词或规格词前置挤掉核心卖点。
