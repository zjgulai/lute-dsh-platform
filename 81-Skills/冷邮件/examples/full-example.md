# 完整示例：SaaS ERP 冷邮件 + 跟进序列

## 场景

目标客户：跨境电商独立站卖家；价值主张：帮卖家把多平台订单与库存统一管理，省 30% 运营时间；外联目的：约 15 分钟产品演示。

## 第 1 封（冷邮件）

主题: 帮 [公司名] 把多平台订单管理省下 30% 的时间

正文:
```
Hi [名字],

看到 [公司名] 最近在拓展 TikTok Shop 渠道，
多平台订单和库存同步想必是团队正头疼的问题。

我们帮 200+ 独立站卖家把订单、库存、履约统一到一个后台，
平均每周省下 6 小时运营时间。

方便安排 15 分钟快速演示吗？

[你的名字]
```

## 第 2 封（Day 3 跟进）

主题: Re: 帮 [公司名] 把多平台订单管理省下 30% 的时间

正文:
```
Hi [名字],

上次提到多平台订单管理，附一个真实客户数据：
某美妆卖家接入后，错发率从 3% 降到 0.2%，退货纠纷减半。

如果你也在看这块，我可以发一份针对 [公司名] 场景的对比清单。

[你的名字]
```

## 第 3 封（Day 7 换角度）

主题: 库存同步问题，其实可以不用人工盯

正文:
```

我们重点解决的正是「多平台库存实时同步」，防止超卖和漏单。

下周三或周四哪天方便，我花 15 分钟演示一下？

[你的名字]
```
