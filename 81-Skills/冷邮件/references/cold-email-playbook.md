# 冷邮件外联 Playbook

## 1. 个性化冷邮件五要素

1. **定制化开场**：一句话点出对方的公司/行业/近期动态，证明你不是群发。
2. **痛点共鸣**：说出对方当前最可能面临的挑战，让它觉得「这人懂我」。
3. **价值主张**：用「结果」而非「功能」表达——我们帮相似公司实现了什么。
4. **清晰 CTA**：一个明确的下一步（约 15 分钟电话 / 约 demo），不要多个选择。
5. **简洁结构**：3-5 句正文，能扫读、不啰嗦。

## 2. 跟进序列节奏（3-5 封）

| 封数 | 时机 | 主题角度 | 目标 |
|---|---|---|---|
| 第1封 | Day 0 | 首次价值主张 | 建立认知 |
| 第2封 | Day 3 | 补充一个具体案例/数据 | 增加可信度 |
| 第3封 | Day 7 | 换角度重提价值（不同痛点） | 再给一次机会 |
| 第4封 | Day 14 | 社会证明 / 客户背书 | 降低决策风险 |
| 第5封 | Day 21 | 最后机会（礼貌收尾，保持关系） | 触发回复或结束 |

## 3. 回复模板

- **兴趣确认**：对方回复感兴趣 → 快速约时间 + 发议程。
- **异议处理**：对方说「太贵/没预算/没时间」→ 先共情，再给价值锚点，最后给低门槛下一步。
- **会议预约**：给对方 2-3 个可选时间，附会议主题与预期时长。
- **礼貌拒绝**：对方明确拒绝 → 感谢 + 保持关系 + 开放未来机会。

## 4. 合规与送达率

- 遵守 CAN-SPAM / GDPR / 中国《互联网广告管理办法》：提供退订、真实发件人、不得误导性主题。
- 主题行避免全大写、感叹号堆砌、垃圾词（免费、中奖、点击）。
- 尊重退订请求，退订即停发，维护发件人信誉。

## 5. 跟踪指标

- 打开率、回复率、会议预约率为核心指标；持续 A/B 主题行与开场白。
