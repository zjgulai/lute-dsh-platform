# 工作流示例：跨境物流方案

## 输入

```
发货地: 深圳
目的地: 美国洛杉矶（Amazon FBA）
货物: 家居收纳盒（纸箱）
重量: 800kg
体积: 6.5 m³
货值: $12000
时效: 30 天内到仓
预算: ¥12000
```

## 处理流程

1. **判定服务范围**：跨境物流方案规划 → 本技能负责。
2. **承运商对比**：
   - 海运头程：时效 30-40 天，约 ¥8/kg
   - 快船：时效 15-20 天，约 ¥15/kg
   - 空运头程：时效 7-10 天，约 ¥28/kg
3. **体积重核查**：6.5 m³ × 167 = 1085kg 体积重 > 800kg 实重 → 按 1085kg 计费（轻抛货）。
4. **税费测算**：货值 $12000 > $800 免税额度，需申报进口关税（家居收纳盒约 0-6.5%）+ 目的国清关。
5. **输出方案**：给出 3 套对比 + 推荐 + 风险提示。

## 输出（节选）

```
推荐方案: 快船头程
- 时效: 18-20 天（满足 30 天内到仓）
- 费用: ¥15 × 1085kg ≈ ¥16275（含偏远附加）
- 清关: 商业清关，DDP 条款
- 税费: 关税+增值税由卖家承担
```

## 风险提示

⚠️ 轻抛货按 1085kg 体积重计费，非 800kg 实重
⚠️ 若赶不上 30 天 deadline，需切换空运（+¥13000）
