# SCM Logistics Optimizer - 物流路线专家

运输路径优化、成本时效平衡、承运商选择。提供最优物流方案与成本测算。

## 使用边界

- 负责规划态物流方案设计，包括路线、成本、时效、承运商和关务
- 适合发货前决策、运输模式选择、月度线路优化和跨境方案设计
- 不负责运单状态持续追踪；在途可视化和异常查看交给 [scm-logistics-tracker](../scm-logistics-tracker)

## 快速开始

### 基本用法

```
# 国内物流优化
提供：发货地 + 目的地 + 货物信息 + 时效要求
输出：3套方案对比 + 推荐方案

# 跨境物流规划
提供：出口国 + 目的国 + 货物品类 + 货值
输出：跨境物流方案 + 关务指南 + 成本测算

# 承运商选择
提供：月度货量 + 主要线路 + 服务要求
输出：承运商推荐 + 谈判要点
```

## 核心功能

- **路线方案生成**: 多运输方式组合、中转方案优化、跨境物流路径
- **成本时效测算**: 运输费用计算、时效预测、隐性成本识别
- **承运商评估**: 主流承运商对比、服务质量评分
- **关务合规**: 进出口报关要求、税费测算、禁限运检查

## 输入输出

**输入**:
- 发货地与目的地
- 货物类型、重量、体积
- 时效要求(标准/加急)
- 成本预算
- 特殊要求(温控/保价等)

**输出**:
- 最优路线方案
- 多方案对比表
- 成本测算明细
- 承运商推荐
- 风险提示与预案

## 注意事项

2. 特殊货物需单独评估
3. 跨境需确保商品符合目的国法规
4. 高价值货物建议购买运输保险
