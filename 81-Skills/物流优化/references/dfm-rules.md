# 物流测算规则（dfm-rules）

本文件是「物流优化」的渐进式披露第二层：计费规则与关务税费的确定性知识，正文不展开。

## 体积重换算规则

- 空运/国内快递：体积重 = 长×宽×高(cm) / 6000（单位 kg）
- 国际空运：体积重 = 长×宽×高(cm) / 5000
- 海运：1 CBM = 167 kg（空运体积重系数），实际计费按「实重 vs 体积重取大者」
- 轻抛货（体积重大于实重）按体积重计费，这是普通 LLM 最易漏的隐性成本

## 计费附加项

| 附加项 | 典型费率 | 触发条件 |
|--------|---------|---------|
| 燃油附加 | 运费 3-8% | 常规 |
| 保价费 | 保额 0.3-0.5% | 高价值货物 |
| 上楼费 | ¥50-100/票 | 大件送货上楼 |
| 偏远附加 | ¥50-100/票 | 乡镇/偏远地址 |
| 仓储费 | 按 m³/天 | 中转停留 |

## 税费测算

- 进口关税 = 完税价格 × 关税税率（按 HS 编码查税率）
- 进口增值税 = (完税价格 + 关税) × 增值税率（中国 13%，欧盟 19-25%）
- DDP：卖家承担全部进口关税+增值税；DDU：目的国清关卖家负责，税费收件人承担
- 跨境电商小包低于目的国免税额度（如美国 $800）时免关税

## 承运商基准（供参考，实际以询价为准）

| 承运商 | 国内时效 | 破损率 | 适合场景 |
|--------|---------|--------|---------|
| 顺丰 | 1-2天 | 0.2% | 高时效/高价值 |
| 德邦 | 2-3天 | 0.3% | 大件/上楼 |
| 中通快运 | 3天 | 0.5% | 经济件 |
| DHL/FedEx/UPS | 3-5天(国际) | 0.2-0.3% | 跨境文件/急件 |
| 云途专线 | 12-18天 | 0.8% | 跨境小包经济 |

## TCO 构成

总拥有成本 = 运输 + 仓储 + 关税 + 保险(货值0.5%) + 库存持有成本(货值20%/年)

盈亏平衡判断：月货量 > 8000 单自建仓 TCO 更低；< 5000 单用第三方仓划算。
