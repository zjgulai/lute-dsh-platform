# 完整画像示例

以下是一个从题面信息推导出的完整 ICP 画像，展示交付物的标准格式与「每个维度都落到决策」的写法。

## 输入

```
产品: 便携式蓝牙音箱
市场: 美国
价格: $49.99
现有数据: 无（基于产品定位与市场常识推断）
```

## 输出

### ICP 画像卡片

| 维度 | 内容 | 决策落点 |
|------|------|----------|
| 基础信息 | 25-40 岁，收入 $50K-$100K，城市及郊区，年轻专业人士 / 创意工作者 | 广告人群定向、出价区间 |
| 行为特征 | 活跃于 Instagram、YouTube；兴趣为户外、音乐、科技；线上研究、评价驱动 | 投放平台选择 |
| 痛点与需求 | 现有音箱续航不足、户外不够耐用、音质与便携难兼得 | 卖点提炼（续航 / 防水 / 音质） |
| 购买动机 | 户外聚会与通勤场景需要便携高品质音乐；价格敏感但有品质底线 | 转化文案（便携 + 音质 + 性价比） |
| 触达渠道 | 社媒广告 (Instagram/Facebook)、KOL 合作（户外 / 科技博主）、户外活动赞助 | 预算分配 |

### 说明

- 本示例无真实客户数据，人口与行为维度为推断，标注「基于假设」。
- 如需更精准，建议补充：站内搜索词、复购数据、社媒互动人群标签。
