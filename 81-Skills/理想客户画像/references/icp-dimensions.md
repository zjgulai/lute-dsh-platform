# ICP 画像维度定义与填写要点

本文件是 `SKILL.md` 输出结构的扩展说明，在需要更细的维度清单或判断依据时查阅。

## 画像卡片结构

一个合格的 ICP 画像至少覆盖五个维度，每个维度都要能落到一个具体决策动作。

| 维度 | 内容 | 落到哪个决策 |
|------|------|--------------|
| 基础信息 | 年龄 / 收入 / 地域 / 职业 / 家庭结构 | 广告人群定向、出价区间 |
| 行为特征 | 活跃平台 / 兴趣 / 购买习惯 / 决策路径 | 渠道选择、内容形式 |
| 痛点与需求 | 现有方案的不足、未被满足的需求 | 卖点提炼、产品迭代 |
| 购买动机 | 为什么买、触发时机、价值排序 | 转化文案、促销节奏 |
| 触达渠道 | 社媒 / KOL / 搜索 / 线下 / 邮件 | 预算分配、投放计划 |

## 填写要点

1. **先有依据再写维度**：每个维度尽量来自题面信息（产品 / 市场 / 客户数据），无依据的维度标注「推断」，不冒充事实。
2. **一个画像一个核心场景**：避免把多个毫不相干的人群揉进同一张画像；不同人群拆成多个 ICP。
3. **痛点与动机要区分**：痛点是「现在难受在哪」，动机是「为什么愿意花钱解决」，两者分开写。
4. **渠道要与行为特征互证**：行为特征写了「活跃于 Instagram」，触达渠道就要含社媒投放，不能自相矛盾。

## 反例与修正

| 反例 | 问题 | 修正 |
|------|------|------|
| 「年龄 20-50 岁」 | 区间过宽，无区分度 | 按产品价格与场景收敛，如「25-35 岁城市年轻白领」 |
| 「兴趣：音乐」 | 太宽泛，无法定向 | 落到平台与标签，如「Spotify/短视频音乐垂类」 |
| 画像与题面矛盾 | 编造了题面没有的人群 | 回到题面信息，无对应则标推断或追问 |
