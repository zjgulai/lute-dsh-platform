# 术语标准化规则参考

## 策略选择规则

| 字段类型 | 策略 | 原因 |
|---------|------|------|
| applicable_objects | STRICT | 错误合并会导致知识误用 |
| prerequisites | STRICT | 遗漏前置条件会导致执行失败 |
| constraints | STRICT | 约束条件必须精确 |
| domain_tags | FLEXIBLE | 便于检索和分组 |
| keywords | FLEXIBLE | 语义相似即可 |

## 合并判定规则

### STRICT 模式
- 概念必须100%相同
- 仅允许大小写、空格、全角半角差异
- 中英文对照需确认概念完全一致

### FLEXIBLE 模式
- 同义词可合并
- 中英文对照可合并
- 缩写与全称可合并（ROI ↔ Return on Investment）
- 单复数可合并（ratio ↔ ratios）
- 行业俗称与正式名称可合并

## 冲突检测规则

1. 一对多映射：拒绝，要求提供上下文
2. 歧义术语：保留原样或添加前缀
3. 合并数超过3个来源：标记为可疑，需人工审查
4. 缩减率异常：<20% 检查是否未充分合并；>40% 检查是否过度合并

## 质量检查规则

- 核心概念未被意外合并
- 同义词已被识别并合并
- 无一对多映射
- 无空值或空字符串映射
- 映射可逆（可追溯）
