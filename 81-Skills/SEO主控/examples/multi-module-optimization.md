# 多模块 SEO 统筹示例

## 场景：跨境电商独立站自然流量下降

**用户输入**：
> 我的独立站最近三个月自然流量掉了40%，帮我诊断一下问题出在哪里。

**协调器分析**：
流量下降可能是技术问题、内容问题、竞品挤压或算法更新，需多模块诊断。

**协调流程**：
1. `seo-technical-audit` → 检查索引状态、Core Web Vitals、抓取错误
2. `seo-content-optimizer` → 审计核心页面内容质量、关键词排名变化
3. `seo-competitor-analyzer` → 检查竞品同期流量变化、关键词差距
4. `seo-geo-optimizer` → 检查 AI 搜索结果是否覆盖了你的流量

**输出**：整合诊断报告 + 分阶段恢复路线图

## 场景：新站 SEO 启动

**用户输入**：
> 我的新站刚上线，需要做完整的 SEO 优化，包括技术、内容和竞品分析。

**协调流程**：
1. 技术审计 → 内容优化 → 竞品分析 → Schema 部署
2. 输出 90 天执行日历 + 优先级清单
