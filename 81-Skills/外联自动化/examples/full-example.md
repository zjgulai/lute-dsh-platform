# 完整落地示例：户外蓝牙音箱 KOL 达人邀约

## 输入

```
目标: 户外领域 KOL（50 人，粉丝 5k-200k）
产品: 便携式蓝牙音箱（三防/长续航）
合作形式: 产品评测（免费寄样）
```

## 输出

### 1. ICP 与名单来源

- 目标：户外/露营/徒步/钓鱼类 KOL，粉丝 5k-200k，互动率 ≥ 2%。
- 来源：社媒平台搜索、达人数据库、竞品合作列表。
- 排除：纯带货无内容、与竞品独家合作、粉丝地域不符。

### 2. 首封触达模板

```
主题: 合作邀请｜[品牌名] 户外蓝牙音箱体验官

Hi [Name],

关注你在 [平台] 分享的 [具体户外内容] 很久了，尤其喜欢你 [某个具体观点]。
我们做了一款主打 [三防/长续航/低音] 的户外蓝牙音箱，想邀请你成为首批体验官，
免费寄送样机并做真实评测。你的内容与我们用户的户外场景高度契合，想听听你的真实反馈。
感兴趣的话，我发你产品资料和合作权益。

Best,
[Signature]
```

个性化变量：平台、粉丝量、近期内容主题、户外场景偏好。

### 3. 跟进序列

- Day 3：温和跟进（补一条对方内容共鸣）。

- Day 14：最后提醒（限时名额）。
- Day 21：关闭归档。
