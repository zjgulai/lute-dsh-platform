# 端到端优化示例

本示例展示「爆款视频分析器」从输入到完整输出的全过程。

## 输入

```
主题: 便携式榨汁杯带货
平台: TikTok
时长: 30秒
目标受众: 通勤上班族、健身人群
原脚本开头: "大家好，今天给大家推荐一款榨汁杯"
```

## 输出

### 结构优化（黄金3秒 + 8秒节奏 + 单一CTA）

- **0-3 秒（钩子）**：砍掉"大家好"自我介绍，换成结果/冲突开场——"出差三个月，我包里唯一没丢的就是这个杯子。"
- **4-12 秒（痛点+卖点1）**：便携讲成场景——塞进通勤包、办公室抽屉、健身房，配"比手机还矮"的具象对比。
- **13-24 秒（卖点2）**：续航讲成"能榨几次"而非"多少毫安"——"充满一次，连榨 8 杯，一周不用充电"。
- **25-30 秒（CTA）**："链接在主页，早八人也能天天喝现榨。"

### 标题建议

- "早八人的果汁自由！这个杯子 5 秒出汁还不用洗"
- "充电一次用一周的榨汁杯，打工人真香"

### 标签建议

#榨汁杯 #早餐 #上班族好物 #便携

### 音乐/节奏建议

- 前 3 秒配强鼓点 + 榨汁瞬间的慢镜头放大
- 卖点切换用快剪，每 2-3 秒一个画面变化
- 结尾 CTA 处降速 + 字幕强调，突出链接入口

### 发布策略

- 发布时间瞄准早高峰前（7:00-8:30）触达通勤人群
- 评论区置顶"扣『清单』发同款链接"，引导互动
