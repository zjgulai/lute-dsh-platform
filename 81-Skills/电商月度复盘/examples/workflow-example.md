# 完整月度复盘工作流示例

> 本文件为电商月度复盘的渐进式披露第三层，供新手参考标准交付格式。

## 输入

```
用户：帮我做2026年3月的月度经营复盘，要有KPI、环比、趋势和问题诊断。

订单CSV（30天）: orders_202603.csv
上月数据: 2月销售额 ¥2,850,000 / 订单 8,500 / AOV ¥335.3
月度目标: 销售额 ¥3,500,000 / 订单 10,000
```

## 处理流程

1. **数据验证**：确认 CSV 含 order_date / order_amount 列，30 天数据完整，金额可转数值。
2. **KPI 计算**：销售额、订单量、客单价、转化率、复购率（`scripts/run.py` 或直接计算）。
3. **环比对比**：与上月同期对比，计算各指标变化率。
4. **趋势分析**：按日/按周拆解，识别工作日 vs 周末差异、季节性因素。
5. **问题诊断**：未达标指标 → 根因分析（流量/转化/SKU/退货）→ 改进建议。

## 标准输出

见 SKILL.md「输出示例」区块：

```
📊 2026年3月 经营复盘报告
【KPI概览】...

【行动建议】...
```

## 常见场景

| 场景 | 关键点 |
|------|--------|
| 老板要月度运营会材料 | 突出 KPI 达成率 + 环比 + 下月重点 |
| 销售额未达标深挖 | 三因素分解：流量 / 转化 / SKU 表现 |
| 大促月份复盘 | 单独标注活动期，计算促销 ROI 与增量 |
| 渠道对比 | Amazon vs Shopify 拆解，看哪个渠道增长快 |
