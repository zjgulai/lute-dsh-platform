# SEO 内容优化 Playbook

页面级内容 SEO 优化的实操方法论（正文的渐进式披露第三层）。

## 1. 关键词密度与分布

- **区间建议而非固定值**：正文关键词密度建议 1.5%–2%（约每 100 词出现 1–2 次目标词），避免 <0.5%（太低无信号）与 >3%（堆砌惩罚）。
- **位置优先于频率**：目标关键词应出现在 Title、H1、正文前 100 词、至少一个 H2 与图片 ALT 中；仅堆正文频率无效。
- **语义扩展**：用 TF-IDF 找相关词（如「wireless headphones」配套 noise cancelling / bluetooth / over-ear / battery life），而非机械重复主词。

## 2. Title 与 Meta

| 元素 | 建议 | 检查点 |
|---|---|---|
| Title | 50–60 字符，核心词前置，含卖点 | 长度、关键词位置、差异化 |
| Meta 描述 | 140–160 字符，含关键词 + CTA + 卖点 | 是否缺失、是否含关键词、是否有行动召唤 |
| URL | 短、可读、含关键词 | 是否含乱码/参数 |

## 3. 内容质量评估

- 字数基线：产品页建议 800+ 词，文章页 1000+ 词。
- 可读性：Flesch 指数 60–70 为宜（面向大众）。
- E-E-A-T：补使用场景、FAQ、规格对比表、作者/更新信息。

## 4. 内部链接

- 每页至少 3–5 条相关内链，锚文本用描述性关键词而非「点击这里」。
- 发现孤岛页面（无任何内链指向）→ 从分类页/相关文章补链。
- 链接深度 ≤ 3 跳（首页 → 分类 → 详情）。

## 5. 输出契约

每条建议按「当前值 → 建议值 → 改动动作 → 预期影响」四段输出，落到可执行清单（P0/P1/P2），不输出泛泛常识。

> 排名效果受搜索引擎算法与竞争环境影响，本 playbook 只提供优化方向，不构成排名承诺。
