# SEO Content Optimizer - 页面内容SEO优化工具

提供关键词密度分析、内容质量评估、Title/Meta优化、内部链接策略等页面级优化建议。

## 快速开始

### 基本用法

```
# 单页面优化
提供页面URL + 目标关键词 → 输出页面优化报告

# 批量优化
提供页面列表 + 关键词映射 → 输出批量优化建议

# 竞品对比优化
提供页面URL + 竞品URL + 关键词 → 输出超越策略
```

## 核心功能

- **关键词分析**: 关键词密度计算、分布评估、TF-IDF语义分析
- **页面元素优化**: Title标签、Meta描述、H标签层级、图片ALT
- **内容质量评估**: 内容完整性、可读性评分、E-E-A-T评分
- **内部链接策略**: 内链机会识别、锚文本优化、权重流动

## 输入输出

**输入**:
- 目标页面URL或内容
- 目标关键词列表
- 竞品参考页面(可选)

**输出**:
- 页面优化建议
- Title/Meta方案
- 关键词布局建议
- 内容优化清单

## 注意事项

1. 避免关键词堆砌，保持自然阅读
2. SEO优化不能以牺牲用户体验为代价
3. 重大Title变更建议先小流量测试
4. 定期回顾并更新内容保持新鲜度
