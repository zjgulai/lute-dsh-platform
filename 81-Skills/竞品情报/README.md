# Competitor Intelligence

竞品情报与竞争格局分析工具

## 快速开始

```bash
# 竞品分析
分析竞品情报
竞品: [竞品列表]
维度: [分析维度]

# 竞争格局
生成竞争分析
市场: [市场名称]
深度: L1/L2/L3
```

## 能力边界

- 竞品档案：输出单个或多个竞品的定位、价格、渠道、功能和策略。
- 竞争格局：输出 Five Forces、定位图、空白点、反向洞察、应做/不应做。
- 公司尽调：不在本 Skill 内完成，转 `company-research`。

## 复杂度

Standard
