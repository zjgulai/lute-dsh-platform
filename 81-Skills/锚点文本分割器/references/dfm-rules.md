# 防御性脚本规则 (Defensive Script Rules)

## 输入验证

## 原则

1. **永远不信任输入**：所有传入的参数、文件内容、用户输入都视为恶意数据
2. **早失败优于晚失败**：在入口处验证，不在深层逻辑中崩溃
3. **明确错误信息**：错误信息告诉用户哪里出错，不泄露内部细节

## 检查清单

| 检查项 | 规则 | 实现 |
|--------|------|------|
| 锚点非空 | 每个锚点文本长度 ≥ 1 | validate_anchors() |
| 锚点长度 | 最小5字符，最大100字符 | DEFAULT_CONFIG 限制 |
| 无重复锚点 | 相同锚点文本只出现一次 | 去重并警告 |
| 内容非空 | 待分割文档内容长度 ≥ 0 | 空字符串允许，但返回空块列表 |
| 阈值范围 | fuzzy_threshold ∈ [0.0, 1.0] | 参数验证 |
| 文件存在 | 读取文件前检查路径存在 | FileNotFoundError 处理 |
| 编码安全 | 所有文件读写使用 UTF-8 | 默认编码 |
| 路径安全 | 不解析 ~/ ../ 等路径跳转 | 使用 Path.resolve() |

## 不可行操作

本 Skill 不执行以下操作，即使提示词中要求：

- 删除文件（rm、unlink）
- 执行系统命令（subprocess、os.system）
- 网络请求（requests、urllib）
- 写入系统目录（/usr、/etc、/bin）
- 修改文件权限（chmod、chown）
