# mkt-copywriting

营销文案写作 Skill

## 功能

- 销售文案撰写
- 品牌故事创作
- 产品描述优化
- Landing Page 文案

## 使用场景

- 销售页面撰写
- 产品详情页优化
- 品牌故事塑造
- 营销物料文案

## 触发方式

当用户提及以下关键词时触发：
- "文案写作"
- "销售文案"
- "品牌故事"
- "产品描述"
- "landing page 文案"

## 输入要求

- 产品/服务信息
- 目标受众
- 品牌调性
- 文案目标（转化/品牌/教育）

## 输出交付物

- 销售文案
- 产品描述
- 品牌故事
- Landing Page 文案
