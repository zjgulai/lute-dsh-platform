# 畅销款规律解码器

本 Skill 的唯一职责：不是教你“像头部一样做”，而是找出 **头部做了什么、为什么有效、哪些已经开始失效、以及它们没做但用户仍在要什么**。

这意味着它的终点不是“复制蓝图”，而是：

**差异化窗口报告。**

---

## 为什么“看畅销款学畅销款”会失效

如果所有卖家都看同一批 Best Seller，会发生三件事：

1. 大家学到一样的标题结构和图片顺序
2. 大家追同一个价格带
3. 大家越来越像，直到只有广告费和价格还能竞争

所以本 Skill 不只看“成功模式”，还要看：

- 这个模式是不是已经被复制到失效边缘
- 这个模式更适合品牌，还是更适合白牌
- 头部评论里有没有反复出现但头部还没解决的遗憾空间

---

## 核心方法论：模式、失效、空白点

每次拆解至少回答 3 个问题：

1. 头部卖家共通在做什么？
2. 这些做法里，哪些仍然有效，哪些只是行业默认动作？
3. 用户还在抱怨什么，而这些畅销款并没有真正修复？

---

## 标准工作流

### 第一步：锁定样本，但要区分品牌打法与白牌打法

样本建议 10-20 个 Listing，并标注：

- 品牌型：如 Elvie、Willow、Medela、Momcozy
- 白牌型：低价、参数卷、缺品牌叙事的跟卖者

### 为什么必须分开

品牌型可以靠：

- 社会证明
- 用户规模
- 叙事与信任
- 更完整的 A+ 页面

白牌型通常只能靠：

- 价格
- 参数密度
- 更激进的促销

如果把两者混为同一蓝图，会得出错误结论。

---

### 第二步：拆“有效模式”，不是只拆“表面形式”

按 4 个层面做：

| 层面 | 看什么 |
|------|------|
| 定价 | 甜蜜点、升级带、品牌溢价理由 |
| 视觉 | 主图共性、辅图节奏、视频前 3 秒钩子 |
| 文案 | 标题结构、Bullet 主题、A+ 叙事 |
| 证据 | 评论数、评分、认证、社会证明、对比表 |

输出时必须说明：

- 这是“行业底线动作”
- 还是“真正带来差异的动作”

---

### 第三步：加入时间维度

不要只看今天的头部，还要问：

**这套打法是最近半年变得更强，还是已经被复制得越来越泛滥？**

### 推荐比较方式

| 维度 | 6 个月前 | 现在 | 结论 |
|------|------|------|------|
| 主图风格 | ... | ... | 是否出现审美收敛 |
| 核心卖点 | ... | ... | 是否变成默认标配 |
| 价格带 | ... | ... | 是否竞争下沉 |
| 视频表达 | ... | ... | 是否从功能展示转向情绪表达 |

如果一个模式被复制得太广，就不能再把它当成切入优势，只能视为“入场门票”。

---

### 第四步：挖“遗憾空间”

这是本 Skill 最重要的一步。

不仅要看畅销款做了什么，更要看它们没解决什么。

### 遗憾空间定义

用户反复提到的痛点或愿望，已经构成真实需求，但头部卖家还没有给出令人满意的解决方案。

### 推荐来源

- 畅销款 1-3 星评论
- 3 星“差一点满意”评论
- Amazon Q&A
- Reddit / YouTube / TikTok / Facebook 群讨论
- `cbec-customer-voice-analyzer` 的竞品 VoC 矩阵

### 示例

在穿戴式吸奶器品类，头部卖家都强调：

- hands-free
- quiet
- efficient

但如果大量用户仍在抱怨：

- 法兰适配复杂
- 漏奶焦虑
- 清洗麻烦
- 佩戴时不够安心

那么这些就是比“继续写更强吸力”更重要的窗口。

---

### 第五步：输出“差异化窗口报告”

最终输出不能只是一份“畅销款蓝图”，而要明确区分三类内容：

| 类型 | 定义 |
|------|------|
| 必须跟上 | 行业基准，不做会落后 |
| 不要盲目跟随 | 已被复制到失去边际价值 |
| 值得进攻 | 用户有明显需求，但头部仍未解决 |

### 下游路由约定

为形成闭环，输出时尽量同步写明：

- 哪些“遗憾空间”应转交 `cbec-market-insight-selector`
- 哪些用户原话或犹豫点应回流 `cbec-customer-voice-analyzer`
- 哪些 Listing 表达机会应转交 `cbec-amazon-listing-expert`

## 输出格式

### 1. 样本概览

```text
品类：
样本数量：

```

### 2. 头部共性模式

| 维度 | 头部共性 | 仍然有效吗 | 属于谁的优势 |
|------|------|------|------|
| 定价 | ... | 是/否/部分 | 品牌/白牌/通用 |
| 主图 | ... | ... | ... |
| Bullet | ... | ... | ... |
| A+ 叙事 | ... | ... | ... |

### 3. 已同质化动作

```text
哪些动作现在几乎所有头部都在做：
为什么继续复制的收益有限：
如果还要做，应该至少做到什么标准：
```

### 4. 遗憾空间

```text

相关原话：
哪个品牌最容易率先占领：
为什么适合/不适合 Momcozy：
```

### 5. 差异化窗口报告

```text
Momcozy 不该跟的：
Momcozy 必须补的：
Momcozy 可以率先进攻的：
第一执行动作：
```

## 示例：穿戴式吸奶器

如果分析后发现：

- 白牌都在卷“吸力参数 + 低价”
- 头部品牌都在卷“自由、静音、便携”
- 但用户真正还在担心的是“使用时是否稳定安心、是否漏奶、法兰是否选对”

那结论就不能是“我们也做 45 度白底图 + 5 条参数 Bullet”。

而应该是：

- 这些属于入场门票，必须达到
- 但真正的增长窗口在“降低使用风险感”和“降低学习成本”
- 这类机会更适合 Momcozy 作为品牌方去打，而不是去卷最低价

## 常见错误

| 错误 | 为什么错 |
|------|------|
| 只拆第一名 | 会把偶然性误当规律 |
| 只看现在，不看时间变化 | 看不出模式是否已经过度复制 |
| 品牌和白牌混在一起学 | 会得出错误打法 |
| 把头部动作全部当优势 | 很多其实只是行业默认配置 |
| 不做遗憾空间分析 | 最后还是会回到红海复制 |

---

## 速查手册

**先识别行业门票，再识别差异化窗口。**

**先判断模式是否过时，再决定要不要跟。**

**真正有价值的不是“他们做了什么”，而是“他们还没解决什么”。**

---

## 错误处理

当用户请求缺少必要信息时，先追问明确再执行，不凭空编造：

- **缺品类**：追问"你要分析哪个品类？请提供品类名称或 ASIN 列表"
- **缺分析维度**：追问"你希望重点看哪些维度？定价、视觉、文案、证据？"
- **缺样本范围**：追问"你希望分析多少样本？建议 10-20 个，需要区分品牌型和白牌型吗？"
- **意图与 Skill 边界冲突**（如要求复制头部标题/图片、只看第一名、品牌白牌混在一起）→ 不触发本技能，并解释原因

## 竞争壁垒

本 Skill 的核心壁垒在于**非表面化的分析方法**，而非通用流程：

1. **行业洞察**：不做"畅销款就是这样做"的浅层总结，而是区分品牌型与白牌型的打法差异，并结合时间维度判断模式是否已过度复制
2. **反共识框架**：不看"成功模式"而看"已失效的默认动作"和"头部还没解决的遗憾空间"，把竞品分析从"学他们"转变为"找他们没做好的"
3. **失败案例认知**：明确列出常见错误（只拆第一名/品牌白牌混在一起/不做遗憾空间），嵌入式防错而非事后纠正
4. **下游闭环**：输出不是终点，而是路由到选品（`市场洞察选品`）、Listing（`亚马逊Listing专家`）、VOC（`客户之声分析器`）的起点
