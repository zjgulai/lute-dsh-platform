# cbec-bestseller-pattern-analyzer

拆解 Amazon 畅销款，找出头部套路、有效规律和未解决的遗憾空间，生成差异化窗口报告。当用户提及"畅销款分析"、"Best Seller解码"、"竞品规律"、"爆款拆解"、"定价带分析"、"图片规律"或需要深度分析竞争对手成功模式时使用。 触发词：畅销款分析、Best Seller解码、竞品规律、爆款拆解、定价带分析、图片规律。
