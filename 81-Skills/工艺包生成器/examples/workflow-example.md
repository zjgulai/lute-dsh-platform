# 工作流示例：硅胶婴儿辅食碗 Tech Pack

> 演示完整四步工作流的一次落地产出。输入为一段产品描述，输出为面向工厂的技术包。

## 输入（用户原话）

> 我要做一款母婴硅胶辅食碗，需要完整工艺包。材质是食品级液态硅胶，内壁带刻度线，
> 底部有吸盘防滑，目标 6 个月以上宝宝，需要标注食品接触合规和脱模风险。

## 第一步：基础图纸输出

- 三视图（正/侧/俯）：标注碗体、吸盘、刻度线位置
- 制造工艺图：液态硅胶注射成型（LSR injection molding）
- 装配图 / BOM：碗体（LSR）+ 吸盘（LSR，可一体或二段包胶）

## 第二步：DFM 审查

| 风险点 | 为什么有风险 | 建议验证方式 |
|--------|--------------|--------------|
| 刻度线印刷/纹理 | 食品接触面不清晰或脱落 | 刻度用凹刻纹理成型，验证可读性 |
| 吸盘与碗体包胶 bonding | 二段成型界层脱开 | 包胶前处理，做剥离测试 |
| 壁厚不均 | 缩水变形 | 目标壁厚差 ≤40%，T1 试模测壁厚 |

## 第三步：母婴合规关注点

```text
适用标准方向：FDA 21 CFR / GB 4806 食品接触迁移测试
材料/结构敏感点：食品接触面硅胶硫化体系、吸盘小零件脱落风险
标签或警示要求：适用年龄、耐热温度、清洗方式警示
```

## 第四步：制造风险摘要

```text
最可能的制造风险：刻度线成型不清晰、吸盘包胶界层剥离
最容易出错的装配位：吸盘与碗体二次成型对位
最该优先打样验证的细节：刻度清晰度 + 剥离强度
最该优先确认的合规点：食品接触迁移测试报告
```
