# 母婴品类合规关注点清单

> 技术包第三步「母婴品类风险位」时按产品类别查阅，至少补一类关切点。
> 本清单不替代法务/认证机构，只用于**提醒哪些位置值得优先确认**。

## 风险类别与对应产品

| 类别 | 典型产品 | 关注点 | 优先确认方向 |
|------|----------|--------|--------------|
| 皮肤长期接触 | 背带、睡袋、口水巾 | 材质刺激性、pH、甲醛、偶氮 | GB 31701 / CPSIA 邻苯与重金属 |
| 食品接触材料 | 喂养勺、辅食碗、奶瓶及配件 | 迁移量、双酚、硫化体系 | FDA 21 CFR / GB 4806 迁移测试 |
| 小零件脱落 | 玩具、牙胶、安抚物 | 吞咽/窒息风险 | 小零件测试、拉力扭矩测试 |
| 尖角/勒压/卡夹 | 推车配件、围栏、餐椅 | 锐边、夹缝、勒颈 | 锐边测试、夹缝间隙 |
| 电器安全/充电/发热 | 暖奶器、消毒盒、吸奶器 | 温升、短路、防水 | IEC 60335 / 安规温升与绝缘测试 |

## 输出格式（写入技术包「4. 母婴合规关注点」）

```text
适用标准方向：
材料/结构敏感点：
标签或警示要求：
```

## 判定边界

- 只输出"需确认的方向"与"适用标准方向"，**不输出"已合规"结论**
- 需要法定效力结论时转介法务/认证机构
