# 完整工作流示例

## 场景：Q1 季度复盘 + Q2 战略规划

### 输入
- 本季度90天订单CSV（字段：order_date, revenue, orders, category, aov）
- 上季度/去年同期数据（可选，用于环比/同比）
- 年度目标（total_revenue, total_orders）

### 处理流程
1. **数据校验**：检查CSV是否为空、字段是否完整、数据是否≥30天
2. **核心KPI计算**：销售额、订单量、客单价、复购率、毛利率
3. **趋势分析**：三个月逐月趋势 + 环比 + 同比
4. **年度进度**：季度完成 vs 年度目标，达成率 + 缺口预测
5. **战略洞察**：增长驱动归因（新客vs老客、量价拆解）+ 风险预警
6. **策略建议**：下季度目标设定 + 资源分配 + 关键行动项

### 输出报告结构
见 SKILL.md「输出示例」章节。

### 边界情形
- 缺CSV → 追问「请提供90天订单CSV」，不编造数据
- 缺年度目标 → 声明「无法计算达成率，仅输出趋势」，不编造目标
- 数据<30天 → 声明「数据跨度不足，建议使用月报/日报」
