# 子 Skill 边界说明

## 电商季度战略 vs 相邻 Skill 路由规则

| 场景 | 应触发 | 不触发 |
|------|--------|--------|
| 季度复盘（90天） | 电商季度战略 | — |
| 月度复盘 | 电商月度复盘 | 电商季度战略 |
| 日报 | 电商日报 | 电商季度战略 |
| 大促活动ROI复盘 | 大促效果分析 | 电商季度战略 |

| 季度数据分析（仅简单统计） | 电商CSV处理 | 电商季度战略 |
| 年度战略规划（非数据驱动） | — | 电商季度战略（缺数据） |

## 职责冲突场景处理

- 用户同时要求「季度复盘 + 大促ROI」：先做季度复盘，大促部分建议用户另开大促效果分析
- 用户说「季度数据做个表格」：若仅需排名/统计 → 不触发，路由到电商CSV处理；若需战略分析 → 触发
- 用户说「分析一下趋势」但未指定时间范围：追问时间范围，确认≥90天且有季度复盘意图才触发
