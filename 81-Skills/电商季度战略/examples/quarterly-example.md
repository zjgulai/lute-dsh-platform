# 电商季度战略 — 示例输入/输出

## 输入示例（90天订单CSV，前5行）

```csv
order_date,revenue,orders,category,aov
2026-01-05,18600,62,母婴,300
2026-01-18,24300,81,喂养,300
2026-02-03,22100,74,母婴,299
2026-02-15,19800,66,穿戴,300
2026-03-08,25400,85,喂养,299
```

## 输出示例（季度复盘摘要）

- **季度销售额**：¥XX（目标 ¥YY，达成率 ZZ%）
- **三个月趋势**：1月 → 2月 → 3月，逐月走势
- **同比/环比**：vs 去年同期、vs 上季度
- **下季度建议**：目标设定、资源分配、关键行动项
