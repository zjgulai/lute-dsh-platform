# ecom-quarterly-strategy

电商季度战略分析工具，输入90天订单CSV，输出季度经营复盘、战略建议、年度对比、长期趋势洞察。

## 快速开始

```bash
# 季度复盘
使用 ecom-quarterly-strategy: 生成Q1季度复盘

# 战略规划
使用 ecom-quarterly-strategy: 制定Q2战略建议

# 年度预测
使用 ecom-quarterly-strategy: 预测全年完成情况
```

## 功能特性

- **季度全景分析**: 核心指标达成、三个月趋势对比、年度目标进度
- **战略洞察**: 增长驱动因素、市场机会识别、风险预警
- **年度对比**: 同季度去年同期对比、全年目标达成预测
- **策略建议**: 下季度目标设定、资源分配、关键行动项

## 输入要求

- 90天订单CSV文件
- 上季度同期数据
- 年度目标设定
- 季度经营计划

## 输出内容

- 季度经营复盘报告
- 战略建议与行动计划
- 年度目标完成预测
- 下季度策略建议

## 依赖

- 父技能: ecom-main-hub
- 相关技能: ecom-monthly-review, ecom-promo-analysis, ecom-csv-processor
