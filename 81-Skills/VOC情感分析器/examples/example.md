# VOC情感分析器 使用示例

## 输入

```
评价数量: 500条
产品: 便携式蓝牙音箱
评价数据: CSV 格式，包含 text、rating、date 列
分析维度: 情感分布、痛点排序、卖点提炼、功能需求
```

## 输出

```markdown
## VOC分析报告

### 情感分布
- 正面: 65%
- 中性: 20%
- 负面: 15%

### Top5痛点
1. 续航时间不足 (32%提及，severity=高)
2. 蓝牙连接不稳定 (18%，severity=高)
3. 低音效果差 (15%，severity=中)
4. 充电速度慢 (12%，severity=中)
5. 防水等级不够 (8%，severity=低)

### 卖点提炼
- "便携性好" (45%提及)
- "音质清晰" (38%)
- "外观时尚" (25%)

### Feature Requests
- 支持 USB-C 快充 (23%提及)
- 增加 EQ 调节功能 (18%)
- 配套 App 控制 (12%)

### 改进建议
针对续航痛点，下一代产品建议提升至30h+；针对蓝牙稳定性，建议升级蓝牙5.3芯片
```
