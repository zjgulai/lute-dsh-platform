# 完整交付示例：穿戴式吸奶器（虚拟品牌）

> 展示「标准输出格式」的落地形态。品牌私有上下文来自 `references/business-context.md`，本示例为虚拟夹具，仅演示结构。

## 1. 目标人群与中断点

```text
目标人群：二胎职场妈妈，正在背奶或考虑从 Medela 升级。
当前替代方案：传统电动吸奶器（笨重、需固定插座）、Medela。
最大购买焦虑：上班泵奶怕被看到、噪音尴尬、清洗麻烦、担心吸力不够排空。
最有效的情绪钩子：「放进内衣里就能泵奶，通勤开会都不耽误」。
最关键的信任障碍：吸力是否真的够、会不会漏奶、法兰尺寸是否合适。
```

## 2. 说服链摘要

```text
0-2 秒识别：可穿戴、免手扶、放进内衣的吸奶器。
2-4 秒痛点关联：职场妈妈不必躲进母婴室，边工作边泵奶。
4-6 秒信任建立：多模式多档、低噪、多法兰适配、易拆洗。
6-8 秒价值判断：解放双手换来的时间，值回价格；售后与保修兜底。
```

## 3. Listing 资产

### 标题

穿戴式电动吸奶器 免手扶隐形哺乳 低噪多模式 便携背奶 通勤办公 孕产妇专用

### Bullet 5 条

1. 真正腾出双手，而不是"更方便一点" — 放进哺乳内衣即可泵奶，通勤、开会、带娃时都能继续完成日常节奏。
2. 夜间也敢用的安静体验 — 低噪运行减少打扰，让半夜泵奶不再变成全家被迫醒来的时刻。
3. 医院级吸力支持高效排空 — 多模式与多档位调节，帮助不同泌乳阶段找到更舒服的节奏。
4. 让人放心下单的细节设计 — 提供多法兰适配、易拆洗结构与售后支持，降低"买了不合适"的顾虑。
5. 开箱就能进入使用状态 — 标配核心配件，减少额外采购与试错成本。

### 图 1-7 brief

1. 主图：穿戴姿态在内衣下隐蔽、可被一眼识别（不违反平台规范）。
2. 关联痛点：办公场景下边工作边泵奶。
3. 核心性能：吸力档位、低噪分贝、续航时长。
4. 处理疑虑：法兰尺寸、清洗难度、漏奶风险。
5. 比较优势：与传统电动/手动方案结构对照。
6. 购买完整性：配件全家福、包装。
7. 品牌信任：真实妈妈使用反馈、质保、口碑数据。

### A+ 叙事结构

1. 痛点共鸣：职场妈妈在母婴室排队、躲厕所泵奶的窘境。
2. 解决方案出现：放进内衣、免手扶，泵奶不再打断工作。
3. 场景想象：会议间隙、通勤路上、夜里照顾宝宝，都能从容完成。
4. 证据与比较：多模式参数、低噪数据、认证、真实评论。
5. 社会证明收束：越来越多职场妈妈的选择，质保与客服承诺。
