# Prompt 工程指南

## 核心 Prompt 模式

### SKU 提取 Prompt

```python
EXTRACT_SKU_PROMPT = """
从以下文档中提取可复用的知识单元（SKU）：

文档内容：{content}

提取要求：
1. 识别触发条件（何时使用该知识）
2. 提取执行逻辑（具体步骤）
3. 定义输出格式（结果模板）
4. 标注适用对象（适用人群/场景）

输出格式：JSON 格式的 SKU 数组
"""
```

## 优化技巧

1. **具体化示例**: 提供 2-3 个具体示例
2. **约束明确**: 限制输出格式和长度
3. **错误处理**: 定义无法提取时的返回

## 质量检查清单

- [ ] 触发条件是否可判定
- [ ] 执行逻辑是否可执行
- [ ] 输出格式是否明确
- [ ] 边界情况是否覆盖
