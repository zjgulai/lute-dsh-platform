# cbec-category-sourcing-report

生成跨境电商品类的完整商业可行性报告，涵盖全球趋势、价格段、用户痛点和供应链评估。当用户提及"可行性报告"、"品类分析"、"选品报告"、"供应链评估"、"跨境选品"或需要全面的品类市场分析时使用。 触发词：可行性报告、品类分析、选品报告、供应链评估、跨境选品。
