# 跨境品类可行性报告 - 工作流示例

## 示例 1：母婴品类完整报告

**用户输入**：
> 我想在亚马逊上做母婴用品，你帮我出一份品类的可行性报告，看看全球趋势、供应链情况和价格段分布

**Skill 执行流程**：

1. 接收品类关键词「母婴用品」
2. 模块 A：搜索全球市场规模 → 约 $120B，CAGR 5.2%，区域拆分 NA/EU/APAC
3. Gate A 验证：≥2 来源 → 通过
4. 模块 B：四段价格段拆分 → Budget/Mid-Range/Premium/Luxury 各含锚点产品
5. Gate B 验证：每段有平台在售品 → 通过
6. 模块 C：用户痛点提取 → High/Moderate 分级，连接产品机会点
7. 模块 D：供应链评估 → OEM/ODM 覆盖率 78%，≥3 家供应商
8. Gate D 验证：供应商卡片 ≥3 → 通过
9. 模块 E：三阶段轻定制建议 → 贴标/选配/OEM 含投资门槛
10. 输出完整报告

## 示例 2：缺品类关键词 → 追问

**用户输入**：
> 帮我出一份跨境可行性报告

**Skill 执行**：
- 错误处理分支 1「缺品类关键词」→ 追问"请问要分析哪个品类？"
- 不凭空编造报告

## 示例 3：数据不足 → 降级处理

**用户输入**：
> 帮我出一份特小众品类的跨境可行性报告

**Skill 执行**：
- 搜索市场数据 → 仅 1 个来源
- Gate A 未通过 → 标注"数据来源单一，仅供参考"
- 供应商卡片不足 3 家 → 标注"建议人工核验"，给出搜索关键词
- 无法量化的指标 → 区间表达 + 置信度标注
