# cbec-product-attribute-analyzer

分析品类中哪些属性组合真正贡献销量，判断空白组合是伪机会还是真需求机会。当用户提及”属性分析”、”品类画像”、”属性组合”、”销量加权”、”市场结构”或需要产品结构机会分析时使用。 触发词：属性分析、品类画像、属性组合、销量加权、市场结构。
