# 属性组合分析参考：三维标签标准与需求验证来源

本文档定义「产品属性分析器」的三维标签标准化规则与需求端交叉验证的数据来源，供正文工作流引用。

## 三维标签标准化

打标前必须先标准化，避免同一属性出现多个叫法。

### 维度一：结构/形态

| 标准标签 | 常见别名（标准化为左侧） |
|------|------|
| 一体式 | all-in-one、集成式、一体成型 |
| 分体式 | split、分离式、可拆卸主机 |
| 穿戴式 | wearable、可穿戴、挂脖式 |
| 手持式 | handheld、便携手持 |
| 台面式 | desktop、台式、桌面款 |

> 口径：优先按「佩戴/放置方式」归类，信息不明标「未明示」。

### 维度二：材质/工艺

| 标准标签 | 常见别名 |
|------|------|
| PPSU | 聚苯砜、琥珀色奶瓶 |
| 玻璃 | glass、高硼硅 |
| 硅胶 | silicone、食品级硅胶 |
| PP | 聚丙烯 |
| 不锈钢 | stainless、316/304 |

> 口径：按主材质归类，复合材料取占比最高者，并备注次材质。

### 维度三：设计元素/功能特征

| 标准标签 | 常见别名 |
|------|------|
| 防胀气 | anti-colic、排气系统、气阀 |
| 静音 | low noise、quiet、<40dB |
| 可拆洗 | washable、易清洗、可拆卸 |
| 可折叠 | foldable、折叠收纳 |
| 大容量 | large capacity、多件套 |

> 口径：每 ASIN 可打多个功能标签；仅提取标题/五点明确提及的，不臆测。

## 需求端交叉验证来源

| 验证问题 | 可查来源（按证据强度排序） |
|------|------|
| 搜索信号 | Amazon 搜索联想、Helium 10/Jungle Scout 关键词、Google Trends |
| VoC 信号 | Amazon 评论、Q&A、Reddit 子版块、TikTok 评论区 |
| DIY/hack 信号 | 教程站、论坛改造帖、视频「如何自制/改装」、社媒 hack 帖 |
| 技术/成本障碍 | 竞品普遍缺位、价格带落差、结构复杂度、供应链可行性 |

## 结论类型判定标准

| 类型 | 判定信号 |
|------|------|
| 伪空白 | 无搜索信号 + 无 VoC 提及 + 无 DIY hack 迹象 |
| 困难空白 | 有搜索/VoC 信号，但竞品普遍缺位且存在明确技术/成本障碍 |
| 可进攻空白 | 有搜索/VoC 信号 + 供给弱 + 品牌具备切入能力（供应链/渠道/技术） |
