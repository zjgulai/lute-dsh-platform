# 使用示例

## 示例 1: 单平台淘宝订单 CSV 处理

**输入**: 淘宝后台导出的订单 CSV

```
订单编号,买家会员名,实付金额,购买数量,付款时间
TB001,张三,128.00,2,2026-03-05
TB002,李四,56.00,1,2026-03-05
```

**输出**: 标准化后的 CSV 文件 + 数据质量报告

## 示例 2: 多平台合并

**输入**: 淘宝 + 京东 + 拼多多三个平台的订单 CSV

**输出**: 合并后的统一标准格式 CSV，带 platform 来源标记

## 示例 3: 数据质量检查

**输入**: 含异常数据的订单 CSV

```
order_id,order_date,amount,sku_name,quantity
T001,2026-03-01,99.00,婴儿推车,1
T001,2026-03-01,99.00,婴儿推车,1
T002,2026-03-02,150.00,儿童安全座椅,1
T003,2026-03-03,,婴儿湿巾,5
```

**输出**: 检测到 1 条重复（T001）、1 条缺失金额（T003），生成质量报告
