# 评估维度体系（选品矩阵默认 8 维度）

本文件定义选品矩阵默认的 8 个评估维度、权重、评分 rubric 与风险标识。使用时按此体系打分，或提供自定义维度覆盖。

## 默认 8 维度

| # | 维度 | 权重 | 说明 |
|---|------|------|------|
| 1 | 需求规模 (demand_size) | 0.20 | 市场需求量与稳定性 |
| 2 | 竞争强度 (competition_intensity) | 0.15 | 竞争对手数量与强度 |
| 3 | 利润潜力 (margin_potential) | 0.15 | 扣除成本后的毛利空间 |
| 4 | 进入门槛 (entry_barriers) | 0.10 | 市场进入难度 |
| 5 | 差异化空间 (differentiation_space) | 0.12 | 产品差异化空间 |
| 6 | 趋势动量 (trend_momentum) | 0.10 | 市场趋势方向与持续性 |
| 7 | 运营适配性 (operational_fit) | 0.10 | 与现有运营/供应链匹配度 |
| 8 | 风险画像 (risk_profile) | 0.08 | 综合业务风险评估 |

权重合计 = 1.00。

## 评分 rubric（1-10 分）

每个维度按 1/3/5/7/10 五个锚点评分：

### 需求规模
- 1：需求极低、下滑趋势
- 3：需求低、仅利基市场
- 5：需求中等、稳定
- 7：需求高、增长中
- 10：需求极高、强劲增长

### 竞争强度
- 1：高度饱和、大牌主导
- 3：竞争者多、价格压力大
- 5：竞争中等、可差异化
- 7：竞争者少、市场分散
- 10：几乎无直接竞品、蓝海

### 利润潜力
- 1：毛利极低（<10%）
- 3：毛利低（10-20%）
- 5：毛利中等（20-30%）
- 7：毛利好（30-40%）
- 10：毛利优秀（>40%）

### 进入门槛
- 1：门槛极高（专利/法规/$10万+）
- 3：门槛高（认证/资本密集）
- 5：门槛中等（需技术知识）
- 7：门槛低（易采购/易销售）
- 10：门槛极低（开放市场/简单物流）

### 差异化空间
- 1：完全商品化、无法差异化
- 3：差异化有限（主要价格战）
- 5：差异化中等（功能/设计）
- 7：差异化好（创新/品牌）
- 10：创新空间广阔、独特定位

### 趋势动量
- 1：市场下滑、趋势消退
- 3：持平或略降
- 5：稳定、成熟市场
- 7：增长市场、有动能
- 10：高增长新兴品类

### 运营适配性
- 1：运营完全不匹配
- 3：匹配差、需大改
- 5：匹配中等、需部分适配
- 7：匹配好、小调整即可
- 10：与现有运营完美匹配

### 风险画像
- 1：多重不可控风险
- 3：重大风险、难以缓解
- 5：中等风险、可管理
- 7：低风险、可理解
- 10：风险极低、业务模型稳健

## 风险标识（risk_flags）

每个维度定义 low/high 风险标识，在候选数据中出现对应关键词时自动标注：

| 维度 | low 风险 | high 风险 |
|------|---------|----------|
| 需求规模 | 需求下滑趋势 | 强季节性、窗口短 |
| 竞争强度 | 高度饱和+价格战 | 新进入者快速复制 |
| 利润潜力 | 商品定价、毛利紧 | 原材料价格波动 |
| 进入门槛 | 法规/合规风险 | 品控挑战 |
| 差异化空间 | 功能易复制、无 IP | 创新需研发投入 |
| 趋势动量 | 潮流风险、周期短 | 快速演进、颠覆风险 |
| 运营适配性 | 物流复杂、供应链脆弱 | 供应商集中风险 |
| 风险画像 | 产品责任、安全隐患 | IP 侵权/专利悬崖 |

## 使用脚本

用 `scripts/run.py` 生成选品矩阵：

```bash
python3 scripts/run.py --candidates candidates.json
python3 scripts/run.py --candidates candidates.json --dimensions custom_dims.json --output matrix.json --format json
```

候选数据 JSON 格式（candidates.json）：

```json
{
  "candidates": [
    {
      "name": "便携式蓝牙音箱",
      "scores": {"demand_size": 9, "competition_intensity": 7, "margin_potential": 8, "entry_barriers": 8},
      "risks": "潜在季节性波动",
      "notes": "供应链成熟"
    }
  ]
}
```
