# 高点击率标题公式与示例

广告标题优化的核心方法论，按心理学触发机制分为五类公式。

## 1. 数字型

用具体数字制造可预期感，降低认知成本。

- 公式：`[数字] 个 [好处/结果] + [时间/条件]`
- 示例：`7 天减重 5 斤的 3 个习惯`
- 广告版：`3 个设置，让 WiFi 快一倍`

## 2. 疑问型

用问题唤起好奇，让用户带着"想知道答案"点击。

- 公式：`你 [痛点] 吗？/ 为什么 [反常识]？`
- 示例：`你的颈椎正在报警，你知道吗？`
- 广告版：`为什么聪明人都不用免费 VPN？`

## 3. 痛点型

直接戳中目标受众最痛的问题，唤起共鸣。

- 公式：`[痛点场景] + 终于 [解决方案]`
- 示例：`通勤两小时，终于能听清播客`
- 广告版：`加班到深夜，终于不再腰酸背痛`

## 4. 对比型

用反差制造张力，突出产品独特价值。

- 公式：`[旧方式] vs [新方式] / [竞品价] 的 [产品] 只要 [价]`
- 示例：`千元音质，三分之一价格`
- 广告版：`别人卖 999，我们只卖 299`

## 5. 命令型

用强动词直接下达行动指令，降低决策门槛。

- 公式：`[动词] + [对象] + [结果]`
- 示例：`别再乱买瑜伽垫了`
- 广告版：`点一下，今天就睡个好觉`

## 情感触发词库

| 情绪 | 触发词 |
|------|--------|
| 焦虑/恐惧 | 失去、落后、风险、紧急、错过 |
| 欲望/希望 | 提升、蜕变、逆袭、机会 |
| 归属/认同 | 同类、圈子、懂你、专属 |
| 成就感 | 拿下、搞定、进阶、第一 |

## 使用原则

1. 一个标题只用一种主导公式，避免堆砌
2. 触发词要贴合目标受众的真实语境，避免空喊
3. 落地页与标题承诺一致，避免"标题党"导致高跳出
4. A/B 测试时一次只变一个变量（公式或触发词），才能归因
