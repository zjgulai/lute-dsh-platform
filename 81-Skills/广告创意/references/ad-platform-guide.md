# 广告平台规范与字符限制速查

本文件列出各主流广告平台的文案规范与字符限制，供跨平台合规检查时参考。

## Facebook / Instagram（Meta Ads）

| 位置 | 限制 | 说明 |
|------|------|------|
| Primary Text | 125 字符（移动端截断） | 首 125 字符最关键，之后折叠 |
| Headline | 40 字符 | 移动端可能只显示前 25-40 |
| Description | 30 字符 | 部分版位不显示 |
| Link Description | 27 字符 | 已逐步废弃 |

**审核要点**：避免过度承诺（如"保证月入过万"）、避免含违法药品/赌博内容、避免使用用户个人属性（"你孤独吗"）。

## Google Search Ads（RSA 自适应搜索广告）

| 位置 | 限制 | 说明 |
|------|------|------|
| Headline | ≤30 字符 ×15 条 | 系统自动组合测试 |
| Description | ≤90 字符 ×4 条 | 建议写满 |
| Display URL path | 15 字符 ×2 | |

**审核要点**：标点符号使用规范、不得使用"最佳/第一"等绝对化用语（需资质）、不得夹带第三方商标。

## TikTok Ads

| 位置 | 限制 | 说明 |
|------|------|------|
| 视频时长 | 5s-60s（信息流） | 前 3 秒决定留存 |
| 文案 | 通常 ≤100 字符 | 鼓励短句 + emoji |
| CTA | 按钮式（了解详情/立即购买等） | 系统预设 |

**审核要点**：UGC 风格优先、避免过度剪辑的硬广质感、音乐需有商用授权。

## 朋友圈广告（微信）

| 位置 | 限制 | 说明 |
|------|------|------|
| 外层文案 | 40 字内 | 移动端友好 |
| 图文/视频 | 6 图或 1 视频 | |

**审核要点**：不得诱导分享、不得夸大功效、医疗/金融类需特殊资质。

## 通用合规红线（各平台一致）

1. 不得使用绝对化用语（"最好/第一/唯一/顶级"）除非有权威佐证
2. 不得虚假宣传、夸大功效
3. 不得侵犯他人肖像权、商标权、著作权
4. 医疗、金融、教育等特殊行业需前置资质
5. 成人、烟草、赌博类禁止投放

> 以上限制会随平台政策更新，投放前以各平台最新广告政策为准。
