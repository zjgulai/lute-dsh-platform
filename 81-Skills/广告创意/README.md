# mkt-ad-creative

广告创意文案生成 Skill

## 功能

- 生成多平台广告文案（Facebook、Google、TikTok）
- 提供创意概念发想
- 生成 A/B 测试文案变体
- 优化广告标题

## 使用场景

- 需要为新产品创建广告文案
- 进行广告 A/B 测试
- 优化现有广告标题
- 生成多版本创意概念

## 触发方式

当用户提及以下关键词时触发：
- "广告文案"
- "投放文案"
- "创意概念"
- "A/B 测试文案"
- "广告标题"

## 输入要求

- 产品信息与卖点
- 目标受众画像
- 品牌调性指南
- 投放平台要求

## 输出交付物

- 多版本广告文案
- 创意概念方向
- 广告标题选项
- A/B 测试方案
