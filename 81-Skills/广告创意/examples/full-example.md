# 完整示例：从输入到多版本广告文案

## 场景

一款智能手表的投放文案，目标受众 25-35 岁上班族，投放 Facebook。

## 输入

```
产品：智能手表（原价 1299 元，活动价 899 元）
核心卖点：心率监测、睡眠分析、运动模式、7 天续航
目标受众：25-35 岁上班族，关注健康与效率
品牌调性：专业、克制、可信赖
投放平台：Facebook
```

## 输出

### 版本 A（功能导向）

> 心率、睡眠、运动，一块表全掌握。7 天续航，出差不用带充电器。

### 版本 B（情感导向）

> 忙到忘记照顾自己的你，值得一块懂你的表。

### 版本 C（价格导向）

> 千元级智能表，双 11 到手 899，限时直降 400。

### 版本 D（社交认同）

> 100 万职场人已经在戴了，就差你一块。

### 版本 E（送礼场景）

> 送 TA 一块懂健康的表，比一句"多喝热水"更实在。

## 配套建议

- **首投建议**：版本 A（功能）+ 版本 C（价格）先跑，数据驱动的理性受众对功能与价格敏感
- **测试变量**：第一轮测角度（功能 vs 价格 vs 情感），第二轮测素材（图片 vs 视频）
- **优化指标**：CTR 看文案吸引力，CVR 看落地页承接，两者要配套看

## 标题优化示例

原标题：`优质智能手表热卖中`

| 公式 | 优化后 |
|------|--------|
| 数字型 | `续航 7 天的智能表，通勤族都在戴` |
| 痛点型 | `戴了 3 年手环，终于换成能测心率的表` |
| 对比型 | `1299 的表，今天 899 带走` |
| 命令型 | `别只看手环了，升级一块真智能表` |
