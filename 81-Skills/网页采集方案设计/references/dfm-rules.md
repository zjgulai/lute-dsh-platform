# DFM Rules for Web Data Audit Designer

## 字段裁剪决策矩阵 (Decision Matrix)

| 维度 | 权重 | 高分特征 | 低分特征 |
|------|------|---------|---------|
| 业务价值 | 40% | 直接支撑口碑监控/差评预警/客服效率/产品问题发现 | 仅展示用途、无分析场景 |
| 获取稳定性 | 30% | DOM结构稳定、无复杂交互、不依赖弹层 | 高频改版区、仅偶现 |
| 标准化难度 | 20% | 易清洗、易归一、易转结构化类型 | 自由文本、多语言混杂 |
| 长期维护成本 | 10% | 选择器基于data属性/ID，不受前端框架影响 | 依赖CSS类名、JavaScript渲染 |

## 字段保留/剔除速查表

| 字段类型 | 保留条件 | 剔除条件 |
|---------|---------|---------|
| 文本字段 | 核心内容（标题/正文/描述） | 模板生成文本（版权声明等） |
| 数字字段 | 价格/评分/计数等可量化指标 | 展示类数字（页面浏览量等） |
| 时间字段 | 发布时间/回复时间/状态变更 | 服务器时间/缓存时间 |
| 标识字段 | 业务ID/URL | 内部自增ID |
| 用户字段 | 昵称/角色 | 头像URL/徽章/等级 |
| 图片字段 | 主图URL（仅URL） | 缩略图/装饰图 |

## 质量审计阈值速查

| 指标 | 默认阈值 | 告警阈值 |
|------|---------|---------|
| 核心字段完整率 | ≥98% | <95% |
| 页面覆盖率 | ≥90% | <85% |
| 翻页重复率 | ≤15% | >30%连续3页 |
| 采集成功率 | ≥95% | <90% |
| 数据时效性 | ≤采集频率×2 | >48h |
