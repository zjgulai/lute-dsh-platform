# 供应商评估示例

## 示例 1：1688 店铺快速评估

用户输入：帮我查一下这家 1688 店铺的背景，链接是 https://shop123.1688.com，主营不锈钢水杯。

Skill 输出：店铺画像报告（店铺基础信息、交易等级、评价质量）+ 初步风险建议。

## 示例 2：深度准入评估

用户输入：对深圳市华强电子有限公司做供应商背景调查，我要采购一批充电宝配件。

Skill 输出：完整评估报告（工商信息核查 → 供应能力 → 质量合规 → 风险矩阵）+ 准入建议 + 验厂清单。

## 示例 3：供应商对比

用户输入：我手上有 3 家玻璃杯供应商的资料，帮我对比哪家更值得合作。

Skill 输出：对比矩阵（多维度评分排名）+ 推荐排序 + 备选推荐。
