# SCM Supplier Evaluator - 供应商评估专家

1688背景调查、验厂评估、准入决策支持。提供供应商画像、风险评估与准入建议。

## 快速开始

### 基本用法

```
# 1688店铺快速评估
提供：1688店铺链接 + 产品需求
输出：店铺画像 + 初步风险评估

# 深度准入评估
提供：公司全称 + 合作规模 + 产品要求
输出：完整评估报告 + 准入建议 + 验厂清单

# 供应商对比
提供：2-3家供应商信息
输出：对比矩阵 + 推荐排序
```

## 核心功能

- **1688店铺分析**: 店铺基础信息、主营产品分析、历史交易数据、买家评价分析
- **企业工商信息核查**: 工商注册验证、注册资本、经营范围、法律诉讼
- **供应能力评估**: 产能与交付能力、MOQ、打样周期、大货交期
- **质量与合规评估**: 国标符合性、质检报告、ISO认证
- **风险评估**: 经营稳定性、质量一致性、交付准时性

## 输入输出

**输入**:
- 1688店铺链接/ID
- 供应商公司名称
- 产品类别与需求
- 合作规模预期

**输出**:
- 供应商画像报告
- 风险评估矩阵
- 准入建议(通过/谨慎/拒绝)
- 验厂Checklist
- 备选供应商推荐

## 注意事项

1. 评估依赖1688公开数据，深度尽调需人工补充
2. 店铺数据可能滞后，建议结合实时沟通
3. 不能替代正式法务审核
4. 高价值合作务必实地验厂
5. 建议每季度回顾供应商表现
