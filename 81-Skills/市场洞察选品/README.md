# cbec-market-insight-selector

为 Momcozy 在 Amazon 与 Shopify DTC 之间做新品方向判断，考虑品牌协同、复购潜力、渠道打法和竞争空白。当用户提及"选品"、"市场洞察"、"市场机会"、"产品方向"、"新品规划"或需要战略级选品决策时使用。 触发词：选品、市场洞察、市场机会、产品方向、新品规划、趋势判断。
