# Minimal Skill

最简 Skill 示例，适用于简单知识型任务。

## Structure

```
minimal-skill/
├── README.md
├── SKILL.md
├── .skill-meta/
│   └── manifest.yaml
├── references/
│   └── .gitkeep
├── examples/
│   └── .gitkeep
├── scripts/
│   └── .gitkeep
└── tests/
    └── .gitkeep
```

## Usage

Copy this template for simple skills (less than 2000 characters).
