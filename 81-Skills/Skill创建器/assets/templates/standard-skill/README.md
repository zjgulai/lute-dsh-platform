# Standard Skill

标准 Skill 示例，适用于中等复杂度场景（2000-5000 字符）。

## Structure

```
standard-skill/
├── README.md
├── SKILL.md
├── .skill-meta/
│   └── manifest.yaml
├── references/
│   └── patterns.md
├── examples/
│   └── .gitkeep
├── scripts/
│   └── .gitkeep
└── tests/
    └── .gitkeep
```

## Features

- 标准目录结构
- references/ 存放参考文档
- examples/ 存放使用示例
- scripts/ 预留脚本目录

## Usage

Copy this template for standard skills.
