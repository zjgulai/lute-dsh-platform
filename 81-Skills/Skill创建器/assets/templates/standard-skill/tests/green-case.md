## 与 REFACTOR 的关系

- GREEN 通过 ≠ 可发布
- REFACTOR 阶段需要：边界场景、错误处理、反例输入、长输入、模糊请求等压力测试
- REFACTOR 通过后才提交 `lute-skills-eval` 评分

## 归档

- GREEN 通过后，本文件作为 Skill 的 baseline 证据保留
- 后续 Skill 改版时，必须重新跑同一 GREEN，确保不退化
- 出现退化时：把本文件改名为 `green-case-v{n}.md`，新版另存
