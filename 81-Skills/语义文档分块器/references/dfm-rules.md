# 文档分块规则 (DFM Rules)

本文档定义语义文档分块器在分块过程中的判断规则与优先决策树。

## 决策树

```
输入文档
  ├── 无标题层级 → 报错：需添加标题或改用固定长度切分
  ├── 有标题，但 < 1000 tokens → 不分块，直接返回单块
  ├── 有标题，>= 1000 tokens
  │   ├── 阶段1：在 H1/H2 处粗分
  │   ├── 阶段2：对超限块递归细分
  │   │   ├── 块 > max_tokens → 在子标题处细分
  │   │   │   ├── 无子标题 → 在段落边界处二分
  │   │   │   └── 迭代次数 > max_iterations → 强制二分，标注警告
  │   │   └── 块 <= max_tokens → 完成
  │   └── 阶段4：附加元数据 (id, parent_path, start/end_line, tokens)
  └── 输出 chunks + tree
```

## 关键规则

1. **段落完整性优先**：分割点永远不在段落中间，必须调整到最近的段落边界。
2. **标题层级保护**：子标题永远不脱离父标题的 chunk，即在 H2 处分割时，H2 以下的所有 H3/H4 都跟随该 H2。
3. **标题跳跃处理**：遇到 `# 标题` 后直接接`### 子标题`（无 H2），自动在 H2 处插入虚拟标题"未命名".
4. **Token 估算**：中文 2 chars/token，英文 4 chars/token。混合文档按字符比例加权。

## 边界情况

- 文档只有 1 个 H1 但没有子标题：整个文档作为 1 个 chunk
- 文档标题层级很深（6 级）：最内层标题作为 chunk 的 title
- 文档含代码块：代码块内的 `#` 注释不视为标题
