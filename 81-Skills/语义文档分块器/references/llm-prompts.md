# LLM Prompt 模板

## Phase 1: 章节分割点分析

### System Prompt

```
你是一个文档结构分析专家。你的任务是分析 Markdown 文档的标题结构，决定最佳的文本分割点。

目标：将文档分割为逻辑上完整、大小适中的块，便于后续处理和分析。
```

### User Prompt Template

```markdown
## 文档统计
- 总字符数：{total_chars:,}
- 预估 Tokens：{estimated_tokens:,}
- 目标块大小：不超过 {max_tokens:,} tokens
- 标题数量：{header_count}

## 标题结构（含行号）
```
{header_tree}
```

## 任务
分析标题结构，识别 **SPLIT POINTS**（分割点）- 即新块应该开始的行号。

### 分割规则
1. **大小限制**：每个块应不超过 {max_tokens:,} tokens（约 {max_chars:,} 字符）
2. **逻辑边界**：优先在章节边界处分割，不要在段落中间切断
3. **层级优先**：优先在高层级标题（一级、二级）处分割
4. **内容完整**：保持相关内容的完整性，不要把同一个主题拆分到两个块

### 输出格式
返回 JSON 对象：
```json
{
  "split_points": [行号1, 行号2, ...],
  "reasoning": "分割理由简述（中文）",
  "estimated_chunks": 预估块数量
}
```

注意：
- 第一个块总是从第 1 行开始，所以 split_points 不需要包含 1
- 行号必须是标题结构中存在的行号
- 确保相邻分割点之间的内容不超过大小限制

返回 ONLY JSON，不要其他文本。
```

### Few-Shot Example

**输入示例**：
```
标题结构：
[Line 1] # 第一章 绪论
[Line 25] ## 1.1 研究背景
[Line 80] ## 1.2 研究意义
[Line 150] # 第二章 文献综述
[Line 300] # 第三章 研究方法
```

**输出示例**：
```json
{
  "split_points": [150, 300],
  "reasoning": "在章节边界分割：第一章（绪论）约6000 tokens，第二章（文献综述）可能较大，第三章单独成块",
  "estimated_chunks": 3
}
```

## Phase 2: 锚点生成

### System Prompt

```
你是一个精确的文本分割助手。你的任务是阅读一段长文本，识别逻辑分割点，并为每个分割点提供一个精确的锚点文本。

锚点文本必须是原文中存在的连续字符序列，用于在原文中精确定位分割位置。
```

### User Prompt Template

```markdown
## 块信息
- 当前标题：{title}
- 父级路径：{parent_path}
- 内容长度：{content_length:,} 字符（约 {estimated_tokens:,} tokens）
- 目标大小：{target_tokens:,} tokens

## 需要分割的内容
```
{content}
```

## 任务
识别 2-4 个逻辑分割点，为每个点提供一个 **ANCHOR**（锚点）。

### 锚点要求
1. **精确性**：锚点必须是原文中 {anchor_length} 个字符的**精确**片段
2. **唯一性**：选择具有识别性的文本序列，避免常见短语
3. **边界位置**：锚点应位于逻辑边界处（段落之间、主题转换处）
4. **可复制**：直接复制原文，不要修改任何字符

### 输出格式
```json
{
  "anchors": [
    {
      "anchor": "原文中恰好{anchor_length}个字符的片段",
      "description": "此锚点位置的内容简述（如：在第二节之前）"
    },
    ...
  ]
}
```

### 示例
**文本片段**：
```
第二节 理论基础

本研究的理论基础包括...

第三节 实验设计

实验采用双盲设计...
```

**正确锚点**：
```json
{
  "anchors": [
    {"anchor": "第二节 理论基础\n\n本研究的", "description": "在第二节之前"},
    {"anchor": "第三节 实验设计\n\n实验采用", "description": "在第三节之前"}
  ]
}
```

**错误锚点**：
- ❌ "第二节"（太短，不唯一）
- ❌ "理论基础"（可能在多处出现）
- ❌ "第二节 理论基础"（人工简化，非原文精确复制）

返回 ONLY JSON，不要其他文本。
```

## Prompt 调优建议

### 1. 温度设置

- **章节分割**：`temperature=0.3`（需要一致性）
- **锚点生成**：`temperature=0.1`（需要精确性）

### 2. Token 估算

中文文档：`tokens ≈ chars / 2`
英文文档：`tokens ≈ chars / 4`

### 3. 错误处理

当 LLM 返回无效响应时：
1. 重试 1-2 次
2. 如果仍然失败，使用默认策略（在章节标题处分隔）
3. 记录警告日志

### 4. 性能优化

对于超大文档（>100k tokens）：
- 先进行粗粒度章节分割
- 只对超大块进行锚点细分
- 避免一次性处理全部内容
