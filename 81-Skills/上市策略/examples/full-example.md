# 端到端完整交付示例

> 场景：一款面向新手妈妈的便携吸奶器准备上市，进入美国市场。以下为该场景下 `上市策略` 技能的标准交付结构（示例，非真实数据）。

## 输入（用户提供）

- 产品：便携式电动吸奶器（可穿戴、静音、多档位）
- 目标市场：美国（母婴品类）
- 目标人群：0-1 岁宝宝的新手妈妈
- 发布时间：8 周后；预算：$20,000

## 交付物 1：GTM 方案

- **市场定位**：为「背奶上班、夜里亲喂」的新手妈妈提供「解放双手、安静无感」的穿戴式吸奶方案。
- **目标客户细分**：① 返岗背奶妈妈（最痛、付费意愿高）② 夜间亲喂妈妈 ③ 二胎时间紧张的妈妈。
- **定价策略**：价值定价，对标同类穿戴式吸奶器（$150-$200 区间），首发价 $179 + 早鸟折扣。
- **渠道优先级**：① 亚马逊（主力成交）② 母婴垂直社区（Reddit r/breastfeeding、Facebook 妈妈群）③ TikTok 种草（短视频演示）。

## 交付物 2：发布时间线

- **T-4 周**：landing page + waitlist 上线；Reddit/知乎母婴区软性铺垫；3 名母婴 KOC 确认。
- **T-2 周**：早鸟内测 50 名种子妈妈；Amazon 页面预上架；PR 稿件 + 媒体名单。
- **Launch Day**：亚马逊正式开卖 + 社媒同步 + 邮件序列触发。
- **T+2 周**：数据复盘（转化率/退货率/评论）→ 广告扩量 → 用户反馈收集。

## 交付物 3：渠道策略

- 付费：Amazon PPC + TikTok Spark Ads，预算 60%，素材 A/B 测试。
- 内容：短视频演示（穿戴/清洗/静音对比）+ 妈妈日记类 UGC。
- 合作：3 名 KOC 佣金置换 + affiliate 计划。
- PR：母婴媒体评测样机 10 台。

## 交付物 4：增长实验计划

- **北极星指标**：周活跃「完成一次吸乳」的用户数。
- **实验 1**（高 ICE）：落地页 A/B ——「解放双手」vs「安静无感」主文案，看 waitlist 转化。
- **实验 2**：新用户 7 天激活引导（教学视频 vs 图文），看首周吸乳完成率。
- **实验 3**：邀请得配件（老带新），看 K 因子与获客成本。
