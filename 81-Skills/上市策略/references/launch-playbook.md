# 上市策略 · 渠道打法参考手册

本手册是 `SKILL.md` 的渐进式披露第三层，仅在需要落地细节时读取。正文已点名引用本文件。

## 1. GTM 策略落地清单

1. **市场定位**：一句话说清「为谁、解决什么、凭什么赢」。定位公式：目标人群 + 核心痛点 + 差异化优势。
2. **目标客户细分**：按可触达性、付费意愿、痛点强度切分，优先服务「最痛且最易触达」的细分。
3. **定价策略**：成本加成 / 价值定价 / 竞争定价 / 订阅制，按品类与竞争格局选主策略并说明理由。
4. **渠道优先级**：按「触达效率 × 转化率 × 成本」排序，先集中 1-2 个主渠道打透，再横向扩展。

## 2. 冷启动打法

- **种子用户获取**：创始人朋友圈、垂直社区（Reddit/知乎/即刻）、KOC 置换、等候名单（waitlist）。
- **病毒传播机制**：内置分享钩子（邀请得权益、双人拼团、内容自传播），让 K 因子 > 1。
- **早期用户激活**：定义激活事件（如「完成首次核心动作」），7 天内完成激活的引导序列。
- **口碑传播**：NPS 追踪、用户故事征集、老带新激励。

## 3. 渠道分发方案

| 渠道类型 | 适用阶段 | 关键动作 |
|---|---|---|
| 付费渠道 | 放大期 | 素材 A/B 测试、受众分层、预算上限 |
| 内容营销 | 预热期~长期 | SEO 长文、社媒矩阵、行业报告 |
| 合作/联盟 | 预热期 | KOL、affiliate、渠道分成 |
| PR/媒体 | 发布日前后 | 稿件、媒体名单、评测样机 |

## 4. 增长实验设计

- **北极星指标**：唯一反映真实价值的核心指标（如「周活跃完成核心动作的用户数」），而非虚荣指标。
- **实验优先级矩阵**：ICE 评分（Impact × Confidence × Ease），先做高影响低成本的实验。
- **A/B 测试**：单变量、足够样本量、设定显著性阈值（p<0.05），实验前先写假设。
- **增长循环**：获客 → 激活 → 留存 → 推荐 → 回流，找最弱一环优先优化。

## 5. 发布节奏（T 倒推）

- T-8 周：定位与目标确认
- T-4 周：预热（landing page、waitlist、KOL 确认）
- T-2 周：早鸟（内测、Product Hunt 准备、PR 稿件）
- T-0：发布日全渠道同步
- T+2 周：复盘与放大（数据复盘、广告扩量、反馈收集）

## 6. 常见坑（失败案例）

1. **过早烧付费**：产品留不住用户时盲目投广告，ROI 归零。先验证留存再放大。
2. **虚荣指标自嗨**：只看注册量不看激活/留存，增长假象掩盖产品问题。
3. **渠道贪多**：同时铺 5 个渠道，资源稀释，每个都打不透。
4. **无实验假设**：拍脑袋改版，无法归因，改进不可复现。
