# mkt-launch-strategy

产品发布策略与增长实验设计 Skill

## 功能

- GTM 策略制定
- 冷启动策略
- 渠道分发方案
- 增长实验设计

## 使用场景

- 新产品上市
- 新市场进入
- 众筹/预售启动
- 重大功能更新发布

## 触发方式

当用户提及以下关键词时触发：
- "产品发布"
- "GTM 策略"
- "冷启动"
- "增长实验"
- "launch plan"

## 输入要求

- 产品信息
- 目标市场
- 竞争环境
- 发布目标与时间

## 输出交付物

- GTM 完整方案
- 发布时间线
- 渠道策略
- 增长实验计划
