# SEO Multilingual - 多语言SEO优化工具

提供hreflang标签配置、多语言站点架构、地域定向优化、跨境SEO策略等国际化优化方案。

## 快速开始

### 基本用法

```
# hreflang配置生成
提供多语言页面列表 → 输出完整hreflang代码

# 站点架构规划
提供目标市场 + 当前架构 → 输出架构建议

# 地域定向优化
提供URL + 目标国家 → 输出地域优化方案

# 多语言SEO审计
提供多语言站点 → 输出审计报告
```

## 核心功能

- **hreflang标签配置**: 语言-地域代码生成、格式检查、x-default设置
- **多语言站点架构**: 子目录/子域名/ccTLD选择、URL结构规划
- **地域定向优化**: 地理定位标签、本地内容策略、货币与价格
- **跨境SEO策略**: 各国搜索引擎优化、本地化关键词、文化适配

## 输入输出

**输入**:
- 多语言页面URL列表
- 目标市场/语言
- 当前站点架构

**输出**:
- hreflang配置方案
- 多语言站点架构建议
- 地域定向策略
- 实施检查清单

## 架构对比

| 架构类型 | SEO权重 | 维护成本 | 推荐场景 |
|---------|---------|---------|---------|
| 子目录(/en/) | 集中 | 低 | 推荐 |
| 子域名(en.) | 分散 | 中 | 大型站点 |
| ccTLD(.co.uk) | 独立 | 高 | 本土化 |

## 使用场景

- 多语言站点搭建
- 跨境电商SEO
- 地域流量优化
- 语言版本冲突解决

## 注意事项

1. hreflang必须使用正确的ISO代码格式
2. 所有语言版本必须互相引用(双向验证)
3. 必须设置x-default指向最通用版本
4. 不要在同一页面混合多种hreflang实现方式
