# 子Skill详细说明

本文件记录 电商分析主控 统筹的5个子Skill的输入输出契约，供协调器路由时查阅。

## ecom-csv-processor（CSV数据预处理）

- **触发场景**: 原始订单CSV格式混乱、字段映射错误、多平台数据需合并
- **输入**: 任意格式订单CSV（多平台、多字段）
- **输出**: 标准化的干净CSV（统一字段、清洗后）
- **关键词**: csv、订单、导入、上传、处理、字段映射、多平台合并

## ecom-daily-report（日报/周报生成）

- **触发场景**: 日常监控、晨会数据、异常预警
- **输入**: 1-7天订单CSV
- **输出**: 日报/周报（销售额、订单量、退货率、环比）
- **关键词**: 日报、周报、daily、今天、昨天、今日、昨日、晨会

## ecom-monthly-review（月度复盘分析）

- **触发场景**: 月度KPI、趋势分析、问题诊断
- **输入**: 30天订单CSV
- **输出**: 月度复盘报告（KPI达成、趋势、问题诊断）
- **关键词**: 月报、月度、monthly、本月、上月、复盘

## ecom-quarterly-strategy（季度战略分析）

- **触发场景**: 季度总结、战略规划、年度对比
- **输入**: 90天订单CSV
- **输出**: 季度战略报告（阶段总结、战略方向、年度对比）
- **关键词**: 季度、quarterly、战略、规划、策略、总结

## ecom-promo-analysis（大促活动分析）

- **触发场景**: 活动复盘、ROI分析、促销优化
- **输入**: 活动期订单CSV + 成本数据
- **输出**: 活动效果报告（ROI、流量转化、促销优化建议）
- **关键词**: 大促、促销、promo、活动、双11、黑五、prime day、ROI
