# ADR-0042 · 外部插件注册 `settings.section` 必须走 `slots.inject`；直接 `register` 会静默丢行

- 状态：accepted
- 日期：2026-09-12
- 决策者：用户（要求设置页新增「算法技能」页并目视验收）+ agent（验收前实测压出）
- 决策记录：[Note](../notes/implemented/contract/2026-09-12-settings-slot-must-inject.md)

## 背景

新页 `dsh-algo-skills-local` 的宿主半边**完全正常**：`/api/dsh-algo-skills/health` 连着 200，
`/tree` 848 KB / 1338 张卡，`dsh-market` 热挂载日志写下 `hot-mounted dsh-algo-skills-local`，
`pnpm run gate` 15/15 绿。客户端半边也**被宿主加载了**：实测 `/plugins/events`（该端点不做鉴权）
返回的模块图里，`dsh-algo-skills-local` 的 rev 是 `ee2bc9fd2273`，条目在 74 条之中。

但设置页侧边栏里没有这一行。

原因在客户端 `apply` 的注册方式：它直接调 `ctx.slots.register({ name: 'settings.section', ... })`，
而槽注册表的纯核心在被注册的键**尚未被声明**时是硬抛的：

```
Error: slot "settings.section" is not declared (a parent entry's children table must declare it)
```

外部插件的 `apply` 跑在设置外壳声明这个键**之前**。抛出被插件自己的 `catch` 接住，
落成一条 `console.warn`，装配继续、页面照常启动——row 从未出现，且没有任何一处报错。

仓库里其余 5 处 `settings.section` 注册（`dsh-overseas-skills` ×2 / `dsh-theme-local` /
`dsh-agent-team-gui-local` / `dsh-wanzh-hulian`）**无一例外**都包在
`ctx.slots.inject('settings.section', () => ctx.slots.register(...))` 里。

同时实测纠正 [ADR-0041](ADR-0041.md) 的一条假设：该包**不需要宿主重启**。`dsh-market` 的
toggle 走热挂载（`restart:false / refresh:true`，`activation.state=live`），落盘副作用只有
用户 patch 层 2 行；后续每次启动由 bundle 层正常加载，两种路径状态一致。

## 决策

**面向槽位注册的外部插件，一律用 `ctx.slots.inject(key, () => ctx.slots.register(...))`，
不得裸调 `ctx.slots.register`。**

1. `inject` 是**等待声明**的语义，不是语法糖：声明已存在时同步执行回调，否则在声明提交后执行；
   控制器挂在调用方 fiber 上，插件卸载会取消等待并摘掉已生效的贡献。
2. `register` 保留在回调内，**不额外包 `ctx.effect`**——`inject` 自己就装在 `ctx.effect` 里，
   再包一层会让等待语义被外层 effect 的时序覆盖。
3. `try/catch` 留在**回调内部**：`inject` 在声明已存在时是同步执行的，回调里漏出的异常会直接
   冲进外壳启动流程。本包的策略不变——最坏情况是少一行，不是把 GUI 带下去。
4. 判据是「行为」而不是「写法」：新增面向槽位的插件，验收必须包含一条**声明前挂载**的断言
   （`tests/client-mount.spec.ts`），而不是只测注册参数。

## 备选方案

- **直接 `register`，靠捕获兜底**：就是本次的缺陷形态。捕获把失败翻译成了静默，
  宿主 200、日志无异常、门禁全绿，只有人眼能发现少了一行。
- **把 `settings.section` 的声明提前**：要改官方设置外壳的装配顺序，属于
  [ADR-0008](ADR-0008.md) 的 pin 面，代价与收益不成比例。
- **插件自己重试注册**：手写轮询/定时器复刻 `inject` 的语义，且拿不到声明 epoch，
  声明折叠重建时会漏掉重挂。
- **在宿主半边顺带注册一行**：客户端槽位只能由客户端注册；绕过等于把 UI 结构搬进 host。

## 后果

正面：缺陷的成因与判据各有一处家；`tests/client-mount.spec.ts` 用**忠实复刻核心语义**的
替身（声明前 `register` 抛、`inject` 延迟）把它钉死——把实现改回裸 `register`，
该文件 3 条立即转红。同型判据可被后续任何槽位插件复用。

负面：`inject` 的失败面比裸 `register` 宽一档（回调抛异常会经 `queueMicrotask` 重抛），
所以第 3 条不是可选项而是配套义务。

后续：设置页的目视验收仍待用户完成；验收通过后再启动出海技能按
场景 → 4 面 → 岗位 的重构（见 [ADR-0041](ADR-0041.md) 后果节）。
