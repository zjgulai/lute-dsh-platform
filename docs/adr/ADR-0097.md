# ADR-0097 · Mutation test 只在自有临时根提交副作用

- 状态：accepted
- 日期：2026-09-16
- 决策者：用户（lute）+ agent
- 决策记录：[Note](../notes/implemented/contract/2026-09-16-mutation-fixture-isolation.md)
- 相关：ADR-0014（门禁硬门槛）、ADR-0094（canonical gate result）、总账 P-31、QG-006A

## 背景

门禁的 mutation test 本来用于证明 checker 能说“不”，但其中四条路径会反过来污染被测环境：
`scripts/gate.test.mjs` 覆写真实根 `package.json` 后再写回旧字节，Settings 判据把固定 mutant
写进真实 `scripts/acceptance/`，worktable 自测覆写真实 pin 后恢复，`agent-fullstack` 的局部 fixture
仍通过缺省参数读取真实 `~/.dsh/skills`、desktop profile 与本机图标清单。另有六组 `mkdtemp`
fixture 没有 cleanup。

“finally 写回旧字节”不是隔离：若另一个进程在测试期间合法修改同一文件，finally 会把它覆盖。
固定 mutant 也会让两次并发测试互相删除。动态运行旧 Red 本身就可能制造事故，因此 QG-006A
先以源码位置和调用路径锁定 Red，再在隔离根重现相同缺陷形状。

## 决策

1. 新增 `scripts/lib/mutation-fixture.mjs` 作为 mutation fixture 的公共基础设施。每个 case 取得唯一
   `mkdtemp` 根及独立 `repo/home/profile/tmp`；临时父目录不得位于当前 checkout 或真实 HOME 下。
2. 生命周期固定为 `create → prepare → commit → cleanup`。prepare 半失败、checker/assertion 抛错和
   cleanup 失败都保留原错误；不通过“恢复真实文件”收尾。
3. fixture path 只接受封闭 scope 与逐段子路径，拒绝绝对路径、traversal、控制字符、非 NFC 与
   symlink 穿越。cleanup 在递归删除前复核根目录的 canonical path 与 dev/inode；pathname 被替换时
   fail-closed，绝不删除后来者。
4. 当前已存在的污染点全部迁移：根包身份负例直接对临时 repo 的显式 manifest collection 运行；
   Settings 探针与 `real-node.mjs` 复制到临时 repo 并注入临时环境；worktable 在临时 repo 中创建最小
   Git vendor；fullstack 局部 checker 显式传入临时 skills/profile/icon roots。六组无 cleanup fixture
   改用 owned fixture。
5. 真实仓库或 live profile 只允许作为标明边界的 L2 read-only 正控，不能成为 mutation target。
   QG-002..005、QG-010..012 后续新增的 mutation case 必须消费同一隔离契约；聚合并发、SIGTERM
   与完整工作树 before/after snapshot 仍属于 QG-006B，不能由本决策冒充。
6. 根 gate 登记 `mutation-fixture-selftest`，验证生命周期、路径围栏、根唯一性、prepare/commit 异常、
   cleanup ownership 与“assertion + cleanup 双失败”。QG-006A 的基础设施可以先完成；尚未实现的业务
   mutation 由各自 QG ticket 接入，并在 QG-006B 做最终聚合证明，避免形成循环依赖。

## 备选方案

- 保留真实文件覆写并在 finally 恢复：会覆盖并发合法写入，否决。
- 只给固定 mutant 加随机后缀：仍在 checkout 内写测试产物，且真实 HOME/profile 缺省读取未解决，否决。
- 每个测试各写一套 `mkdtemp + rm -rf`：ownership、symlink 与半失败语义会继续分叉，否决。
- 在 QG-006A 同时实现聚合并发和 SIGTERM snapshot：那是 QG-006B 的独立验收边界，本批不越权。

## 后果

- mutation case 不再需要保存和回写真实文件；测试失败也只影响自己拥有的临时根。
- package manifest 的完整判定面被提为可注入 repo root 的 `collectManagedManifests()`，根包 `.` 不再由
  CLI 临时拼接。
- fixture 生命周期自测 8/8、根 `test:gate` 408/408；四类污染点与六组 cleanup 迁移均进入同一测试链。
- 本决策不证明完整 gate 在并发/SIGTERM 下零副作用，不证明 live UI，也不修改真实 `~/.dsh`、DMG、
  Release 或远端设置。
