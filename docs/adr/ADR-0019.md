# ADR-0019 · 对官方 UI 的改写锚必须运行时解析，禁止把 CSS-module 哈希写进产品代码

- 状态：accepted
- 日期：2026-09-11
- 决策者：用户（lute）+ agent（现场取证 + 对照实验后提出）
- 决策记录：[Note](../notes/implemented/architecture/2026-09-11-root-brand-live-resolver.md)

## 背景

`dsh-root-brand` 品牌皮肤需要隐藏官方空会话 hero 的原生标题与预览角标（二者都是 conversation 包的私有 locale 键，既非公开 slot、也不在可被插件注册的公开命名空间）。原实现把**构建期算出的 CSS-module 哈希类名**写进插件的 CSS 常量：

```
._37cUPa_headlineText, ._37cUPa_previewBadge { display: none; }
._37cUPa_headline { grid-template-columns: auto; }
```

基座由 DSH Desktop 2.0.4 升到 2.0.5 后，官方 conversation 客户端重新构建，前缀由 `_37cUPa_` 变为 `zNic4G_`（实测：2.0.4 归档 `.orig` 与 `/Applications/DSH Desktop.app` 内产物逐字比对），规则整体 miss，产生三个后果：

1. 官方标题不再被隐藏，而它的文案已被 `brand-replay.sh` 改写成同一句 → 用户看到同一句话出现两次；
2. 官方预览角标不再被隐藏 → 右上角显示「预览版」而非 `Preview`；
3. 同一根因还打掉 `dsh-client-ui-chat` 的 StatsLine 折叠锚（`q2FAPq_root` → `bxNl9a_root`），统计条折叠**静默失效**。

漏检的结构性原因有二：插件自己的测试断言「常量里含有 `_37cUPa_`」（把版本钉复制进断言，等于自证）；构建校验只查关键字与体积，从不校验选择器在真机是否命中。`docs/research/09-audit-architecture.md` 早已把「选择器 miss 即自然降级、静默退化不可观测」登记为债务，本次是同类第 3 次复发。

## 决策

**对官方 UI 的改写锚必须以运行时解析取得，禁止把 CSS-module 哈希写进产品代码或测试断言：**

1. 解析锚用官方自己的**包路径级**标识——`style[data-plugin-css="<包路径>/<模块>.module.css"]`（官方预渲染器契约，不随构建哈希变化）；
2. 类名由「模块 CSS 文本 + 模块局部名的负向断言」离线算出（含该局部名的前缀候选必须恰好一个），前缀长度不作为硬前提；
3. 解析失败必须**自报**：`console.warn` + `document.documentElement` 诊断属性，禁止静默退化；最坏表现是降级而非崩溃；
4. 测试的真值来自**真实产物**（已入库归档 + 本机 app 包），不新增冻结 fixture；断言对象是用户可观察行为（官方标题不再显示、角标显示 `Preview`、统计条折叠），不是自己写下的哈希常量；
5. 品牌文案**单一真相源**：官方标题的隐藏与品牌句的渲染都归插件；`brand-replay.sh` 不再改写官方 `hero.headline`；
6. 角标保持官方节点不动，只改写其文本节点（外观、位置、无障碍语义保留），并在卸载时还原。

## 备选方案

**把 2.0.5 的新哈希补进选择器组（两代前缀并列）。** 只作为 P0 止血可行，作为终态被否决——下一个版本再来一次，债务原地循环，且这次已经证明「靠测试断言常量」无法拦住它。

**把官方 JS 里的 `hero.preview` 词典值直补成 `Preview`（走 brand-replay 补丁层）。** 被否决——用户已明确要求中文界面下也生效；补丁每次升级重打包必丢、需重放，且会新造第二条真相源（本轮事故的成因正是第二条真相源）。

**把界面语言切成英文以取得官方 `Preview`。** 被否决——需求是中文界面下的呈现，且会连带改变整个 GUI 的语言。

**用结构选择器（`nth-child`）替代类名。** 作为解析失败时的降级规则保留，不作为主路径——它对 DOM 结构变更同样脆弱，且会把「官方改了结构」变成无声的错误命中。

**等上游为 `hero.headline` / `hero.preview` 提供可注册席位。** 方向正确但不可控（`docs/research/09-audit-architecture.md` 已登记），不能作为本次修复的前提；解析器是为此前的等待期提供可持续的实现。

## 后果

- 正面：2.0.4 与 2.0.5 由**同一份实现**覆盖（两代前缀都被解析器算出），未来 2.0.x 只要模块文件名不变即免维护；漂移从「静默」变为「可观测」；品牌文案回到单一真相源，{补丁丢失 → 第二实例}这条路径从根上消失。
- 负面/代价：插件首次引入对官方 DOM 的运行时读取（`displayCase` 级别的只读探测），比纯 CSS 多一层间接；需要在客户端 bundle 里保留一个解析器与观察者（实测产物 13.5KB → 16.7KB，仍远低于 120KB 预算）。
- 后续动作：上游若重命名 `HeroShell.module.css` / `StatsLine.module.css`，解析器会报 drift 并走结构降级；届时应重锚模块 id 并在 `docs/research/09-audit-architecture.md` 更新锚点分级。官方提供可注册席位后，本套 DOM 改写整体退役。
