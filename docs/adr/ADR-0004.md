# ADR-0004 · 仓库收录范围：全平台 monorepo（含 81-Skills 公开）

- 状态：accepted（原文未入库，本篇为证据重建）
- 日期：2026-09-06
- 决策者：用户（lute）
- 原文：从未提交到仓库；本篇依据 `README.md`「平台组成」表、`81-Skills/` 目录与 `.gitignore` 白名单重建。

## 背景

仓库收录范围有两条可选路线：只收录与 DSH 基座直接耦合的插件（更小更聚焦），或把技能集与工具链一并收录（更大但完整）。技能集 `81-Skills/`（81 个自研技能）是否公开收录需单独决策。

## 决策

**采用全平台 monorepo 收录范围**：出海技能（`dsh-overseas-skills/`、`81-Skills/`）、出海工具、万物互联（`dsh-wanzh-hulian/`）、支撑插件、打包工程（`packaging/`）、文档资产一并收录，`81-Skills/` 公开。

## 备选方案

- 只收录基座耦合插件：被否决——技能集与工具链是交付物的组成部分，分开会导致版本对齐再次跨库。
- 技能集私有收录：被否决——技能集是产品差异化能力，公开可减少客户解释成本，且不含凭证。

## 后果

- 正面：一次 clone 即得完整可构建平台；技能与插件版本天然同版。
- 负面/代价：仓库体量显著增大（实测技能集 1,533 文件 + 出海技能 1,652 文件），目录治理与门禁必须能覆盖非代码资产（在 ADR-0011 与 ADR-0014 处理）。
