# ADR-0103 · 门禁的「无副作用」必须由快照见证与进程级回收证明，而不是由 `finally` 声明

- 状态：accepted（2026-09-17）
- 决策记录：[2026-09-17-self-attestation-and-process-reaping](../notes/implemented/contract/2026-09-17-self-attestation-and-process-reaping.md)
- 关联：[ADR-0063](ADR-0063.md)（仪器假绿）、[ADR-0094](ADR-0094.md)（三态读数）、[ADR-0097](ADR-0097.md)（mutation fixture 隔离）、[ADR-0102](ADR-0102.md)（同族：射程变小与「没问题」同形）、[ADR-0040](ADR-0040.md)（真 node 判据）、[ADR-0043](ADR-0043.md)（分流取证）

## 背景

QG-006A 把 mutation fixture 迁出了真实工作树，并给每个 fixture 加了 ownership 校验与
`finally` 回收。它的退出条件里留了一句「最终并发/SIGTERM/全工作树零副作用由 QG-006B 证明」。
2026-09-17 执行 QG-006B 时，这句话被实测证伪了两次，形状不同、根因同一个：**回收只存在于
顺利走完的那条路径上**。

| 实测 | 读数 |
|---|---|
| `kill -TERM` 一个正在跑的 `node scripts/gate.mjs --mode quick` | 退出码 143；`TMPDIR` 里留下 **8** 个残留根（6 × `fullstack-installer-*`、1 × `wanzh-routes-*`、`node-compile-cache`）；另有一个 `node scripts/gate.mjs` 被 init 收养（PPID 1）继续跑 |
| 数真实 `TMPDIR`（不是猜） | **2,066** 个残留根、35 MB：`fullstack-installer-*` 1,555 个、`gn-check-*` 438 个、`wanzh-routes-*` 82 个；最早的是历次 `pnpm run gate` 累积的，两天内长到这个量 |
| 三个残留源的代码 | `install-fullstack-skills.spec.mjs` 的 `fixture()` 每用例 `mkdtempSync` 且**从不清理**；`generic-manifest-skip.spec.mjs` 的 `makeTree()` 同样；`oauth-routes.spec.mjs` 有 `test.after(() => rmSync(...))`，但 `test.after` 只在正常跑完时执行 |

第二、三行还只是**机器卫生**问题；真正让它成为门禁问题的是第一条：门禁自己的仪器在
被信号打断时既不回收自有根、也不保证子进程一起结束。而「门禁跑完仓库没变」这句话，
当时**没有任何东西在核**——`git status` 在跑前跑后都是同一份脏工作树，看起来一样，
于是「没看」与「看过了，干净」在读数上同形（ADR-0102 的同族形态）。

还有一个更早的、同形状的读数：2026-09-17 用**合成空 HOME** 跑 `--mode quick` 时，
`skill-lines-selftest` 判红，而红的原因是 `skill-lines.test.mjs` 的 S4–S7 用
`checkSkillLines({ repoRoot, runOne })` 而没有注入 `home`，于是走了 `homedir()` 默认值、
在陌生 HOME 下进了「环境前提不在」的早返回分支，桩一次都没被调用。那是**判据读了
真实环境**，不是被测代码坏了。

## 决策

### 1. 把「无副作用」做成有契约的仪器，而不是一句声明

新增 `scripts/lib/repo-snapshot.mjs`（纯函数，无进程、无副作用）与
`scripts/lib/repo-attest.mjs`（起子进程并见证）。快照的射程是**四层相加**，每层都必须
在读数里：

| 层 | 来源 | 为什么要它 |
|---|---|---|
| `entries` | `git ls-files --stage` + `git status --porcelain=v2 -z --untracked-files=all`，untracked 用 `git hash-object` 进同一 blob 域 | 「射程跟着 git 走」是本仓库既有规矩（ADR-0075/P-11）；把磁盘全量哈希化在本仓库不成立（654,616 个 ignored 文件） |
| `roots` | 声明根（`DEFAULT_DECLARED_ROOTS`，含 `packages/*/*/node_modules/` 这类 glob）的深度 1 名录 | 构建产物不得成为盲区；glob 让新增包自动进射程，避免「加包就得改列表」式腐烂 |
| `ignoredSummary` | `git ls-files --ignored --directory` 分片：已识别的生成区只记名字，**未声明的 ignored 区域全量走** | 别人 `.gitignore` 覆盖的新文件（本仓库白名单式 ignore 下，仓库根的新文件全是 ignored）必须可见 |
| `gitState` | `HEAD`、`--symbolic-full-name HEAD`、`.git/index` 字节哈希、`for-each-ref` | 「只写了个临时文件」与「顺手刷新了别人的脏工作树 index」是两件事，只有 index 哈希分得开 |

判定合同：**`expected` 侧的每一次收缩都必须报错**，不允许静默变小。

- `SNAPSHOT_EMPTY_SCOPE`：没有 tracked 也没有 untracked → 判红（空射程不得与「干净」同形）；
- `SNAPSHOT_SCOPE_COLLAPSED`：untracked 里出现以 `/` 结尾的条目 → 判红（射程被折成目录）；
- `SNAPSHOT_ENUMERATION_STALE`：枚举出的路径在磁盘上不存在 → 判红（枚举与磁盘不一致）；
- `SNAPSHOT_SCHEMA_MISMATCH`：两个快照 schema 不同 → 判红（不许把「格式变了」读成「有差异」）。

判定与解释分离：`identical()` 同时返回 `identical`（digest 与差异数）与 `unexplained`
（digest 动了却**指不出路径**）。第二项是本轮实测逼出来的——`ignored` 区域先进 digest
但没进差异解释时，真实出现的读数是「`identical: false` 且 `diffs: []`」，长得像工具坏了。

### 2. 六条结束路径各有见证，`finally` 不算证据

正常退出、断言失败、checker 非零、fixture setup 失败、cleanup 失败、SIGTERM，
每条都起**真子进程**并比较 before/after digest。子进程是被见证的对象，它声明自己干净
不算证据；证据写进见证者自己的临时根，**不写回被见证的仓库**。

### 3. 进程级回收：注册表 + exit + 信号

`mutation-fixture.mjs` 维护进程内 live 根注册表，并在首次创建时挂上 `process.on('exit')`
与 `SIGINT`/`SIGTERM`/`SIGHUP` 处理器：先回收，再以默认处置**重发同一信号**——这样父进程
看到的是「死于信号」，而不是被改写成「正常退出 143」。同时新增 `mutationRoot(prefix)`：
返回一个自有根的路径字符串，让只想要「一个不会泄漏的临时目录」的调用方（就是上面那三个
泄漏源）用 `mutationRoot('x-')` 直接替换 `mkdtempSync(join(tmpdir(), 'x-'))`，`join(root, …)`
的调用点一行不改。

### 4. `.git/*.lock` 是重试对象，不是差异类型

并发 git 的瞬时锁（`index.lock` 等）会在快照里出现又消失，被误读成 `lock-added` 差异
（实测：并发见证套件里出现过一次）。处置是**先重试、再看**：只有 `unexplained` 会触发
重试（最多 3 次），具名差异一次都不重试；锁若仍在磁盘上，`unexplained` 保持为真并照旧
判红——那才是被信号打断的写入者留下的真残留。锁因此不进 `DIFF_KINDS`，而是作为 ignored
区域记录，使「说不清的变化」这一通道自动覆盖它。

### 5. 判据不得读真实环境

`skill-lines.test.mjs` 的 S4–S7 改为经 `withSelftestHome()` 注入合成 HOME——它们测的是
「有前提时的行为」，读 `homedir()` 会让判据本身依赖机器状态（QG-006A 契约的同一句话）。
默认值仍然保留给真实调用方（`gate.mjs` 走 `homedir()`），被测方不改。

### 6. ref 分两份：自己的判红，别人的如实回报

同一次实施里还暴露了一处归因问题：`refs/codex/**` 是别的工具的命名空间，把它算成
「本次运行的副作用」是错误归因，直接忽略又会掩盖「测的这段时间有人在写这个仓库」。
处置是把 ref 分成两份——`refs`（heads/tags/remotes）进 digest、仍判红；外部命名空间
（`CONCURRENT_REF_PREFIXES`）只记**名字与新旧 OID**，进 `concurrentActivity`，
如实回报但不参与判定。这不是忽略名单：不在前缀里的 ref 照旧判 `refs-changed`。

### 7. 跑并发见证之前先量安静度：不安静报类型化 skip，而不是判红

10 轮用例会（正确地）把邻居的写入读成差异，所以门禁在跑它之前先做一次短暂的安静度
探测（4 次快照、间隔 3 秒）。不安静就返回 **类型化 skip**（`concurrent-writers-detected`），
点名抓到的路径并给出出路 `DSH_ATTEST_REPO=<独占副本>`；判红会把「别人在写仓库」与
「门禁有副作用」压成同一句话，而那正是本 ADR 要消灭的形状。CI runner 的工作树是独占的，
这条探测在那里直接通过。

### 8. 见证入口对 CI 公开

`node scripts/gate.mjs --attest <目标> [--mode quick|full] [--json]` 用同一份快照契约
见证一次完整门禁运行，退出码由差异决定，报告里标 `authority: 'L2-local'`。QG-007 的
独立 runner 要复算的是**同一份契约**，因此入口在门禁里，而不是只存在于测试文件里。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 把磁盘全量文件哈希化当射程 | **否**。本仓库 654,616 个 ignored 文件，一次见证要分钟级；且它量的是「开发者机器上的构建产物」，不是门禁的行为。改为「git 视图 + 声明根名录 + 未声明 ignored 区域全量走」 |
| 只在测试里做见证，不给 CLI 入口 | **否**。QG-007 要在独立 runner 上复算同一件事，测试文件不是可调用的契约面 |
| 把 `.git/*.lock` 直接加进忽略名单 | **否**。「并发读锁」与「被打断的写入者留下的残留」在单张快照里同形；忽略前者就等于放掉后者。改为二次确认 |
| 用 `try/finally` 手工回收替换注册表 | **否**。`finally` 覆盖不到信号，这正是实测留下的 8 个根与 2,066 个历史根的成因 |
| 把三个泄漏源改写成 `withMutationFixture`（四作用域） | **否**。它们只要一个临时根；给它们 repo/home/profile/tmp 是过度耦合。改为 `mutationRoot()` 这一窄接口，保留原调用点形状 |
| 让并发见证用合成 HOME 换取完全隔离 | **否**。合成 HOME 下 8 项走「环境不在」分支、`skill-lines-selftest` 判红——那是门禁在陌生 HOME 下的读数，不是并发缺陷。HOME 保持真实只读，独立变量是临时根、lane 标签与端口 |

## 后果

正面：

- 「门禁跑完没改动仓库」从一句声明变成可复算的读数：`--attest` 给出 before/after digest
  与逐条差异，L2 本地与 L3 独立 runner 用同一契约。
- 三条泄漏源被修在源头（`fullstack-installer` 1,555 → 0、`gn-check` 438 → 0、
  `wanzh-routes` 82 → 0），并且修法是**窄接口替换**而不是框架化改造。
- 进程被信号打断时不再留下自有根，也不再留下变成 init 子进程的门禁；`gate:full` 里
  的 `gate-concurrency-selftest`（默认 10 轮 × 2 条完整 gate）把「并发不互相污染」
  变成每次收口都要过的读数。
- `skill-lines-selftest` 不再依赖机器上是否真有 `~/.dsh/skills`——它在**任何** HOME 下
  都会真的跑到被测分支。

负面与已知边界：

- 见证是有成本的：单次 before/after 约 1.1 秒（本机实测），`--attest` 一轮 = 一次完整
  门禁 + 两次快照。并发 10 轮实测约 7–8 分钟，因此它被登记为 **full-only** 并显式抬高
  超时（30 分钟），不进提交前那一档。
- 快照读取不是原子的：写入者与见证者赛跑时可能读到撕裂的条目。处置是重跑并点名
  offender，而不是忽略未知路径。
- `roots` 层只记深度 1 的名录/类型/权限，**不比对内容字节**：声明根内部「名字不变、
  内容被改写」这一形态不在射程内。它是刻意的取舍（479k 文件），依据是「残留会以新增
  名字出现」，而不是「不可能被改写」。
- 并发见证了 10 轮 × 2 条 lane，但它不是 L3：独立 runner 上的 attestation 仍由 QG-007 收口。
- `--attest` 的见证者根**通过时收掉、判红时留下**：本 ADR 刚数过 2,066 个「从不清理」
  留下的残留根，不能自己再犯一遍；而判红时留下的根是「为什么红」的唯一现场。
- `GENERATED_IGNORED_PREFIXES` 是**具名白名单**：新出现的、被 ignore 的目录若不在这张
  表里，会走全量 walk（慢但可见）；表里已有的前缀内部新增文件只以区域名记账。
- **并发稳定性读数必须在独占副本上取**。同一套 10 轮用例在本仓库上三次两次判红，两次都
  判对了（写入者是并行的其它会话）。本工作树长期有多个写入者，因此该用例支持
  `DSH_ATTEST_REPO=<clean clone>`；共享工作树上直接跑它会（正确地）被别人的写入判红。
  这也是本 ADR 唯一需要「环境独占」才能取到的读数，已如实标在证据里。
