# ADR-0098 · Settings 样式只消费解析器 marker，AX 校准不得复用验收目标

- 状态：accepted
- 日期：2026-09-16
- 决策者：用户（lute）+ agent
- 决策记录：[Note](../notes/implemented/surface/2026-09-16-settings-owned-scope-and-independent-ax-calibration.md)
- 相关：ADR-0014（门禁硬门槛）、ADR-0019（官方 UI 锚）、ADR-0097（mutation fixture）、总账 P-25、PROD-UX-001、QG-012

## 背景

Settings Shell 的脚本只会接受带直接 `nav` 的 Settings 形状，但 CSS 曾直接命中全部
`[role="dialog"][aria-modal="true"]`，导致脚本身份判定与样式作用域不是同一契约。普通 modal、
带导航的产品抽屉或确认框可能在没有被 Settings 解析器接受时，仍被改成 960px 面板并套用导航、按钮样式。
运行时又以永久 `sawShell` 布尔值记忆历史，Settings 关闭后出现普通 modal 也可能被误报为 drift。

实况 AX 探针还有相反方向的假绿：旧公式以目标导航按钮高度计算
`scale = medianButtonHeight / 40`，再用同一个高度计算 `buttonCss = medianButtonHeight / scale`。
无论目标按钮真实高度是多少，结果都恒等于 40；它不能验收自己声称验收的尺寸。

## 决策

1. Settings 身份只由 parser 判定：目标必须是唯一的 modal，包含直接 `nav`，`aria-labelledby`
   指向 `nav` 的直接标题节点，导航按钮共享同一直接列表容器，并且恰有一个
   `aria-current="true"`。多个完整候选、结构漂移或身份不唯一都 fail-closed。
2. parser 成功后才给同一 panel 节点添加 `data-dsh-settings-shell-root`；所有 Shell CSS 只能在该
   marker 下生效。面板关闭、替换、absent、drift、同步异常或 disposer 执行时，marker 与分组标题
   必须回收。注册表不可读或数量不符时清除旧标题，但保留已确认 panel 的 L1 样式 marker。
3. 跨次状态只保存上一次成功 panel 的节点身份。节点仍在线却失配才是 drift；旧节点已离线后出现
   普通 modal 是 absent，不使用永久“曾经见过 Settings”的运行时布尔值。
4. AX scale 使用 pinned upstream `SettingsRoot.module.css` 的 nav 宽 `188 CSS px` 与 close
   `28×28 CSS px`：两个 AX 节点、三个观测信号。目标导航按钮集合不得与校准节点相交，目标高度
   只在 scale 固定后按 `40±2 CSS px` 验收。
5. 锚缺失/不唯一、比例残差超限、非正尺寸、窗口错配、目标与校准样本重叠、样本不足、权限不足或
   instrument timeout 都返回稳定 typed unavailable，不得产出 pass。报告保留 anchor ID、节点 ID、
   raw AX 值、expected CSS 值、sample scale、残差、容差和目标测量；`--require-no-skip` 将其升为失败。
6. 面板目标按视口动态计算为 `min(960, viewportCss - 48)`，官方对照为
   `min(800, viewportCss - 48)`；两档容差带重叠时没有判别射程，返回 typed unavailable。
7. 离线自检与 mutation test 必须覆盖合法整体 zoom、目标高度偏差、旧恒等式复发、锚冲突/缺失、
   错窗、非正尺寸、权限、timeout、L1、L2 和未装载状态。离线绿色不冒充受控 macOS live 验收。

## 备选方案

- 继续用通用 modal CSS，再依靠页面结构“通常不会撞”：身份判定仍有两个事实源，否决。
- 给所有非 Settings modal 建排除名单：新 modal 会不断漏进来，且列表无法证明完整，否决。
- 用目标按钮高度校准，但增加更宽容差：代数恒等式与容差无关，仍会恒真，否决。
- 把 zoom 固定为 1.2：显示缩放、窗口与宿主设置变化后会把合法状态判红，否决。
- 锚失效时回退到目标按钮校准：会在最需要 fail-closed 时恢复原假绿路径，否决。

## 后果

- 非 Settings dialog 没有 parser-owned marker，因此 Settings Shell 不再改变其面板、导航或按钮样式。
- Settings 关闭、React 替换 panel、parser drift、registry 失败和 dispose 都有明确回收语义。
- AX 探针能区分合法整体缩放与目标控件自身尺寸漂移；目标自身校准、锚冲突旁路等 mutation 会稳定打红。
- 188/28 是当前 pinned upstream 的声明式校准契约；上游升级若改变它们，必须在 pin 升级批次重新确认，
  不能静默放宽容差。
- 当前结论是 `local implementation complete; instrument verified; live unverified`。它不证明运行中 DSH、
  两种显示缩放、VoiceOver、干净 checkout、DMG 或 Release 已验收。
