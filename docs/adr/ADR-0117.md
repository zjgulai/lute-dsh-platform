# ADR-0117 · 实况探针的「取不到值」分两类：全局断链判红，局部作用域不判红

- 状态：accepted（2026-09-18）
- 决策者：用户（lute）+ 主题外观轮
- 决策记录：[Note](../notes/implemented/contract/2026-09-18-theme-live-gui-unresolved-classification.md)
- 相关：ADR-0009（一份事实只有一个家）、ADR-0014（门禁硬门槛、豁免只减不增）、ADR-0115（浅色主题取真中性骨架——C4 实况探针是它的验收环节）

## 背景

C4 实况探针（`scripts/acceptance/theme-live-gui.mjs`）在**正在运行的 DSH 渲染进程**里读
`--dsw-*` 的生效值，用来回答「引擎算出来的」与「界面实际生效的」是否一致（ADR-0115 的验收环节）。
它原先只有一个「未解析」档：**声明了却取不到值**，命中即判 `exit 1`。

首轮在真机上跑通后（359 个 token、仪器自检 6/6），报出 1 个：

```
✗ --dsw-hovercard-bg
```

取证发现这个归因是错的。它声明在 CSS Modules 局部类 `._card_1b2ny_13` 上（值 `#2C2C2E`），
而当前页面**没有任何元素挂载那个类**；探针挂在 `body`，本就不在它的继承链上——取不到值是
**预期结果**。仪器把它记成「层叠失效的指纹」并判红，是**假红**。

同一处代码还有反向的错：声明收集不递归进 `@media` / `@supports` / `@layer` / CSS 嵌套，
容器内的声明会从 `declared` 里整条消失，既不算成功也不算失败——**静默漏测**。补上递归后
立刻抓到此前完全不可见的 `--dsw-corner-shape`。

两个错方向相反、同源：**「取不到值」这一个读数被当成了单一含义**。

## 决策

**一、声明收集记来源。** `declared` 由 `Set<name>` 改为 `Map<name, Set<selectorText>>`，
报告里每条 token 带 `declaredIn`。

**二、全局/局部判据。** 选择器组任一项剥掉 `[..]` / `(..)` 装饰内容后，不含组合符
（空格、`>`、`+`、`~`）且以 `:root` / `html` / `body` / `*` 开头 → 该 token 记为
`scope: "global"`，否则 `"local"`。

**三、只对全局那档判红。**

| 情形 | 退出码 |
|---|---|
| `unresolvedGlobal > 0`（根选择器上声明却取不到） | 1 |
| `sheetErrors > 0`（跨域样式表读不到，覆盖不全） | 1 |
| 仅 `unresolvedLocalScoped > 0` | **0**（预期，不是缺陷） |
| 仪器自检未通过 / 前置条件缺失 | 2 |

`unresolved` 字段保留「全部取不到值」语义不变（不破坏既有读者）；新增 `unresolvedGlobal` /
`unresolvedLocalScoped` 两个分类字段与对应 summary 计数。

**四、递归收集容器规则。** 这是分类成立的**前置条件**，不是顺手重构（理由见「备选方案」）。

## 备选方案

- **只做分类、不递归容器规则。** 分类的正确性依赖枚举的完整性；容器内的全局声明看不见就会被
  判成局部或不存在——修了假红却引入假绿，比不修更糟。故两者必须同一批改。
- **用正则实现判据。** `PROBE` 整体处于一个 JS 模板字符串内，正则里的 `\[` 会被模板字符串先吃掉
  一层反斜杠（`\d` 直接变成 `d`）。改为手写字符扫描，并写明本段禁止出现反引号。
- **把局部作用域 token 从 `declared` 里剔除。** 会丢掉「页面到底声明了什么」这一路独立证据——
  它存在的意义正是防止仪器只对着自己的清单自证（ADR-0009）。
- **只加字段、不改退出码。** 假红仍在：报告更详细了，判据照旧错。

## 后果

- **退出码语义变更（契约级），经搜索无下游受影响。** 全仓搜过
  `theme-live-gui|theme-palette-audit|theme-engine-crosscheck|relaunch-dsh-cdp`：真正调用本脚本的只有
  `scripts/acceptance/relaunch-dsh-cdp.sh`，它只判 `!= 2`（就绪判据），不区分 `1` 与 `0`；
  其余命中是 ADR / Note 的文档引用。
- **`PROBE` 内禁止反引号**（新纪律）。本轮实测踩到：在 `PROBE` **内部的注释**里写 markdown 反引号，
  反引号提前终止模板字符串，后续 token 名被当 JS 解析成递减运算，报
  `Invalid left-hand side expression in postfix operation`。由 `node --check` 抓到，不是看 diff
  看出来的。**改这个文件必须跑语法检查。**
- 报告体积增大（浅色态 ~49KB → ~84KB），来自每条 token 多出的 `scope` + `declaredIn` 两个字段。
- 判据可被复核：报告同时打印「仅局部作用域」清单，不只给一个计数。
- 双态实测（浅/深各一次，主题由用户手动切换）：两态均 `unresolvedGlobal = 0`、
  `unresolvedLocalScoped = 1`、仪器自检 6/6、`exit 0`。数字取自同一预设（gruvbox），
  **未在第二个预设下复跑**。
