# 未接线卡覆盖率决策：1184 张保持「按需装配池」

- 日期：2026-09-13
- 前置记录：`2026-09-13-twin-pairs-resolution.md`（阶段 1：8 合并 / 3 区分）、`2026-09-13-twin-pairs-quota-rollout.md`（阶段 2：667 对配额推广）
- 关联 ADR：无新增（同一决策留痕制，复用 [ADR-0015](../../../adr/ADR-0015.md)）

## Problem

阶段 2 配额推广把「本岗默认接线」收窄后（wiredAnywhere 483 → 258），孪生对程序只剩一项遗留：1338 张安装卡里 1327 张已归位，其中**1184 张不进任何岗位的默认 subset**（配额前同口径为 978 张）。上一轮将此挂为「待拍板」，用户指示「继续执行」——按已确立的原则收敛，不再追加提问。

关键取证（全部来自运行态 `GET /api/dsh-algo-skills/tree`，2026-09-13 实测）：

| 口径 | 数值 | 说明 |
| --- | ---: | --- |
| skills 安装 | 1338 | 与恢复索引钉死总数（cards 1338）一致 |
| placed 已归位 | 1327 | 卡的 L3 → 岗位责任名 join；算法技能页即此口径 |
| wired 本岗接线 | 127 | subset 含该卡且归位本岗 |
| wiredElsewhere 接线他岗 | 16 | 归本岗、却接线到别的岗位（分类/接线不一致，页面三态可见） |
| wiredAnywhere | 258 | = 143 张 p2s 卡 + 115 个非 p2s 条目（原生平台技能 + pb-001~008 手册） |
| **已归位未接线** | **1184** | 1327 − 127 − 16；配额前为 978，差值 206 正是配额裁掉的已归位 slots |
| unplaced 未归位 | 11 | AI 伦理 / responsible-AI 系列，其 L3 无岗位责任名对应 |
| emptyRoles | 2 | 砺器 / 联商（分类空白岗，非接线议题） |

两个易误读点（已实测排除）：
1. `disable-model-invocation: true` **全库统一**——接线卡 127/127 同为 true，是 S2 安装管线对论文卡「显式装配、不自动触发」的一贯默认，与接线正交，不是配额产物；
2. wiredAnywhere 含 115 个非卡条目，拿「1338 − 258」直接减会得出错误结论。未接线卡的唯一事实口径是页面逐行 wired 旗标：**1184 = 1327 − 127 − 16**。

## Decision

**1184 张保持不接线，作为「按需装配池」；不批量接线、不改 modelEnabled 开关。** 孪生对程序至此三阶段闭环：11 对处置（8 合 3 分）→ 667 对配额 → 未接线池口径定死。

理由三条：
1. 全量接线 = 撤销用户对阶段 2 的明示拍板（「每 L3 留 2 张」），并把岗内错选空间（situational 87.5% vs 独苗 100%）原样买回来；
2. 接线不是可达性的唯一通道：pb-001~008 手册的 FLOW 机制写明 Case Control 按阶段装配 Skills；管线侧已有幂等路径（`wire-skill-map.mjs` 只追加 → `apply-skill-map-overrides.mjs` 重放 → `generate.mjs`）可按需把单张卡接进任意岗位；
3. 卡不丢：全部 1184 张在算法技能页按其分类岗位可见，接线三态（本岗 / 他岗 / 未接线）逐卡标注。

## Alternatives considered

- **全量接线**：弃。与用户拍板相悖，错选率回升，且与论文卡「显式装配」的一贯设计冲突。
- **按「覆盖方法差异」重估每 L3 的 N**：弃。阶段 2 评审时已否（125 条目无统一判据），且仍不回答「剩余池如何可达」。
- **给未接线卡批量翻转 `disable-model-invocation`**：弃。该字段全库统一、与接线正交，先动它再谈接线会把两个口径搅在一起。
- **不接线 + 现状维持**（采纳）：默认窄、池全量可达、撤销路径不变。

## Consequences

- 覆盖率的定义从此固定：**接线 = 「默认装配」，不是「能力可达性」**；未接线卡 = 按需装配池。算法技能页 totals 与逐卡旗标是唯一事实源，不再另立第二份口径。
- 遗留（属分类/接线一致性议题，页面已可见，处置需动 S2 分类管线或岗位责任名，不在本程序范围）：16 张接线他岗、11 张未归位、2 个空岗（砺器 / 联商）。
- 撤销与变更路径不变：`node packages/capabilities/dsh-paper2skills/scripts/apply-skill-map-overrides.mjs --revert` + 重跑 `generate.mjs`；后续任何 wire 运行后必须重放覆盖层（管线顺序已写死在阶段 1/2 两篇记录里）。
