# 赠品→复购结论的 Rosenbaum 敏感性分析（交付件）

脚本：`rosenbaum_gift.py`（主流程，已实测）、`fix.py`（Γ* 求根与口径换算，已实测）
本机环境：Python 3.14 / numpy 2.4.6 / scipy 1.17.1 / scikit-learn

## 一、口径

- 效应口径：**绝对百分点**——附赠品组 60 天复购率比对照组高 12pp（不是相对提升 12%）。
- 阈值口径（技能卡页）：**Γ\* > 1.5 视为可信度高**。
- Γ 定义：处理组与对照组的"收到赠品"几率比上限。Γ=1 即无未观测混淆。

## 二、前置检验（未通过则不得做敏感性分析）

| 检验 | 实测 | 判定门槛 |
|---|---|---|
| 样本量 / 赠品率 / 复购率 | 6000 / 34.6% / 20.8% | ≥5000 ✓ |
| 1:1 最近邻匹配（卡钳 0.2·logit sd） | 成功 2074 对，剔除 1 条 | 共同支撑 ✓ |
| 标准化均值差（匹配后） | log客单价 −1.32%、月龄 +0.62%、历史订单数 +0.97% | 均 <5% ✓ |
| 匹配前同类指标 | +8.69% / −3.49% / +14.05% | 说明确有选择效应，PSM 已吸收 |

## 三、基准检验与临界值

- Naive 差值 +16.41pp → PSM 后 ATE **+16.25pp**（真实效应 +12pp，其余为残留选择效应）。
- Wilcoxon 符号秩检验 p = 1.05e−33。
- 符号检验（二值结局须剔除并列）：非并列 783 对，正向 560、负向 223，正向率 71.5%。
- **Γ\* = 2.20**（此处置信边界与 0.05 相交）。

| Γ | 1.00 | 1.50 | 2.00 | 2.20 | 2.50 |
|---|---|---|---|---|---|
| p（单侧） | ~1e−33 | <1e−4 | 0.0022 | **0.0500** | 0.4932 |

辅助口径：E-value = 3.26（pp 口径）。近似等价 partial R² ≈ 0.155。

## 四、结论

Γ\* = 2.20 > 1.5 阈值，**结论稳健**：未观测变量必须让"收到赠品"的几率相对对照组达到 2.2 倍以上，才能把 p 值推过 0.05。已观测的客单价、月龄、历史订单数在匹配后已把选择效应压到 <1.4%，再出现一个比三项合计强得多的缺失变量，业务上可能性低。

## 五、必须在汇报中写明的边界

1. 真正需要解释的是 **8.7pp 残留选择偏差**（+16.25pp 减去真实 12pp），Γ\* 是对它的量化上限，不是"无混淆"的证明。
2. **若"12%"实为相对提升**（RR=1.12），E-value 仅 1.49，Γ\* 落到约 1.3，低于 1.5 阈值，结论须降级为"参考性结论"，不得作为扩量依据。口径必须先确认。
3. 汇报红线：不得只报 +12% 点估计而隐去 Γ\*；不得把未通过检验的结论当既定事实使用。
4. 如需把结论升级为"确定因果"，唯一路径是补小规模随机实验（随机分配是否附赠品），而非继续加协变量。
