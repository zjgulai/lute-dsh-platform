# Phase B · 出海技能页四层下钻重构方案

用户 2026-09-12 的决定：**四级下钻 场景 → 4面 → 责任域 → 岗位**；且**先补全 222 个技能的岗位判定，再重构页面**。
本文件是 Phase B 的施工图；Phase A（判定）的产物由本文件第 2 节接管。

## 1. 这一页要回答的问题

技能目录现在按「8 大场景 / 28 细分」摆着，看不出**这些技能服务于组织里的谁**。
重构后，同一条链路从业务场景进入，落点是**岗位**：

```
L1 场景（8，沿用既有 taxonomy-v3）
  └ L2 面（4：经营管理 / 业务运营 / 独立控制 / 数据与Agent平台）
      └ L3 责任域（8：经营与组织 … 数据与AI运行）
          └ L4 岗位（50，含头像、别名、标准产物、已接线数）
              └ 技能卡（含开关、工具缺口、归位来源徽标）
```

搜索框仍是唯一的横切入口：输入关键词时退化为扁平结果（保留现行为，不破坏肌肉记忆）。

## 2. 数据来源与「一份事实一个家」

| 层 | 事实的家 | 取法 |
| --- | --- | --- |
| 技能目录（名称/标题/场景/细分/图标/简介） | 本包 `lib/catalog.js`（既有，`build_preset_catalog.py` 生成） | 不变 |
| 场景 → 面 → 责任域 → 岗位 骨架 | **运行时** `~/.dsh/.agent-presets/agt-*/manifest.json` 的 `x_lute`（plane / domain / order / squad.skills）＋顶层 `icon` | 与算法技能页同一取法，不复制第二份组织骨架 |
| 岗位接线（本岗 preset 真挂载哪些技能） | 同上 `x_lute.skills.subset` | 接线与归位分开显示 |
| **技能 → 岗位 归位判定** | **本包新增 `manifest/role-assignments.json`**（Phase A 产物，仓库内唯一家） | 判定是**新增事实**，材料里没有，故必须落一处；不写进 222 个已安装技能的 frontmatter（会被上游重导覆盖，且越权改他人数据） |

`manifest/role-assignments.json` 每条记录带 `source`：
- `"skill-map"`：继承既有 `scripts/role-presets/skill-map.json`（人工既定映射，强先验）
- `"assigned"`：本轮判定新增

生成器 `scripts/build_role_map.py` 把 manifest 编译成 `lib/role-map.js`（像 `catalog.js` 一样烘焙，页面不依赖 `scripts/`）。

## 3. 页面契约

- **归位 ≠ 接线**（算法技能页的教训）：卡片挂在本岗下是**归位**；卡片上另有一枚**接线徽标**说明本岗 preset 是否真的挂载了它
  ——`本岗已接线` / `接线到 AGT-0xx` / `未接线`。
- **一技多岗如实呈现**：Phase A 实测 61 个技能跨多岗。默认在**每个**归位岗位下都出现（岗位视图 = 工具箱），
  卡片带 `跨 N 岗` 徽标，页脚给出「卡片 ≠ 行数」的去重计数。
- **无岗技能不消失**：`roles: []` 的技能进该场景下的「未归岗」分组，并显示 `no_role_kind`（通用方法 / 纯工具 / 超出材料范围）。
- **零供给岗位不隐藏**：`本岗 0 张卡` 徽标（Phase A 前测得 2 个：AGT-005 / AGT-049；Phase A 后按真实数字）。
- **未安装技能**：目录里 15 条无 `SKILL.md` 的（docx/pdf/pptx/xlsx/skill-finder 等工具型）仍进树，标 `未安装`，不给开关。

## 4. 头像

- L1 场景：已有（`lib/catalog.js` 的 category icon）。
- L2 面 / L3 责任域：新烘 12 枚（4 面 + 8 责任域），与算法技能页**同源同字节**——源都是 lute-brand-icons 技能的 manifest，
  两个包各自烘焙，并由本包的测试**跨包断言 12 条 data URI 逐字节相等**（漂移即红）。
- L4 岗位：运行时读 preset 的 `icon`。

## 5. 施工顺序

1. **A-4 落产物**：`manifest/role-assignments.json` + 覆盖报告（哪些是继承、哪些是新判定、哪些无岗）。
2. **B-1 宿主**：`lib/role-map.js` + `/list` 负载扩成五层树；保留 `groups`（旧胶囊兼容）。
3. **B-2 客户端**：四层下钻 + 懒渲染（只渲染展开到岗位的卡片）+ 徽标。
4. **B-3 证据**：单测（`node --test test/*.spec.mjs`）+ 真机路由实测 + `pnpm run gate`。
5. **B-4 目视验收**，重启后由用户确认。

## 6. 边界（明确不做）

- 不改 preset 接线（`skill-map.json` 与 50 个 preset 一律不动）：归位判定是页面的事，接线是另一次人工决策。
- 不写 222 个已安装技能的 frontmatter。
- 不合并 AI全栈 29 条进场景树：它没有场景轴，保持独立分组（本轮只把它的岗位判定做出来备用，挂法待定）。
