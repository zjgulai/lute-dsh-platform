业务预设（数字员工）

预设 = 给 AI 换一个「职业」。选了角色，AI 就带着这个岗位的系统提示词、专属技能和工具上岗。开箱即用，一句话就能开始工作。共有 7 个业务数字员工 + 4 个出厂基础模式。

👤 7 个业务数字员工⚙ 4 个出厂基础模式🎯 新会话选择即生效📲 飞书可远程切 /preset

怎么使用 三步

步骤操作
1新会话时在预设选择器选一个角色（或对已绑定的飞书机器人用 /preset 切换）
2像对真人下属一样提需求（预设已带专属技能，自动启用）
3成果直接产出（报告 HTML / 视频 MP4 / 图文卡片 / 任务创建…）

7 个业务数字员工

AI 产品开发工程师 3 技能

AI WebApp 产品开发全流程：先澄清需求、再写规格、最后测试驱动开发——一套规范的「从想法到可交付」流程。

grill-me 澄清→to-spec 写规格→tdd 开发

自带技能 (3)

  • grill-me：开发前用决策树逐轮澄清方向、用户选择、范围边界，不跑偏
  • to-spec：把聊清楚的需求写成可追踪规格书
  • tdd：先写失败测试 → 最小实现 → 测试转绿，稳扎稳打
场景：「我要一个团队周报收集小程序」→ 它先问清需求边界，再出规格，再开发。

LLM Wiki 全栈工程师 1 技能

面向企业知识库项目的分阶段开发工程师，会按能力缺口推荐插件。

  • 企业知识库项目分阶段推进（需求→架构→实现→验收）
  • find-plugins：需要某个能力时推荐现成插件
场景：「给公司搭一个内部知识库项目」

AI 数据叙事分析师 1 技能

读 Excel 讲数据故事：数据剖析 → 清洗口径 → 结论提炼 → 图表选型 → 离线 HTML 报表 → 双端验收。适合「把数据变成能讲的故事」。

剖析→清洗口径→提炼结论→图表选型→HTML 报表→双端验收
  • 只读分析本地 Excel（.xlsx/.xlsm），不改原数据
  • 产出离线 HTML 报表（**不联网也能看**），图表自带
场景：丢给它一个销售 Excel：「分析上季度销售情况，出份报告」→ 得到一份带图表的 HTML 报告。

AI 内容视觉编辑 1 技能

长文变图文卡片：1–10 张知识卡片，12 种视觉风格 × 8 种布局 × 3 套配色。

自带技能ai-content-images（1 个）
场景：「把这篇产品介绍做成微信图文卡片」

AI 产品视频导演 1 技能

一句话出宣传片：自动生成简报 → 设计规范 → 分镜 → 源码 → 验收过的 MP4，全流程从空白目录开始。

简报→设计规范→分镜→源码→MP4
  • 产品发布片 / 功能预告片 / 应用宣传片 / 网站展示视频
  • 产出的是验收过的 MP4，不是半成品
场景：「给新 App 做个 60 秒发布预告片」

DSH 动效演示导演 1 技能

大纲变动效演示文稿：8 页单文件 HTML，每页有动画，结构完整视觉突出（不出 pptx）。

  • 演示文稿主题/内容大纲/会议材料 → 8 页动效 HTML
  • 内置动效运行适配器，不依赖外部工具
场景：「把这份会议材料做成带动效的演示页」

飞书数字员工 重点

住在飞书里的员工：处理飞书数字员工对话，用飞书 MCP 创建真实任务——发布、安排、指派一条龙。配合 dsh-im 飞书机器人使用。

  • 飞书里说「安排一个任务给张三」→ 真实在飞书里建任务
  • 普通寒暄只回复不建任务（有分寸，不乱建）
  • 时间解析 MCP：自然语言时间（「明天下午」）自动转具体时间
  • 群聊清醒严肃，私聊轻松自然
自带技能feishu-digital-employee + 飞书 MCP + 时间解析 MCP
怎么触发飞书消息（dsh-im 机器人绑定此预设）+ 新会话选此预设
业务场景：团队在飞书里 @机器人：「周五前让设计组出三版新首页」——真实飞书任务自动创建并指派。

4 个出厂基础模式 非业务角色，随桌面附带

模式定位适合什么时候用
标准模式（standard）默认通用智能体，能力最全日常任务，绝大多数场景
极简模式（minimal）轻量快速，少开销简单问答、快速操作
创造模式（cordis）面向组合与插件开发写插件、调装配
PTC 模式（ptc）特定工作流模板对应工作流场景

业务数字员工与基础模式可以随时切换；对飞书机器人用 /preset 命令也能远程换角色。
