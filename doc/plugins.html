dsh-im · 九大 IM 机器人 v4.1.0重点

把飞书、微信、钉钉、企业微信、QQ、Slack、Telegram、Discord、WhatsApp 变成你的 AI 入口——同事在聊天软件里发消息，电脑上的 AI 直接接单干活，结果流式回传。团队不用学任何新工具，聊天就是入口。

  • 一个渠道可接多个机器人，各自绑定独立工作区、模型与会话，互不干扰
  • 飞书支持流式卡片：思考、工具进度、回答进度实时可见；图片与文件双向回传（图 ≤5MB，单条消息 ≤20MB）
  • 40+ 机器人命令：/new /status /model /reasoning /preset /workspace /session /stop /steer /batch /send /compact /repair 等
  • 每个机器人可设访问模式：Telegram 兼容/安全白名单，WhatsApp 仅自己/指定联系人/开放
  • 接入方式：扫码创建（推荐，自动补权限）或手动填 App ID/Secret
  • 工作区 / 模型 / 预设随时切：对机器人发 /workspace /model /preset
  • 内置「AI Office」：本机主动连公网 AI Office（SSE 下行+任务租约），无需公网 IP
  • 中文优先的入站上下文：群聊清醒严肃、私聊自带幽默

怎么用

设置 → IM机器人 → 选渠道 → 扫码创建 → 飞书里私聊机器人即用；群聊默认「@机器人时才响应」。

换工作区/预设：/workspace、/preset；权限补全：卡片上的「补全权限」扫码增量补。

怎么触发

外部消息 别人在 IM 里发消息 / @机器人，即触发本机 AI 任务；本机「检查连接」可发测试消息。

实测体验

已真机接入飞书（机器人 ABI-KB）：扫码建号 → 私聊消息双向通路 → 卡片回调权限补全（2 分钟限时）→ 在线运行正常。凭据与工作区配置存本机，重装不丢。

业务场景：团队在飞书群里 @机器人：「帮我把今天的周报整理成要点发群里」——电脑上的 AI 自动读工作区文件、生成要点、以流式卡片发回群，全程无需打开 DSH。

agent-team-gui · 多智能体小队 v1.0.1重点

把大任务拆成多个角色并行干：不同小队成员可以用不同模型，串行/并行可编排，DAG 工作流 + 全程运行历史。适合「一个人干不完、或该让几个 AI 分头查证再汇总」的复杂任务。

  • 小队创建与持久化：成员、模型、分工一次配好长期复用
  • workflow 编排：多阶段 DAG，各阶段独立跑不同模型/供应商
  • 运行历史与洞察：每次小队运行可回溯，token 用量按成员可查
  • 上下文模式：spawn（全新）/ fork（继承对话）/ chain（串行传递上一队员结果）
  • 队员可拆成子代理并行，主代理负责汇总与评审

怎么用

「小队运行」面板创建小队并派活；或直接说「让小队做 XX」。想要并行就多个队员，想递进就 chain。

怎么触发

语言指令 界面操作（小队面板）；队员按编排串行/并行执行。

实测体验

内置小队配置：成员按「分析/开发/评审」分工，偏重模型可单独指定；长任务拆队后主代理汇总，出活明显快。

业务场景：「把这个新功能的需求分析、技术方案、测试用例分别交给三个队员，最后汇总评审」——一次派发，三线并行，主代理汇总。

dsh-pocket · 把 AI 装进口袋 v2.8.0重点

一个设置页，手机扫码即访问电脑上的 AI：局域网免配置，公网走安全隧道（PIN 门禁），电脑手机实时同屏。通勤路上也能继续指挥。

  • 扫码即连，无需装 App（手机浏览器打开）
  • 局域网 + Cloudflare 公网隧道双通道，密码/PIN 门禁，用后按需关公网
  • 实时同屏：电脑上聊一半，手机上接着聊，同一会话
  • 兼容/扩展/增强模式均可，无需开浏览器访问也能工作

怎么用

设置 → 手机访问 → 手机扫码 → 输入 PIN 即连；公网访问按需开关。

怎么触发

手机扫码 触发；电脑端「设置 → 手机访问」管理开关与密码。

实测体验

局域网 http://192.168.x.x:3081 密码门禁 302 授权通过；Cloudflare 公网隧道外部抓取 200 + 公网 PIN 通过；测试后已按一次性授权关闭公网。

业务场景：下班路上掏出手机，继续指挥电脑上的 AI 跑完数据清洗，到家看结果已经好了。

archify · 专业架构图生成 v0.1.0（技能 2.14）重点

一句话生成五种专业图：架构图、工作流、时序图、数据流、生命周期图——自包含 HTML，暗/亮主题，可选动效，可导出 PNG/SVG/WebM。

  • 接受自然语言，也接受 Mermaid（flowchart / sequenceDiagram / stateDiagram）转换美化
  • 要画真实系统时，会先读你的代码仓库取证再落图——可验证、不瞎编
  • 严格自校验：9 项质量检查全过（showcase 标准）才交付，不达标会自我修正
  • 五种图各有 schema + 示例，自动排版、自动补标签
  • 产出物是独立 HTML：可点击、可放大、可导出、可放进汇报

怎么用

直接说「用 archify 画一张 XX 的架构图，8-12 个核心组件」；产物是 HTML 文件，让 AI 给出文件路径后打开。

怎么触发

语言指令（提及画图/架构/Mermaid 时 AI 自动启用该技能）。

实测体验

L4 冒烟：validate 9 项 showcase 检查 0 错 0 警 exit 0；deliver 产出 637KB 自包含 HTML。包内是 2.14 快照（仓库 main 已 2.16）。

业务场景：给老板汇报：「把订单系统的架构画成一张能点、能放大、能导出 PNG 的图」——5 分钟出图，直接放进周报。

知识与记忆

noema · 跨会话长期记忆 v0.1.0-rc.3重点

AI 的「长期档案」：跨会话记住你的偏好、决策、项目约定；记忆可浏览、可检索、可审计、可删除。你随口一句「记住 XX」，它就存下并一直遵守。

  • 自动召回：每个新会话开始，AI 先读相关旧记忆再干活
  • 你说「记住 XX」，它存下来；关键词 / 实体 / 知识图谱 / 多跳邻居检索
  • 记忆带实体与代码锚点，按项目组织，跨会话关联
  • 可审计：设置页看全量目录、看候选、解释召回、删除或改写
  • 可导入其它 AI 工具的 AGENTS.md / 规则文件（Codex / Claude / Cursor 等）

怎么用

无需操作即自动生效；显式记忆说「记住：我们部署用 pnpm」；设置 → Noema 记忆可管理。

怎么触发

自动（会话开始自动 recall + 重要事实自动候选）；语言指令（「记住…」）。

实测体验

已沉淀「21 点不提交」等约定与新会话自动召回；记忆目录/图谱能在设置页完整浏览，删除/改写即时生效。

业务场景：上周定下的「21 点前不许提交代码」约定，这周换新会话 AI 依然记得并遵守。
知识与记忆

灵枢 dsh-memory · 感知记忆与联想 v0.4.0重点

「大脑」型记忆：对话自动沉淀进记忆库，带实体、关系、时间线；联想召回让 AI 能跨话题串起你的上下文——越用越懂你。

  • 对话自动沉淀（感知层 + 知识层双层记忆，自动去重）
  • 组合联想召回（内容相似 + 重要性 + 近因加权），跨话题关联
  • 记忆时间线、完整性自检、会话要点外部化（可恢复）
  • 知识摄取：文本 / URL 直接灌进知识层；候选记忆审核队列
  • 联想关系边（因果/相似/时序/空间/层级），图谱检索

怎么用

自动运行，无需操作；也可用「灵枢」相关工具显式查询/写入。

怎么触发

自动（对话自动沉淀 + 推理前自动联想）；工具调用（lingshu_*）。

实测体验

与 noema 并存（功能有重叠，用户决定共存）；记忆库带实体抽取与关系边，联想召回能串起跨天上下文。

业务场景：三天前聊过的某个方案细节，今天随口一提，AI 立刻联想起来接着往下做。

deepresearch · 深度调研 v0.2.2重点

证据优先的调研工作流：多轮检索、来源留证、持久状态，产出可追溯的调研报告。适合「要一份能交给领导的、带出处的调研」。

  • 调研任务持久化：中断了回来接着查，结果不丢
  • Web 工作区：检索到的页面统一收纳管理，逐条留证
  • 每条结论带来源，不空口无凭；多轮检索自动迭代
  • 与搜索（modsearch）、图表（genui）联动成文

怎么用

侧边栏「深度研究」入口，或说「深度调研一下 XX」。

怎么触发

语言指令 入口按钮。

实测体验

「调研 DeepSeek Harness 插件兼容性」——自动多轮检索、归档页面、成文带来源；持久化状态让中途断点可续。

业务场景：「调研一下 2026 年企业级 AI 智能体的市场格局，输出带来源的对比报告」——自动多轮检索、归档、成文。
研究·搜索·视觉

vision-router · AI 的眼睛 v2.0.1重点

给文本模型装上眼睛：免配置视觉链 + 像素级工具全家桶，看图、读图、比图、改图全在本地管线。设计稿对照、截图核验、OCR 一把抓。

  • 看图问答（结构预识别 + 目标定向追问）
  • 目标定位 / 裁剪放大 / 双图像素对比（红热图标差异）
  • OCR 识别（中英）、主色提取、SVG 矢量化、前后景分离
  • HTML 无头截图、长图 OCR、图片直接呈现给用户
  • 多后端自动路由：某条限流/超时自动换线，并把失败如实告知

怎么用

直接把图片拖进对话，或让 AI「看看这张截图哪里有问题」。

怎么触发

图片自动路由（读图/OCR/对比等视觉任务自动走这套管线）。

实测体验

截图 + 像素 diff 验证 UI 修复；页面截图 auto-navigate 读取；多次遇视觉后端限流会如实报「本轮视觉不可用」并继续文字任务。

业务场景：丢给 AI 一张设计稿和一张实现截图：「对比一下，实现哪里和设计不一致」——像素级差异图直接标红输出。

genui · 回复内交互界面 v0.9.6重点

AI 在回复里直接渲染可交互组件：布局、表格、图表、表单、问卷、流程图、3D——不用跳出对话就能用看板、答题、看数据。

  • 20+ 组件：卡片/表格/图表（柱状/折线/环图）/函数图/流程/时间轴/表单/问卷/3D 场景/Mermaid
  • 交互就地完成（判卷、展开、选中），不打断对话，零往返
  • 交互状态按「会话 + 内容指纹」持久化，刷新/重放不丢
  • 问卷模式：每题单选 + 一次提交，本地判分
  • 严格 JSON 校验：坏围栏降级为代码块，不崩

怎么用

让 AI「给我做个对比表 / 出个进度看板 / 来个选择题」，AI 直接在回复里渲染。

怎么触发

AI 自动（结构化表达时主动渲染）；也可用 render_ui 工具主动输出。

实测体验

本白皮书本身的表格/卡片就是用 genui 渲染的；交互组件（问卷/看板）就地判分、状态持久。

业务场景：「把这三个方案的优缺点做成对比表，再来个投票按钮」——回复里直接出现可交互表格，点按钮即反馈。
