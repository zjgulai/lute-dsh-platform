产品本身能干什么 出厂底座 · 开箱即用

不装任何插件，它也是一个完整的 AI 工作台。下面每一条都是开箱即用的底座能力，所有扩展插件都长在这层底座上。

底座

智能会话

多轮对话、任务拆解、自动执行。每步过程可看轨迹、可回放、可追溯，不会「黑箱」。

  • 对话中途可打断、可改方向（steer），AI 从断点接着干
  • 上下文自动压缩，长任务不卡
  • 子代理：一个任务派给多个 AI 并行，主代理汇总
怎么用像聊天一样提需求即可，AI 自己调工具干活
触发你发消息即触发
底座

工作区

绑定一个文件夹当项目根目录，AI 在这里读文件、写文件、跑命令、管版本。

  • 多工作区切换，各会话独立绑定
  • 文件树浏览、搜索结果、任务状态同屏
怎么用侧边栏选择目录 → 新建会话即绑定
触发界面操作
底座

模型中枢

DeepSeek-V4 系列随时切换，按任务挑模型：快速问答 / 深度思考 / 多模态看图。

  • 同一会话可按需换模型
  • 小队成员可各自指定模型
怎么用会话底部模型选择器
触发界面操作
底座

Agent 预设

给 AI 换「职业」：标准模式、极简模式、创造模式、PTC 模式，以及 7 个业务数字员工。

怎么用新会话预设选择器；对飞书机器人用 /preset 远程切
触发界面操作 命令
底座

终端与浏览器

内置终端跑命令、内置浏览器看网页，AI 直接用它们做「操作电脑」类任务。

  • 终端：跑命令、看输出，AI 自己迭代修 bug
  • 浏览器：打开网页、读内容、执行自动化脚本
怎么用侧边栏「终端 / 浏览器」面板
触发界面操作 / AI 自动调用
底座

任务小队（编排）

大任务拆给多个 AI 子代理并行干，主代理汇总——「一个人干不完的活，一个小队来干」。

  • 串行 / 并行 / 编排由你定，成员可指定模型
  • 运行历史全程留痕，token 用量可查
怎么用说「让小队做 XX」，或在「小队运行」面板编排
触发语言指令 界面操作
底座

会话持久化

关掉再开，会话还在。聊天记录、任务状态、子代理进度都留在本地。

怎么用重启应用后自动恢复

3 个典型工作流 从业务问题到成果

📊 深度调研出报告

提需求→深度研究→多轮检索→来源归档→成文
  • 「调研一下 XX 市场格局，带来源」
  • 自动搜网页、读页面、留证据、写报告
  • 用到的能力：deepresearch + modsearch + genui（内嵌图表）

💬 飞书里调度 AI

同事 @机器人→本机接单→读工作区→流式卡片回传
  • 「把今天周报整理成要点发群里」
  • 团队不用学工具，聊天就是入口
  • 用到的能力：dsh-im + 飞书数字员工预设 + 记忆

👤 数字员工产出

选角色→提需求→自带技能→出成果
  • 「读销售 Excel 出份带图表的报告」
  • 「做个 60 秒产品宣传片」「把长文做成图文卡片」
  • 用到的能力：7 个数字员工预设 + 各自专属技能
