技能库

技能 = AI 的专项本领，共 25 个。你不需要记名字——只要在对话里说出要干什么，AI 会自动拿出对应的本领。按「来源」分四类：个人技能、Agent 技能、内置技能、预设绑定技能。触发方式主要有四种：语言触发、工具触发、自动运行、预设绑定。

🗣 语言触发为主🔧 工具触发👤 预设绑定⚡ 部分自动运行

个人技能 你为 AI 安装的通用本领 · 4 个

dsh-plugin-acquire 采集

插件获取闭环：给一个插件链接（GitHub/npm），AI 自动完成形态识别 → 评估 → 安装 → 测试 → 写说明文档。

  • 覆盖全流程并留证据：评估表、分层测试报告、README.usage.md
  • 内置崩溃级阻断检查，防「装了就崩」
怎么用说「帮我装这个插件：链接」
触发语言/斜杠指令（/dsh-plugin-acquire + 链接）
实测：本机 archify / dsh-im 都是这样采编安装并留档的。

build-deepseek-harness-plugin

插件开发全流程：创建、改造、迁移、评审、调试、发布 DeepSeek Harness 插件。

  • Cordis 装配、官方插件替换、Web Client bundle、Slot、Theme Token 等
  • 改 schema 后界面不更新、GitHub 安装等调试知识
触发语言触发（插件开发任务）
场景：「帮我写一个每天自动整理会话的插件」

genui

回复内交互 UI 渲染：表格、图表、表单、问卷、3D 等（与 genui 插件配套）。

触发AI 自动（结构化表达时）
场景：结果需要可视化时自动上表格/看板。

macos-harness

控制整台 Mac：截图、点击、输入、Apple 事件、浏览器控制、文件操作——AI 的「手」。

  • 摄像头级像素输入、目标定位、CDP 浏览器控制
  • 权限（屏幕录制/辅助功能）检测与授权引导
触发语言触发（操作电脑类任务）
场景：「打开访达把这个文件拖到那个文件夹」「帮我登录这个网页」

内置技能 随插件一起装好的本领 · 2 个

archify · 画图本领 随 archify 插件 · 2.14

五种专业图（架构/工作流/时序/数据流/生命周期）+ Mermaid 美化转换，自包含 HTML 产物，可导出。

  • 自然语言或 Mermaid 输入，自动排版、自动补标签
  • 读代码取证再落图，可验证不瞎编
  • 9 项质量检查全过才交付
触发语言触发（「画架构图」类需求）
实测：validate 9 项 0 错 0 警 + deliver 637KB HTML 一次通过。
