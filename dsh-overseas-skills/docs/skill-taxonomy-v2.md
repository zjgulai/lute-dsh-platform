# 出海技能 · 大场景→细分场景 分类总表（v3 终审稿）

> 2026-09-08 修订：按用户决策将「内容与流量」拆分为 **C 内容与品牌** / **D 流量与获客** 两个独立大场景。8 大场景 / 28 细分场景 / 222 技能；preset-* 7 个移出技能目录。

## 分类原则

1. **单一分类轴**：只按「业务场景阶段」分类，不再混用职能轴/工具轴。
2. **内容与流量分家**：内容、品牌、公关、红人伙伴归「内容与品牌」；SEO、广告、邮件私域归「流量与获客」。
3. **同族可拆**：同一家族技能按业务阶段拆分归位（如 Amazon prelaunch 7 件套）。
4. **key 规则**：大场景前缀 + 细分场景小写英文（如 `d1-seo`、`a2-competitor`），新增技能按 key 直接落位。
5. **命名规范**：细分场景用 4-6 字业务动词短语；大场景用「X · 场景名」。

## 前端两级折叠交互（草案）

- 一级：8 张「大场景」卡片（沿用现有卡片墙样式 + 大场景图标）。
- 二级：点开大场景 → 展开细分场景区块（每块小标题 + 技能卡片流）；细分场景默认收起，可单独展开。
- 搜索：跨层级匹配技能名/标题/摘要，结果直接显示所属「大场景 › 细分场景」路径。
- 预设 7 个（preset-*）从技能目录移除，仅在「Agent 预设」页出现。

## 新增技能归位 SOP

1. 判断该技能服务于出海链路哪个阶段；
2. 落到对应大场景 → 细分场景 key；
3. 补充 name/title/summaryZh/icon 四件套；
4. 跑 `python3 scripts/build_preset_catalog.py` 重建目录，`node scripts/verify_static.mjs` 校验。
