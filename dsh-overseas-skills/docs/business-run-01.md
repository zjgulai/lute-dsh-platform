# 品牌营销增长官 · 业务全链路跑通（Run 01）

> 场景：Momcozy（母婴 · 全球第一可穿戴吸奶器，6M+ 妈妈信任）
> 链路：场景选品侦察 → GTM 战略规划 → 营销文案 → 经营复盘
> 规则：无数据不编造（搜索量/竞品价格/CSV 数字一律标注「待验证」）

## 一、选品（scenario-driven-product-scout）

### 1. 身份迁移节点
- 当前阶段：产后 → 哺乳稳定期
- 下一个阶段：哺乳期 → **重返工作**
- 为什么重要：这是「母婴身份」对非母婴场景（通勤、办公室、会议、出差）渗透最强的迁移点，摩擦密集且用户付费意愿高（时间稀缺+隐私焦虑）

### 2. 反直觉场景
场景名称：**返工第一周的隐形泵奶时间**
具体摩擦：通勤路上没时间泵奶；到了公司泵奶间排队/缺电源/缺清洁条件；泵完的配件没地方洗和晾
购买动机：不是「再买一个泵」，而是「把我的泵奶任务从家庭环境移植到职场环境且不狼狈」

### 3. 三个场景机会（谁/何时/摩擦/动机 + 五维矩阵）

**机会 1：职场泵奶通勤套装**（收纳包+保冷奶瓶仓+泵配件清洁站）
- 交叉销售 ★★★★★（M9/M5 现有用户直接延伸）· 供应链 ★★★★☆（包袋+保冷复用）· Amazon ★★★★☆（"breast pump bag for work" 搜索型）· DTC ★★★★☆（返工故事型）· 社群信号 ★★★★☆（返工帖高频）

**机会 2：泵奶配件快速干燥盒**（办公室场景 2 小时速干+UV 保洁）
- 交叉 ★★★★☆ · 供应链 ★★★☆☆（新品类）· Amazon ★★★☆☆ · DTC ★★★★☆ · 社群 ★★★☆☆

**机会 3：静音超长续航配件充电仓**（会议/飞行场景）
- 交叉 ★★★★☆ · 供应链 ★★☆☆☆（电池/静音工程重）· Amazon ★★☆☆☆ · DTC ★★★☆☆ · 社群 ★★★☆☆

### 4. 主推方向
- **推荐：机会 1（职场泵奶通勤套装）**
- 理由：五维矩阵唯一全 4★+；与旗舰泵交叉销售最直接；「返工」是内容叙事富矿（TikTok #pumpingatwork）
- 渠道：Amazon 承接搜索购买 + TikTok/IG 承接故事种草
- 第一验证动作：社群发「返工第一周你最怕什么」投票帖 → 收集 ≥50 条痛点原文 → 用 top3 痛点定套装 SKU 组合（**待验证**，不预设结果）

## 二、GTM 战略规划（gtm-strategy-planning · 按 playbook 框架）

- **进入模式**：跨境直营，美国首发（亚马逊旗舰店 + DTC 独立站）
- **首发阵地**：Amazon.com（"wearable breast pump" 心智已有）→ 验证后推 DTC
- **本地化清单**：FDA 备案/CPSC 合规、英西双语详情页、退货政策对齐竞品带
- **差异化定位**：一句话——「把泵奶从家务变成通勤的一部分：一包带走、清洁无压力」
- **渠道配比**：广告 55% / KOL+达人 25% / 内容 15% / 测试预留 5%
- **定价**：对标中高端竞品带（**具体价格待竞品采样**），留 15–20% 首销折扣空间
- **上市时间表**：M-4 Listing+合规 → M-3 定价/种子用户 → M-2 内容制作（本文案即 M-2 产出）→ M-1 KOL 预热 → M0 上市 → M+1 复盘调渠道
- **KPI**：首月 GMV / ACoS / 转化率 / 评价数≥50 / 复购率 / 渠道 ROI 对比

## 三、营销文案（copywriting · PAS+AIDA）

### Landing 首屏（PAS）
- 主标题：**「返工第一天，泵奶不狼狈。」**
- 副标题：「Momcozy 职场泵奶通勤套装——收纳、保冷、清洁一站带走，让你把精力留给会议，而不是泵奶间。」
- CTA：「抢先加入 Waitlist，上市价立减 15%」

### 产品描述 bullets（功能→利益）
1. **一体收纳**：泵、配件、奶瓶分区固定，单手开合 → 通勤包不再翻找
2. **4 小时保冷仓**：奶瓶独立保冷格，晚班到家仍新鲜 → 奶量不浪费
3. **清洁站**：折叠水盆+晾干架，办公室 5 分钟完成配件清洁 → 泵奶间排队不再是问题
4. **隐蔽外观**：看起来就是个通勤托特包 → 隐私自在
5. **风险逆转**：30 天无理由退货 + 一年质保 → 零试错成本

## 四、经营复盘（ecommerce-business-insights · 无 CSV 不编数）

上市 M+1 需提供订单 CSV 后运行；本框架先就位（**所有数字待数据，不预设**）：

### REVIEW.md 模板
```
# M+1 经营复盘
## 执行摘要（GMV 达成率 vs 目标）
## KPI 树
GMV = 流量 × 转化率 × AOV
 ├ 流量：自然 / 广告 / KOL 引流
 ├ 转化率：Listing 页 / 详情页
 └ AOV：套装搭售率、折扣使用率
## 红绿信号（达标/未达标清单）
## 根因假设（渠道归因 → 假设 → 待验证）
## 行动队列（下周 3 项 + 负责人）
```

### 数据质量门槛（技能硬规则）
- 无日期字段 → 停趋势结论；无客户 ID → 不算复购；无金额 → 不算 GMV/AOV；样本不足 → 标低可信度
- 所有百分比必须注明对比基准（vs 上月/上季/目标）
