### 验收中发现的缺陷与修复（2 处）

- **问题 1（F1 软化误伤）**：`soften-clarify.mjs` 的 DESC_PATTERNS 实际对**全文**执行替换（注释声称仅 frontmatter），导致正文里「缺具体材料→追问细则」条目（如 launch-strategy 的 缺产品信息/缺目标市场/缺发布时间预算 三条）被压成同一句，出现 3 行重复，丢失区分信息。
  **修复**：DESC_PATTERNS 收窄为仅作用于 frontmatter description 字段；正文只保留 BODY_PATTERNS 精确行替换。
- **问题 2（description 块标量截断）**：`extractDescription` 的正则 `\s*` 会吞换行，把 `description: |` 块标量误判为行内标量——多行 description 只提取第一行，触发词/何时不用等后续行全部丢失（影响模型路由依据）。
  **修复**：改为按「行定位 + 顶层 key 终止」解析块标量；重跑管线后全部 81 描述完整提取。
- **验证**：launch-strategy 三条细则完整还原、描述含触发词/何时不用/F1 条款；全 81 系相邻重复行检查仅剩代码块 JSON 的 `}` 等合法内容；F1 软化统计 description 54 个 / 正文 0 个；verify_static 双闸门、词法路由 228/228 均无回退。

## 一、竞品情报（competitor-profiling · L2 竞争格局模式）

**Prompt**：结合竞品与 VOC，提出下一代可穿戴吸奶器 3 个优先改进点。（US/DE/FR，虚拟夹具）

### 执行输出

**分析深度**：L2 标准分析（产品/市场决策）

**1. 结论摘要（≤200 字）**：可穿戴吸奶器竞争从「静音+隐蔽」转向「续航+清洁+合身」三轴。VOC 高频痛点与头部竞品能力缺口重合在续航、清洗便捷、尺码指引。建议下代产品以这三项为迭代主线，定价锚定中高端带并以「职场全天佩戴」叙事切入。

**2. 行业竞争结构（Five Forces 摘要，虚拟数据）**
- 现有竞争：高（Elvie、Willow、Medela 品牌心智强，价格带 $250–$500，虚拟占位）
- 新进入威胁：中（医疗器械+电池合规门槛，FDA/CE 认证周期 6–12 月，虚拟占位）
- 替代品：中（传统电动泵 + 免提配件组合）
- 供应商议价：中低（泵机、电池模块供应充足）
- 买方议价：中（价格敏感度因保险报销政策而异）

**3. 竞争定位**（虚拟占位数据）
- Elvie：静音+极简设计，价格带高位；弱点：单次续航、配件清洁件多
- Willow：一体杯设计，价格带高位；弱点：体积、噪音水平
- Medela：传统泵品牌力强，免提新品追赶中；弱点：设计感与隐蔽性
- Momcozy：性价比+社区口碑；机会：续航/清洁/尺码的「痛点创新」

**4. 关键洞察（含反向洞察）**
1. 续航：VOC 中「中途没电」投诉密度最高，与 Elvie/Willow 能力缺口重合 → 直接改进项
2. 清洗便捷：配件数量与清洁步骤是 DE 市场差评主因 → 结构简化有明确收益
3. 尺码指引：罩杯适配错误导致「吸力不适/漏奶」差评 → 指引与可调结构双重改进
4. **反向洞察**：看似机会的「App 智能联控」不应做——头部品牌已标配，用户付费增量低，且 App 合规（医疗数据）成本高、12 个月后同质化加剧

**5. 战略建议**
- 应做：续航提升至全天档（≥6 次泵奶，虚拟目标）、清洁件数减半、尺码指引前置到详情页与开箱
- 不应做：App 深度功能矩阵、低价抢量（低于 $150 档与低价白牌贴身肉搏，虚拟占位）

**6. Notes**：全部竞品数据为虚拟占位，需以公开信息源（官网/亚马逊详情页/评论采样）二次验证后再定案；信息缺口：真实价格带、真实评论量、真实合规周期。

## 二、市场可行性审计（market-viability-logic-auditor · 三层裁决）

**Prompt**：围绕 Momcozy 出海场景，输出选品、定价与渠道策略建议。（US/DE/FR，虚拟夹具）

### 执行输出

**边界声明**：本技能只做进入前裁决；「选品方向探索」部分路由 market-insight-product-selection。以下按三个既有产品方向逐一裁决（非探索式选品）。

**三层框架 × 三方向**（虚拟数据占位）

| 方向 | 风险层 | 品牌层（Momcozy 优势） | 时间层（12 个月） | 裁决 |
| --- | --- | --- | --- | --- |
| 可穿戴吸奶器（下代） | 医疗/电池合规重，售后复杂度高；已有管线可承接 | 强：现有用户交叉、供应链复用 | 头部已红海化，差异化窗口在痛点创新 | **有条件 Go**（以三项痛点创新为前提） |
| 哺乳文胸 | 纺织类合规可拆解（CPSIA 小零件注意）；退货率需控 | 中强：搭配泵的使用场景自然延伸 | 竞争温和，12 个月不显著恶化 | **Go（优先）** |
| 储奶袋 | 食品接触材料合规；利润薄 | 中：耗材复购可与泵绑定 | 价格战风险随低门槛升高 | **No-Go（首品不建议）** |

**定价建议**（虚拟占位）：下代泵锚定中高端带（对标竞品 $250–$500 虚拟区间），留 15–20% 首销空间；文胸定价对标品类中位，靠组合折扣与泵绑定。
**渠道建议**：Amazon US 主承接搜索购买 + EU（DE/FR）跟进；DTC 承接复购与订阅（储奶袋若做必须走复购绑定，否则不做）。
**3 个产品迭代优先级**（品牌层结论）：续航、清洗便捷、尺码指引——与竞品情报 VOC 结论互证。
**合规提醒**：欧盟额外 CE/REACH/GPSR，不替代法务意见；阈值口径（主词 ≥5000/毛利 ≥25% 等）为工具估算，须按真实后台校准。

**1. 核心结论**
- US：高花费关键词 CTR 与转化背离——「wearable breast pump」类大词花费占比最高但转化低于品牌词（虚拟数字），建议降低低转化词预算 10%–15%

**2. 下周三项动作**
1. 预算重分配：US 大词预算 -10~15% → 品牌词与场景长尾词
2. Listing 文案修订：DE 站优先，续航/清洁差异化卖点前置，FAQ 增补差评反哺
3. 差评闭环：DE 站续航类差评 48h 内回复模板 + 产品团队反馈单（虚拟流程）

**3. 风险预警**：US 广告占比若持续>毛利红线（虚拟阈值），触发周度预算刹车；DE 差评率连续 2 周上升则启动 Listing 验证（虚拟触发条件）。
