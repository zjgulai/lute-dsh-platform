# LUTE Agentic System 安装手册（用户版）

**本手册对应版本：{{VERSION}}**（DSH 基座 2.0.5）· 仅支持 **Apple 芯片** Mac · **macOS 13 或更新**

> 这页要解决的问题只有一个：**你拿到的 `.dmg` 打开后有一堆文件，到底该点哪个。**
> 一页速查见 [安装卡](INSTALL-CARD.md)；卡住时翻本手册对应的那一节。
> 本文件里的 `{{VERSION}}` 在打包时被替换成实际版本号——你手上的随包副本显示的就是真版本。

---

## 1. 开始前：一分钟自检

| 检查项 | 要求 | 怎么确认 |
| --- | --- | --- |
| 芯片 | Apple 芯片（M1 / M2 / M3 / M4） | 苹果菜单  → 「关于本机」→ 看「芯片」一行 |
| 系统 | macOS 13 或更新 | 同上，「macOS」一行 |
| 磁盘 | 至少 **3 GB** 可用（建议留 6 GB） | 系统设置 → 通用 → 储存空间 |
| 密码 | 手上要有这台 Mac 的**登录密码** | 安装中会用管理员身份授权一次 |
| 正在运行的应用 | 先**退出**它（应用菜单 → 退出 / ⌘Q） | 升级时必做；安装器也会自动帮你退 |

> 在一台干净的 Mac 上装第一次，通常 3–5 分钟。

---

## 2. 关键一步：DMG 里哪个文件才是「安装入口」

打开 `.dmg` 后会看到一个窗口，里面躺着大约十个文件。**只有下面两个是可点的安装入口，其余全是载荷**：

| 你看到的 | 它是什么 | 该怎么用 |
| --- | --- | --- |
| **LUTE Setup.app** | 图形安装向导 | ✅ **双击它**（所有人都用这个） |
| **install.sh** | 命令行安装器（和向导做的是同一件事） | ✅ 只在「终端」里运行它 |
| `DSH Desktop.app.tar.gz` | 应用本体（已定制） | ⛔ 别动 |
| `profile.tar.gz` | 运行环境（离线依赖，约 1 GB） | ⛔ 别动 |
| `skills-presets.tar.gz` | 技能与岗位预设 | ⛔ 别动 |
| `aeis-portable.tar.gz` | 灵枢（内置 Python 运行时） | ⛔ 别动 |
| `tools/` | 自检与修复工具 | ⛔ 别动 |
| `INSTALL-GUIDE.md` / `README.md` / `VERSION` / `manifest.json` / `SHA256SUMS` | 说明与校验文件 | 👀 只用来看 |

> ⚠️ **不要双击 `install.sh`。** macOS 默认不执行 `.sh` 文件，双击只会用文本编辑器把它打开——看起来「点了没反应」，其实什么都没装。
> ⚠️ **不要把 `LUTE Setup.app` 从 DMG 里拖出来单独运行。** 它需要在安装包里找同级文件；单独拖出去只会提示「未找到可用的安装包」。
> 顺带说明：**从挂载的 DMG 里直接双击向导是正常的用法**，即使 macOS 把它复制到临时位置运行，向导也会自己找回安装包（见第 9 节最后一行）。

## 3. 安装 · 方式一：双击向导（推荐，无需终端）

1. **双击** `DSH-Desktop-LUTE-{{VERSION}}-mac-arm64.dmg` 挂载。
   第一次打开可能被系统拦下（本包未做 Apple 公证，属正常现象）：**右键点这个 dmg 文件 → 「打开」→ 弹框里再点「打开」**。

2. 桌面上会出现一个名为 **DSH Desktop LUTE {{VERSION}}** 的磁盘图标，并自动弹出窗口。

3. 在窗口里**双击 `LUTE Setup.app`**。
   第一次打开同样可能被拦：**右键点它 → 「打开」→ 弹框里再点「打开」**。
   如果只看到「完成」或「移到废纸篓」，就去 **系统设置 → 隐私与安全性**，在页面下方找到「已阻止使用…」的记录，点 **「仍要打开」** 并确认（会要一次密码）。

4. 向导窗口会先打印一行「安装包：…」——那是它定位到的安装载荷位置。
   正常形如 `/Volumes/DSH Desktop LUTE {{VERSION}}`。
   若向导提示「本程序正被 macOS 从随机只读位置运行（App Translocation）」，**这是正常的**：
   dmg 未公证时系统只把向导本体复制到临时位置启动，它已自动找回挂载卷上的安装包，继续即可。

5. 点 **「开始安装」**，窗口里会一行行打印进度：解包应用 → 就位运行环境 → 技能与预设 → 灵枢运行时 → 自检。
   这一步要几分钟，**别关窗口、别合盖、别断电**。

6. 中途会弹出一次「输入密码」框——这是把应用放进「应用程序」文件夹所需的授权。
   输入**你的 Mac 登录密码**（不是 Apple ID 密码），点「好」。
   除这一步以外，全程不需要管理员权限。

7. 最后一屏显示「安装完成」就成功了，关掉窗口即可。
   桌面上那个磁盘图标可以拖进废纸篓（= 推出镜像）。

> 顺手记一句：**不要用 `sudo` 装**。用 `sudo` 会让后续升级无法覆盖安装（安装器会直接拒绝并教你怎么修）。

## 4. 安装 · 方式二：终端一条命令（习惯终端的话）

与方式一完全等价，只是把向导换成命令：

```bash
cd "/Volumes/DSH Desktop LUTE {{VERSION}}" && bash install.sh
```

- 卷名里的版本号跟着你手上的 dmg 走；不确定就先敲 `ls /Volumes` 看一眼。
- 同样是弹一次管理员密码框，其余全程用户态。
- 看到最后一行 `完成。① 重启 DSH Desktop；② 重新授权 TCC（只需辅助功能 / 屏幕录制两项…` 就是装好了。
- 终端方式**不受 Gatekeeper 拦截影响**：安装器解包后会自己清掉隔离属性。

## 5. 第一次打开

1. 打开「启动台」或「应用程序」，找到 **LUTE Agentic System**，双击。
   > 📌 **名字不一样，是同一个东西**：磁盘上的文件夹叫 `DSH Desktop.app`（访达里看到的名字），
   > 而启动台、系统设置、授权列表里显示的是 **LUTE Agentic System**（它的显示名）。
2. 第一次打开可能又被拦一次 → 同样**右键 → 打开 → 打开**。
3. **第一次启动会准备运行环境（约 1 GB），可能等 1–3 分钟。** 窗口一时空白/转圈是正常的，别强退。
4. 看到主界面后，**退出并重新打开一次**（⌘Q 再开），让下一步的授权生效。

---

## 6. 授权两项（最容易卡住的一步）

应用需要两项系统权限。打开 **系统设置 → 隐私与安全性**，依次进入下面两个面板，把 **LUTE Agentic System** 的开关打开：

| # | 面板 | 它让应用能做什么 |
| --- | --- | --- |
| 1 | **辅助功能** | 读写界面元素（点击按钮、读取窗口内容），**并承载键盘与鼠标的事件投递**（`mac.key` / `mac.click`） |
| 2 | **屏幕录制** | 截图、看屏幕 |

- **只有这两个面板，没有第三个。** 两个都要做，缺一个对应能力就一直用不了。
- ⚠️ **「看起来是开的」不等于「真的开了」。** 从更早的版本升上来、或我们换过应用签名时，
  面板里可能残留着**上一版应用**的授权：开关显示为「已开启」，能力却完全没反应
  （截图、点击都没用）。界面只显示开关，不显示这个开关绑在哪个应用上，所以看不出来。
  处置：把这一项**关掉再打开**；仍不行就走下面两行（第一行清掉残留，再用列表下方的 **＋**
  把应用加回来）：
  ```bash
  tccutil reset Accessibility ai.deepseek.dsh.desktop
  tccutil reset ScreenCapture  ai.deepseek.dsh.desktop
  ```
- 不想逐项判断时，可以跑一次体检（在安装包 dmg 的 `tools/` 目录里）：
  `bash tools/tcc-grant-status.sh` —— 它把每一项的**开关值**与**绑定对象**一起读出来，
  并直接告诉你哪一项是「假的已开启」。

- 列表里找不到「LUTE Agentic System」→ 点列表下方的 **＋**，在「应用程序」里选 **DSH Desktop.app**，加进来再打开开关。
- 开关点不动（发灰）→ 先点面板左下角的 🔒 解锁（部分系统版本才有这个锁）。
- ⚠️ **不要去授「输入监控」。** 键盘与鼠标的事件投递由「辅助功能」承载，不需要为它多开一个面板：
  `macos-harness doctor` 的三项读数（`accessibility` / `screen_recording` / `post_events`）也只由
  上面两个面板覆盖。早期文档把第三项写在「输入监控」下是错的——照它做并非必需，
  还白送应用一个「读取全部按键」的高敏权限。
- ⚠️ **也不要指望「自动化」。** 授权「自动化」（Apple Events）不会让键盘鼠标类能力可用——
  这仍是最常见的错法：看着像授权过了，`mac.key` / `mac.click` 却始终没反应。
- 两项都打开后，**退出应用再重开**一次。
- **自 2.3.0 起，以后升级新版本都不需要重新授权。** 只有从更早的老版本升上来时，需要重授这一次。

## 7. 确认装好了

在「终端」里跑这一行，应输出 `2.0.5-lute.{{VERSION}}`：

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' "/Applications/DSH Desktop.app/Contents/Info.plist"
```

> 访达里右键「显示简介」看到的版本号是 `2.0.5`（系统短版本号），**完整版号要用上面这条命令**看。

## 8. 以后升级（每次拿到新 dmg 都这么做）

1. **先退出**正在运行的应用（⌘Q）。
2. 重复第 3 节或第 4 节 —— **不需要先卸载**。
3. 升级完直接打开即可，**不需要重新授权**。

- 你的会话、记忆、技能、自己装的插件都在 `~/.dsh` 里，安装器只替换「包自己带来的」那部分，这些**不会动**。
- 如果你自己用命令装过插件，而新包不再包含它，安装器**会在进度窗口/终端里把它列出来**提醒你（不会静默丢失）。

## 9. 出问题了：对照表

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| 「Apple 无法检查『…』是否包含恶意软件」 | 本包未做 Apple 公证（我们没走那条付费通道） | 右键该文件 → 「打开」→ 弹框点「打开」；或在 系统设置 → 隐私与安全性 里点「仍要打开」 |
| 「已损坏，无法打开，你应该将它移到废纸篓」 | 从网络下载带进来的隔离属性 | 先在终端跑一次：`xattr -dr com.apple.quarantine "/Volumes/DSH Desktop LUTE {{VERSION}}"`，再重装；或直接改用第 4 节的终端方式 |
| 双击 `install.sh` 只打开了文本编辑器 | 系统默认不执行 `.sh` | 按第 4 节在终端里运行 |
| 点「开始安装」后提示「未找到可用的安装包」 | 向导没能在同级或挂载卷上找到载荷 | ① 点左下「复制终端命令」→「打开终端」→ 粘贴回车；② 确认 dmg 已挂载，且没有把 `LUTE Setup.app` 拖出 dmg；③ 把窗口里的读数（它会打印自身路径、搜索过的目录）截图发给我们 |
| 向导提示「正被 macOS 从随机只读位置运行（App Translocation）」 | 未公证包的正常行为：系统只把向导本体复制到临时只读位置再启动 | **不用处理**，向导会自动到挂载卷上找回安装包；若它同时报「未找到可用的安装包」，改用第 4 节终端方式 |
| 安装报 `Operation not permitted` | 隔离属性传播到解包的文件 | 重新运行一次安装器（它会自动清除） |
| 反复回滚、装不上 | 以前用 `sudo` 装过，`~/.dsh` 属主变成了 root | 终端跑 `sudo chown -R $(whoami) ~/.dsh/profiles ~/.dsh/aeis-venv`，然后重装 |
| 安装中途提示「DSH 实例未能在 15 秒内退出」 | 应用还在运行 | 手动 ⌘Q 退出应用，再运行一次安装器（幂等，可重复跑） |
| 第一次打开长时间空白 / 白屏 | 首启要物化约 1 GB 环境 | 等 1–3 分钟；若几分钟后仍白屏，⌘Q 退出后重开 |
| 升级后白屏 | 安装时应用还在运行 | 完全退出（必要时「强制退出」）后重开；仍不行就重装一次，并确保安装期间应用未运行 |
| 面板里显示「已开启」，但截图/点击仍完全没反应 | 库里残留的是**上一版应用**的授权——界面只显示开关值，不显示它绑在哪个应用上 | 把该项**关掉再打开**；仍不行就跑 `tccutil reset Accessibility ai.deepseek.dsh.desktop`（换 `ScreenCapture` 再来一次），再用 ＋ 把应用加回来。诊断见 `tools/tcc-grant-status.sh` |
| 键盘/鼠标类能力一直没反应，但「看起来」授权过了 | 授成了「自动化」，或按旧文档多授了「输入监控」 | 回到第 6 节只做两个面板：**辅助功能** 与 **屏幕录制**。键盘与鼠标的事件投递由「辅助功能」承载，不需要「输入监控」（并非必需）；「自动化」授了也不会生效 |
| 装完找不到应用 | 显示名和文件夹名不同 | 在启动台搜「LUTE」，或到「应用程序」找 `DSH Desktop.app` |
| 想确认装的是哪一版 | — | 跑第 7 节的命令 |

## 10. 卸载与回退

**卸载**（三步）：

1. 退出应用，把 `/Applications/DSH Desktop.app` 拖进废纸篓。
2. 需要**彻底清干净**时再删这几处（⚠️ 删掉等于清空全部会话、记忆与登录状态，删前务必备份）：
   - `~/.dsh`（会话、记忆、技能、预设、凭据）
   - `~/Library/Application Support/DSH Desktop`（日志与缓存）
   - `~/Library/Application Support/LUTE Agentic System`（若存在，安装向导状态）
3. 系统设置 → 隐私与安全性 → 那两个面板里，选中「LUTE Agentic System」用 **−** 移除。

**回退到上一版**：安装器每次都会留一份带时间戳的备份，装坏了可以搬回来：

```
/Applications/DSH Desktop.app.pre-lute-<时间戳>
~/.dsh/profiles/desktop.pre-lute-<时间戳>
~/.dsh/aeis-venv.pre-lute-<时间戳>
```

把当前那份改名留档，再把要退回的备份去掉 `.pre-lute-<时间戳>` 后缀改回原名即可。

## 11. 反馈问题时，请带上这四样

1. **版本号**：第 7 节那条命令的输出。
2. **日志**：`~/Library/Application Support/DSH Desktop/logs/` 里当天的文件（`.error.log` 优先）。
3. **截图**：报错弹框、授权面板各一张。向导里的读数（安装包路径、搜索过的目录）尤其有用。
4. **dmg 的校验值**（怀疑文件下载不全/被改过时）：

   ```bash
   shasum -a 256 ~/Downloads/DSH-Desktop-LUTE-{{VERSION}}-mac-arm64.dmg
   ```

   与发布方公示的 SHA256 一致，才说明文件本身没问题。
   包内还有一层自校验（四个载荷 + 安装器）：

   ```bash
   cd "/Volumes/DSH Desktop LUTE {{VERSION}}" && shasum -a 256 -c SHA256SUMS
   ```

疑难时还可以让向导**自己报一次读数**（不安装，只打印它看到的路径）：

```bash
"/Volumes/DSH Desktop LUTE {{VERSION}}/LUTE Setup.app/Contents/MacOS/LUTE Setup" --print-payload-root
```
